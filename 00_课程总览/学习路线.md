# PCB 设计课程学习路线

> 🚀 如果你想按“做什么 → 达成标准 → 下一步”直接开工，请优先使用根目录 [START_HERE.md](../START_HERE.md)。本页负责解释路线，START_HERE 负责带你闯关。

> **正式主课程假设：你已经会独立完成二层板。**  
> 如果还不会，先使用本仓库的旧版 01～03 作为前置复习；不要再把旧版 01～08 当成正式主线。

## 1. 两条路线

### A｜正式主课程

```text
Part 0  二层 → 多层认知升级
→ Part 1 STM32F407 V1 四层板

→ Part 3 Power Integrity

→ Part 6 四层 → 六层
→ Part 7 STM32H743 V3 六层高速

```

```text
Part 0~6 的多层 / SI / PI / EMC 基础
→ Part 8 Artix-7 FPGA board-level engineering
→ Part 9 工程交付
```

## 2. 前置能力 Gate

进入 Part 0 前，至少能够：

- 独立完成一个二层板的原理图、PCB、DRC、Gerber；
- 理解基本电源、去耦、晶振、复位、调试接口；
- 会在 KiCad 中创建工程、同步原理图/PCB、设置基本规则；
- 会用万用表和实验电源完成安全上电；
- 能读 MCU datasheet / hardware guide 的基础章节。

缺项时复习：

- `01_零基础入门/`
- `02_原理图设计/`
- `03_二层板实战/`

旧版 `04_多层板理论` ～ `07_进阶专题` 只作为补充阅读；其中相关内容已经由 Part 0～8 重新组织。

## 3. 学习方法

每一章尽量按同一条因果链学习：

```text
现象
→ 物理模型
→ 必要公式
→ Source / Requirement
→ PCB Constraint
→ KiCad 落地
→ Fault
→ Review
→ Measurement / Validation
→ Decision Record
```

不要只记结论。每一个重要数字都问：

- 来源是什么？
- 对哪个器件 / 接口 / stackup 有效？
- 是硬 requirement，还是设计 target？
- 改版、换料、换板厂后是否要 reopen？

## 4. 毕业 Gate

### 四层毕业

完成 STM32F407 V2，并能解释：

- stackup / reference；
- USB / CAN / SDIO 约束；
- SI / PI / EMC 联合取舍；
- DFM / testability；
- bring-up 与 bug evidence。

### 六层毕业

完成 STM32H743 V3，并能解释：

- 为什么 6 层而不是 4 / 8 层；
- SDRAM timing budget 如何从 ns → cycles → PCB skew；
- Ethernet RMII / MDI / cable boundary；
- reference transition / power domain / PDN；
- 实测 evidence 如何支持 Release Gate。

### FPGA 专项毕业

完成 Artix-7 V1，并能解释：

- Device / package / Bank / VCCO / IOSTANDARD；
- BGA escape；
- MIG / DDR3 byte lane；
- GTP channel / S-parameter / BER；
- Vivado XDC ↔ KiCad 的双向约束同步。

### 工程交付毕业

最终工程必须能区分并留档：

```text
Design Freeze
→ DFM / DFA / DFT
→ BOM / alternates / lifecycle
→ fabrication + assembly package
→ programming / calibration
→ test fixture / validation
→ ECO / revision
→ pilot build
→ production release
```

## 5. 状态纪律

教材章节完成，不等于工程已经完成。

- `TBD`：未知或未冻结；
- `DRAFT`：已有方案，未完成证据闭环；
- `FROZEN`：输入资料与工程决策冻结；
- `VALIDATED`：已有实测 / 验证证据；
- `RELEASED`：制造与版本交付完成。

任何项目只要仍有关键 TBD，就不能宣称“生产冻结”。
