## 如何使用这张表

### 1. 它不是“推荐视频收藏夹”

只有真正进入教材正文、图示、实验或 Review 的资源才登记。

因此一个链接被列在这里，意味着至少完成了：

~~~text
原始资源
→ 知识点拆解
→ 与现有章节去重
→ 改写
→ 课程落点
→ 图 / SVG / Lab
→ Review / 实操
→ commit
~~~

### 2. 保留“用户原始链接”

本表优先保留用户粘贴进来的 URL（包括 playlist / timestamp 参数），这样以后可以追溯：

- 当时具体提交的是哪个入口；
- 是否来自某个播放列表；
- 是否指定了某个时间点。

各正文中的就近引用可以使用更干净的 canonical video URL。

### 3. 一个视频不等于一个章节

根据内容形态选择：

- **完整实验叙事** → 可能新建案例章；
- **跨多个主题的基础理论** → 分散回填；
- **工具 / 测量演示** → 放到实验或测量章节；
- **高价值但只覆盖一个局部知识点** → 就近补充，不人为扩成新章。

### 4. 精确数字仍然遵守“来源纪律”

视频中的数字会区分：

- 视频中特定实验的**实测值**；
- 作者给出的**经验规则**；
- 用来解释趋势的**教学数量级**；
- 可以跨项目使用的**标准 / 厂商 requirement**。

不会因为一个视频里出现了某个距离、阻抗、dB 或百分比，就把它升级成整个课程的固定规则。

## 后续登记模板

新增外部资源时，在表格中增加一行：

~~~text
ID
Original URL
Source / Author
Topics
Integrated chapters
Integration mode
Commit
~~~

并在对应章节保留**就近引用**。这样既能从课程正文回到原始资源，也能从本页反查某个资源最终影响了哪些章节。
