# 课程与工程状态说明

本文件解决一个常见歧义：**“教材写完”与“硬件工程做完”不是一回事。**

| 状态 | 意义 | 必须具备 |
|---|---|---|
| 📘 Curriculum Complete | 教学链闭合 | 正文、练习/Review、来源 |
| 🧩 Engineering Draft | 工程正在形成 | spec / constraints / review，可有明确 TBD |
| 🔒 Design Frozen | 设计输入冻结 | exact MPN、stackup、规则、BOM、CAD revision |
| 🧪 Prototype Validated | 样板验证 | bring-up、波形/日志、压力测试、问题闭环 |
| 📦 Release Complete | 可重复交付 | fabrication/assembly package、BOM、版本、release gate |

## 当前原则

1. 不用空白模板冒充验证报告。
2. 不用教学示例值冒充器件厂家 requirement。
3. 不用“DRC PASS”冒充 SI / PI / EMC sign-off。
4. 不用“能上电”冒充产品验证完成。
5. 每次 release 必须绑定 commit / revision / source freeze。
