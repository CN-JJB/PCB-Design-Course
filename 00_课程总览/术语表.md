# PCB 设计术语表（中英对照）

> 按主题分类。每条给出：英文名、中文译名、一句话解释、详见章节。

## A. 板材与结构

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| PCB (Printed Circuit Board) | 印制电路板 | 用铜箔在绝缘基板上刻出互连图形，替代手工飞线 | 01/01 |
| Substrate / Core | 基板/芯板 | 中间的绝缘层，最常见是 FR4 玻纤环氧板 | 04/01 |
| FR4 | FR4 覆铜板 | 最常用的基材：玻璃纤维布+环氧树脂，阻燃等级 94V-0，εr≈4.2~4.6 | 04/01 |
| Prepreg (PP) | 半固化片 | 压合时用来粘接芯片的"胶水层"，受热固化，也决定介质厚度 | 04/01 |
| Copper Foil | 铜箔 | 导电层。厚度用盎司(oz)计：1oz=35μm，0.5oz=17.5μm，2oz=70μm | 01/01 |
| Solder Mask | 阻焊层 | 绿色（或红蓝黑等）那层漆，防止焊锡乱流、防氧化；开窗处露铜可焊 | 01/01 |
| Silkscreen | 丝印层 | 白色字符：位号 R1/C3、极性标记、板名版本 | 01/01 |
| Surface Finish | 表面处理 | 焊盘最外层镀层：HASL喷锡 / ENIG沉金 / OSP有机保焊膜 | 01/01 |
| Edge.Cuts | 板框层 | 定义板子外形轮廓，铣刀沿线切割 | 03/04 |
| Panel / 拼板 | 拼板 | 多块小板拼成一块大板生产，提高效率，带工艺边 | 03/05 |

## B. 层与过孔

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| Layer / Stackup | 层/叠层 | 板子的"楼层结构"：哪层走信号、哪层是地电平面及排列顺序 | 04/01 |
| Signal Layer | 信号层 | 布线的铜层 | 04/01 |
| Plane | 平面层 | 大面积实心铜，作电源或地参考，提供低阻抗供电与回流路径 | 04/01 |
| Through Via | 通孔 | 从顶层打穿到底层的孔，所有层都能看到它 | 04/06 |
| Blind Via | 盲孔 | 从外层到内层但没打穿的孔（如 L1→L2），成本高 | 04/01 |
| Buried Via | 埋孔 | 只在内层之间的孔（如 L3→L4），外面完全看不见 | 04/01 |
| Via Stub | 过孔残桩 | 过孔没用到的多余段，高频时像一根悬挂天线造成谐振 | 04/06 |
| Backdrill | 背钻 | 把残桩钻掉的高速板工艺 | 04/06 |
| Annular Ring | 环形焊环 | 焊盘比孔大出来的那一圈铜，太小会断裂 | 03/03 |
| Microvia | 微孔 | 激光钻孔的小孔（<0.15mm），HDI 板专用 | 04/01 |
| Stitching Via | 缝合孔 | 沿板边或屏蔽墙打的一排接地过孔，把不同层 GND 缝在一起 | 05/04 |

## D. 传输线与信号完整性

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| Transmission Line | 传输线 | 当线长接近信号波长时必须按"分布参数"看待的走线 | 04/02 |
| Characteristic Impedance (Z0) | 特性阻抗 | 传输线对行波呈现的阻抗，由线宽/介质厚度/εr 决定，与长度无关 | 04/02 |
| Microstrip | 微带线 | 外层走线，一侧是空气一侧是介质 | 04/02 |
| Stripline | 带状线 | 内层走线，上下都是平面夹着 | 04/02 |
| Reflection Coefficient Γ | 反射系数 | Γ=(ZL-Z0)/(ZL+Z0)，阻抗失配程度的量化 | 04/02 |
| Rise Time (tr) | 上升时间 | 信号从 10% 到 90% 幅度的时间，比频率更本质的速度指标 | 04/02 |
| Critical Length | 临界长度 | 超过这个长度就必须当传输线处理 ≈ tr×v/6 | 04/02 |
| Ringing | 振铃 | 反射叠加导致波形上下振荡，可能误触发 | 04/02 |
| Overshoot / Undershoot | 过冲/下冲 | 波形冲过目标值/低于目标值，长期损伤芯片 | 04/02 |
| Termination | 终端匹配 | 在末端串/并电阻吸收能量消除反射（22~33Ω 串阻最常用） | 04/02 |
| Differential Pair | 差分对 | 两根反相传输的线，抗干扰强，USB/HDMI/以太网都是 | 04/02 |
| Single-ended Impedance | 单端阻抗 | 一根线单独看对地的阻抗（50Ω 惯例） | 04/02 |
| Differential Impedance | 差分阻抗 | 一对线看进去的阻抗（90Ω USB / 100Ω 以太网HDMI） | 04/02 |
| Odd/Even Mode | 奇模/偶模 | 两线同向/反向激励模式，决定耦合强弱 | 04/02 |
| Crosstalk | 串扰 | 相邻走线通过电磁场互相耦合干扰，近端远端两种 | 04/06 |
| 3W Rule | 3W 规则 | 线中心距≥3倍线宽，降低串扰约 70% 的经验法则 | 04/06 |
| Return Path | 回流路径 | 高频电流返回源头的实际路径——沿参考平面紧贴信号线下方流动 | 04/03 |
| Ground Bounce | 地弹 | 大量 IO 同时翻转时地电位瞬间抬升的现象 dI/dt×L | 04/03 |
| SSN (Simultaneous Switching Noise) | 同步开关噪声 | 地弹的正式名称 | 04/03 |
| Eye Diagram | 眼图 | 无数比特叠加的眼状图形，张开程度=质量好坏 | 04/06 |
| ISI (Inter-Symbol Interference) | 码间干扰 | 前一个比特的能量拖尾影响后一个判决 | 04/06 |
| TDR | 时域反射计 | 往线里打脉冲测阻抗分布的仪器 | 04/02 |

## E. 电源完整性

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| PDN (Power Distribution Network) | 电源分配网络 | 从 VRM 到芯片 die 的整个供电系统 | 04/04 |
| Target Impedance | 目标阻抗 | Zt=ΔVmax/ΔImax，PDN 设计的总纲数字 | 04/04 |
| Decoupling Capacitor | 去耦电容 | 芯片脚边的"本地水库"，瞬态供电+滤噪 | 04/04 |
| Bypass Capacitor | 旁路电容 | 与去耦基本同义，侧重"把噪声短路到地" | 04/04 |
| Bulk Capacitor | 大容量储能电容 | 板级/区域级蓄水池，470μF~1000μF 级别 | 04/04 |
| ESR / ESL | 等效串联电阻/电感 | 电容的非理想成分，决定高频表现 | 04/04 |
| Self-Resonant Frequency (SRF) | 自谐振频率 | 电容阻抗最低点，超过它电容变电感 | 04/04 |
| Mounting Inductance | 安装电感 | 电容焊盘+过孔引入的额外电感，往往比 ESL 还大 | 04/04 |
| Plane Capacitance | 平面电容 | 电源地平面构成的平板电容，C=εA/d，管超高频 | 04/04 |
| Voltage Ripple | 电源纹波 | 电源上的交流噪声，一般要求 <1%~3% | 04/04 |
| VRM (Voltage Regulator Module) | 稳压模块 | LDO/DCDC 等，供电系统的源头 | 04/04 |
| Power Integrity (PI) | 电源完整性 | PDN 设计的目标状态 | 04/04 |
| LDO | 低压差线性稳压器 | 简单干净但效率低，适合小电流 | 06/02 |
| DCDC (Buck) | 开关降压 | 效率高但有开关噪声，需要好的布局 | 06/06 |

## F. EMC 与防护

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| EMC (Electromagnetic Compatibility) | 电磁兼容 | 不干扰别人(EMI)也不被干扰(EMS)的双重能力 | 04/05 |
| Radiated Emission | 辐射发射 | 从空间辐射出去的电磁骚扰，认证测试项 | 04/05 |
| Conducted Emission | 传导发射 | 沿电缆传导出去的骚扰，150kHz~30MHz | 04/05 |
| Common Mode | 共模 | 多根线上同相位的噪声分量，辐射主力军 | 04/05 |
| Differential Mode | 差模 | 线与线之间的环路噪声分量 | 04/05 |
| CM Choke | 共模电感/共模扼流圈 | 对共模呈高阻抗、对差模几乎透明的滤波器 | 04/05 |
| Y-Capacitor | 安规Y电容 | 接在信号线与外壳地之间泄放共模噪声 | 04/05 |
| TVS Diode | 瞬态电压抑制二极管 | ESD 浪涌的"避雷针"，ns 级响应钳位 | 04/05 |
| ESD (Electrostatic Discharge) | 静电放电 | 人体静电打在接口上，8kV 接触是常见测试等级 | 04/05 |
| Shielding | 屏蔽 | 金属罩构成法拉第笼，缝隙要小于 λ/20 | 04/05 |
| Shield Wall | 屏蔽墙 | 板内沿敏感区边缘打的密集接地过孔排 | 05/04 |
| Guard Trace | 保护线/包地线 | 两侧伴随的 GND 走线，隔离串扰（需多缝合孔才有效） | 04/06 |
| CISPR 32 / EN 55032 | 信息技术设备辐射标准 | 商用 Class A / 家用 Class B，B 更严 | 04/05 |
| Faraday Cage | 法拉第笼 | 全包裹导体壳，内部电场为零 | 04/05 |

## G. 设计流程与制造

| 英文 | 中文 | 一句话解释 | 详见 |
|------|------|-----------|------|
| Schematic | 原理图 | 描述电路逻辑连接关系的图 | 02/xx |
| Netlist | 网表 | 从原理图提取的网络连接清单 | 02/04 |
| ERC (Electrical Rules Check) | 电气规则检查 | 检查原理图悬空/冲突等问题 | 02/03 |
| DRC (Design Rules Check) | 设计规则检查 | 检查 PCB 是否违反间距/线宽等工艺约束 | 03/04 |
| DFA / DFM | 可装配性/可制造性设计 | 让板子好贴好造的设计习惯 | 03/04 |
| Gerber | 格柏文件 | PCB 图形的标准交换格式，板厂只认它 | 03/05 |
| Excellon / Drill File | 钻孔文件 | 孔位孔径清单 | 03/05 |
| Pick & Place File | 贴片坐标文件 | 贴片机用的元件位置表（.pos） | 03/05 |
| BOM (Bill of Materials) | 物料清单 | 所有元件的型号数量表 | 02/04 |
| Impedance Control | 阻抗控制 | 要求板厂按目标阻抗生产并在横切面报告实测值 | 04/02 |
| Tg | 玻璃化温度 | 板材树脂软化温度，普通 FR4 Tg≈135℃，无铅工艺建议 ≥150℃ | 03/05 |
| HDI (High Density Interconnect) | 高密度互连 | 微孔+盲埋孔的先进工艺，手机主板级别 | 04/01 |
| Test Point | 测试点 | 留给探针/示波器接触的裸露焊盘 | 03/04 |
| SMD (Surface Mount Device) | 表贴器件 | 贴在板面的元件，与直插(DIP/THT)相对 | 01/02 |
| Reflow / Wave Soldering | 回流焊/波峰焊 | 两种批量焊接方式：整体加热 vs 熔锡波 | 01/05 |
