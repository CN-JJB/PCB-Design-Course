# 第二章 布局方法论：三分布线，七分布局

> 行业共识：布局决定一块板 70% 的成败。布线可以补救布局的小瑕疵，但烂布局神仙也救不回来。本章建立系统的布局方法论，并用 STM32 最小系统完整实战一遍。

---

## 2.1 布局的四大原则

### 原则一：信号流向优先

按"输入→处理→输出"的自然方向排布元件，杜绝信号走回头路：

```
好布局（顺流）：                    烂布局（逆流打结）：

[USB口]→[CH340]→[MCU]→[排针]      [MCU]→[排针]
   左边缘    中间    右侧            ↑       │
                                    │       │
                                   [CH340]←[USB口]
                                  信号交叉穿越，飞线满天飞
```

### 原则二：功能分区

同功能元件物理聚集，区与区之间留隔离带：

```
┌───────────────────────────────┐
│ 电源区      │ 数字区     │ 接口区 │
│ LDO+大电容  │ MCU+去耦   │ USB口  │
│            │ 晶振       │ 按键   │
│─────────────────────────────────│
│ （预留扩展区）                   │
└───────────────────────────────┘
```

分区的意义：干扰源（电源开关噪声）与敏感电路（晶振、模拟）天然远离；调试时能快速定位区域。

### 原则三：核心器件先定位

先放主控 MCU 和大型接口，再围绕它们放外围——**从大到小、从核心到边缘**。顺序错了会反复推倒重来。

### 原则四：飞线最短化

飞线（未连接网络的指示线）是布局的导航仪。目标：

- 飞线总长度最小
- 飞线不交叉或极少交叉
- 关键网络（时钟/差分/复位）飞线必须极短且直

## 2.2 元件放置的细则手册

### 去耦电容——位置就是生命

```
正确：
  VDD脚 ──0.5mm──┤├──过孔──GND
  
错误：
  VDD脚 ────5mm的细长走线────┤├────绕一圈────GND
  （引线电感抵消电容作用，等于白焊）
```

规则量化：

| 参数 | 要求 |
|------|------|
| 电容到引脚距离 | ≤1~2mm |
| 电容-引脚-过孔回路 | 面积越小越好 |
| 大小电容搭配 | 0.1μF 最近，10μF 稍远 |

### 晶振——敏感度最高的器件

- 紧贴 MCU 时钟引脚（≤3mm）
- 晶振正下方 F.Cu 不走任何其他线，B.Cu 尽量也不走
- 负载电容贴晶振放
- 远离板边 ≥5mm、远离 USB/按键等干扰源

### 连接器与接口——朝向即人体工学

- USB 口、排针一律贴板边，焊接面朝外（方便插拔和固定）
- 调试排针放在手容易够到、丝印看得清的位置
- 有防呆结构的连接器注意方向别画反

### 发热器件

- LDO/MOS/DCDC 远离电解电容、晶振、MCU
- 散热焊盘铜皮足够大（SOT-223 的接地腿接大片敷铜）
- 预留散热空间，别让外壳顶到元件

### 机械与工艺约束

| 项目 | 数值 |
|------|------|
| 元件距板边 | ≥3mm（含拼板工艺边考虑则≥5mm） |
| 元件间间距 | ≥0.5mm（手焊需要更大，0.8mm+） |
| SMT 与 THT 分侧 | 能分尽分：贴片全在顶层，直插在底层焊——回流焊工艺友好 |
| 高元件避让 | 电解电容高度 6mm+，注意与外壳干涉 |

## 2.3 实战：STM32 最小系统布局全过程

工程背景：40×30mm 板框已画好，元件全部摊开在外。

### 第一步：锁定三大锚点（5 分钟）

```
① USB Micro-B → 上边中央偏左，贴边
② MCU(LQFP48) → 板中央偏右下，旋转至方便引出的角度
③ SWD 排针(4P) → 右上角贴边
```

这三个定死，其余元件自然有了归属地。

### 第二步：电源链就位

```
USB ──→ AMS1117 → 输出储能电容 → 分发到各去耦阵
布局：LDO 放 USB 正后方偏下，
     输入输出电容紧贴 LDO 对应脚，
     与 MCU 区之间留出 3mm 缓冲。
```

### 第三步：去耦阵列贴脸

把 5 颗 0.1μF + 1 颗 10μF 逐一放到对应 VDD 引脚 1~2mm 内。此时你会发现 MCU 可能要微调旋转角度——正常，锚点阶段允许 ±2mm 微调。

### 第四步：晶振+负载电容

8MHz 晶振放 OSC_IN/OSC_OUT 引脚旁，22pF×2 夹在两侧，检查下方无其他元件。

### 第五步：外围收尾

- 复位 RC+按键 → 左下角
- BOOT 下拉电阻 → MCU 右侧
- LED 限流电阻+LED → 靠近对应 GPIO 且丝印可读的方向

### 第六步：飞线审查

按 U 逐个高亮关键网络目检：

```
[ ] GND 飞线是否杂乱？（二层板 GND 主要靠后续敷铜，少量飞线OK）
[ ] +3V3 主干路径是否顺畅无交叉？
[ ] USB_D+/D- 是否短而平行？
[ ] 晶振两条线是否 <5mm？
```

最终布局示意（俯视，顶层）：

```
 ┌────────────────────────────────────┐
 │        [USB]                       │ 40mm
 │   [C-in][AMS1117][C-out]           │
 │                                    │
 │        [Y8M+C C]  [SWD排针]        │
 │   [RST按键]  ┌──────┐              │
 │              │ MCU  │ [BOOT R]     │
 │   [LED+R]    └──────┘              │
 │  (去耦电容环绕MCU四周，图中略)        │
 │ STM32_MIN_SYS v1.0                 │
 └────────────────────────────────────┘
                30mm
```

## 2.4 布局的自查清单

提交布线前逐项打勾：

```
总体
[ ] 核心器件位于板中心区域，接口贴边
[ ] 信号流向无回头路
[ ] 功能分区清晰且有隔离带
[ ] 飞线交叉数量接近最少

电源
[ ] LDO 输入输出电容紧贴对应引脚
[ ] 去耦电容全部到位且 ≤2mm
[ ] 无元件压在大电流主干路径上

敏感电路
[ ] 晶振周围 3mm 内干净、下方不走线
[ ] 复位线短且远离干扰源

机械
[ ] 全部元件距板边 ≥3mm
[ ] 安装孔周围禁布区内无元件无走线
[ ] 连接器方向符合使用习惯
[ ] 高个元件（电解/排针）无干涉预判

工艺
[ ] 位号丝印方向统一（水平或跟随器件旋转90°档）
[ ] 极性标记清晰可见
[ ] 密脚芯片周围留了返修空间
```

## 2.5 布局的进阶意识（提前埋种子）

二层板阶段你只需要遵守上面规则。但请留意三个将在多层板部分彻底展开的概念：

1. **为什么晶振下方不能走线？** —— 任何走线都会切割它的回流路径并引入耦合（第四章回流路径理论）
2. **为什么去耦电容越近越好？** —— 引线电感公式 L≈1nH/mm，5cm 引线 = 50nH，足以让 0.1μF 在几十 MHz 就失效（第四章 PDN 理论）
3. **为什么功能分区要隔离带？** —— 地平面上的噪声不会跨过完整的沟壑传播（第四章 EMC）

现在先照做，之后你会知其所以然。

## 2.6 常见翻车现场

| 翻车 | 后果 | 教训 |
|------|------|------|
| USB 口放板中间 | 外壳悬空无法固定 | 接口永远贴边 |
| 去耦电容凑热闹堆一起 | 等于没加 | 一脚一容就近放 |
| 忘记排针是通孔件，顶层被大面积盖住 | 底层布线困难 | 通孔件优先规划 |
| 元件顶着板边放 | 切割露铜、装配刮伤 | ≥3mm 铁律 |
| 布局完直接开始拉线不复查飞线 | 越拉越乱 | 先审后拉 |
| MCU 方向没转好，GPIO 出线全拧着 | 布线噩梦期 | 锚点阶段多试几个角度 |
