# 第四章 敷铜、丝印与 DRC：从"能用"到"专业"

> 布线完成只是骨架。敷铜给板子穿上铠甲，丝印让它可读，DRC 是出厂质检。这三件事的质量直接区分"学生作业"和"工程师作品"。

---

## 4.1 敷铜 Zone 完全操作

### 创建 GND 敷铜

```
① Place → Zone（放置→区域），快捷键 Ctrl+Shift+Z
② 弹出 Zone Properties 对话框：
   - Layer: F.Cu（先做顶层）
   - Net: GND
③ 沿板框内侧画出区域轮廓（自动吸附 Edge.Cuts）
④ 双击结束 → 区域创建但还没填充
⑤ 按 B 或右键 → Zones → Fill All Zones 执行填充
```

### Zone Properties 参数详解

| 参数 | 默认 | 推荐调整 | 含义 |
|------|------|---------|------|
| Clearance | 0.2mm | 0.3mm | 敷铜与异网络走线的间距 |
| Minimum width | 0.25mm | 0.25mm | 窄于该值的铜皮碎条不生成（防孤岛） |
| Pad connection | Thermal reliefs | 见下表 | 焊盘连接方式 ★ |
| Fill type | Solid | Solid | 实心填充 |
| Thermal gap/bridge | 0.5/0.2mm | 保持 | 辐条参数 |

### Thermal Relief（热焊盘）——为什么不是全连接？

焊盘直接泡在大片铜里（Direct 全连接）的问题：烙铁热量瞬间被大铜皮吸走，手焊极难达到熔化温度。

```
Thermal Relief 辐条连接：
        ╲ │ ╱
       ──┼┼┼──    四根细辐条连接焊盘与铜皮
        ╱ │ ╲    其余部分留缝隙(gap)

效果：热传导受限(好焊)，直流电阻几乎不变，
     但高频阻抗略高——电源/信号小焊盘用辐条没问题；
     大电流焊盘(Bulk电容)建议改 Direct。
```

| 场景 | 连接方式 |
|------|---------|
| 普通 IC 电源脚去耦电容 | Thermal |
| 大电流入口/储能电容焊盘 | Direct + 加宽辐条 |
| 散热焊盘(QFN 底) | Direct + 过孔阵到背面铜 |

### 多个 Zone 的优先级

同一层可以有多个 Zone 叠放，Priority 数值大的先填充：

- 例：PWR_5V 区优先级 1 先填，GND 区优先级 0 后填——GND 自动避开 5V 区域绕行
- 平面分割（多层板章节）就靠这套机制实现

### 填充的维护纪律

**任何布线改动后必须重新按 B 重填充**，否则看到的铜是旧的。KiCad 有时提示 "Zone is stale"，看到就立刻刷新。

## 4.2 丝印工程学

丝印是给你自己和未来维修者看的说明书。

### 位号规范

| 项目 | 规范值 |
|------|--------|
| 字体高度 | ≥0.8mm（0.6mm 是极限） |
| 线宽 | ≥0.15mm |
| 方向 | 统一水平或统一竖直两个方向，禁止倒置 |
| 避让 | 不压焊盘、不过孔、不越板框 |
| 密脚区处理 | 位号放器件旁边空白处并加引线指示 |

### 必须有的标记

```
[ ] 极性件：LED 的 K 极、电解电容的 +、二极管阴极横线
[ ] pin1 标志：所有多脚 IC 和连接器
[ ] 接口功能标注：USB / SWD / UART / 5V IN
[ ] 关键测试点名称：TP_3V3 TP_GND
[ ] 板名+版本+日期：STM32_MIN_SYS v1.0 20260826
[ ] 高压/防静电警示（如有）
```

### 顶层放不下怎么办

底层丝印（B.SilkS）完全可用——注意底层丝印文字在制造后是镜像视角，KiCad 会自动处理翻转，但你在布局时要切换到底层视图确认位置合理。

## 4.3 测试点与调试友好设计

量产思维：预留测量接口，未来省一半排障时间。

| 类型 | 做法 |
|------|------|
| 电源轨测试点 | 直径 1mm 裸铜焊盘+丝印圈，标 TP_3V3 |
| GND 测试点 | 至少 3 个分散布置（示波器地夹要就近） |
| 关键信号 | 复位、时钟输出(MCO)、总线引出到备用焊盘 |
| 预留飞线焊盘 | 两孔一组的 JP 系列，断开/短接可切配置 |

## 4.4 DRC 完全解读

Inspect → Design Rules Checker（快捷键 Shift+B? 不对，是 Inspect 菜单）。设置页勾选全部检查项，Run DRC。

### 违规类型逐条攻略

| 违规 | 含义 | 修法 |
|------|------|------|
| clearance violation | 铜间距不足 | 移线/缩线宽；若发生在过孔密集处考虑加大间距重排 |
| track width | 线宽低于规则 | 该网络的 Net Class 设对了没有？改类或改线 |
| unconnected items | 飞线未消除 | 补线；若是故意的需原理图层面解决 |
| via annular width | 焊环太窄 | 换大焊盘过孔 |
| hole clearance | 孔与铜太近 | 移孔或移线 |
| courtyard overlap | 封装外框重叠 | 元件挪开；封装 courtyard 本身画错的改库 |
| silk over pad | 丝印压焊盘 | 移文字或删文字（阻焊会盖掉压盘丝印但最好别赌） |
| edge clearance | 铜/孔距板边不足 | 内缩 |
| missing footprint | 符号没封装 | 回原理图补分配 |
| duplicate footprints? | — | 一般为位号问题，Annotate 解决 |

### DRC 的哲学

- **Error 必须清零**——每一个都是制造风险
- Warning 逐条理解后可接受（如某些丝印提示）
- 清零后的 DRC 报告值得存档：`DRC_report_v1.0.html`

> 【进阶意识】DRC 只检查"几何规则"，不检查"电气逻辑"。接错网络它不管——所以 U 键抽查关键连通性仍是人工必修课。多层板阶段还会学到用网表对比工具兜底。

## 4.5 出厂前的最后修饰

1. **重建所有 Zone 填充**（B 键）
2. **3D 视图终检**：正反面旋转观察，检查元件悬浮/重叠/方向错误
3. **导出装配图 PDF**：File → Fabrication Outputs → Component Placement (.pos) 同时生成贴片坐标
4. **版本归档**：整个工程文件夹压缩为 `stm32_min_sys_v1.0.zip`——打样前必做，因为 v1.1 的修改会让你想回滚对照
