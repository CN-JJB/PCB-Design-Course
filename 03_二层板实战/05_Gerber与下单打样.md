# 第五章 Gerber 输出与下单打样：从文件到实物

> 本章目标：理解 Gerber 是什么、KiCad 每个输出选项的含义，掌握嘉立创（JLCPCB）下单全流程，以及收板后的验收方法。走完这一章，你就完成了第一次完整的硬件交付。

---

## 5.1 Gerber 是什么：制造业的通用语言

Gerber 格式（RS-274X，新版 RS-274X/X2）是 PCB 图形的事实标准——**你的 KiCad 源文件板厂不需要也看不懂，工厂只认 Gerber 包**。

```
一个 Gerber 文件 = 一个工艺层的光绘描述
  F_Cu.gbr      → 顶层数控光绘机照此曝光铜箔图形
  B_Mask.gbr    → 底层阻焊开窗位置
  drill.drl     → 数控钻床按此打孔
  ...
```

类比：Gerber 之于 PCB，就像 PDF 之于印刷品。排版软件（KiCad）可以千奇百怪，但交给印刷厂的一定是格式统一的 PDF。

> 【安全提示】Gerber 只含几何图形不含电路逻辑，发给板厂无泄密风险；但含全部版图细节，公开分享前自行斟酌。

## 5.2 KiCad 制造文件输出详解

### 第一步：Plot 铜层与丝印阻焊

File → Fabrication Outputs → Gerbers (.gbr)：

```
┌─────────────────────────────────────────────┐
│ Include Layers（勾选要输出的层）               │
│ [x] F.Cu          [x] B.Cu                  │
│ [x] F.Mask        [x] B.Mask                │
│ [x] F.SilkS       [ ] B.SilkS (若底面没丝印可不勾)
│ [x] Edge.Cuts     ← 必勾！没有板框=无法成型   │
│                                             │
│ General Options                              │
│ [ ] Plot footprint values  ← 不勾(板上不印参数值)
│ [x] Plot footprint references ← 勾(位号必须印)
│ [ ] Force plotting invisible values/texts   │
│ [x] Subtract soldermask from silkscreen     │
│      ← 丝印自动避开焊盘开窗区                 │
│ [ ] Check zone fills before plotting ★必勾   │
│      ← 出厂前强制检查敷铜是否最新填充！        │
│                                             │
│ Use extended X2 format: 保持默认             │
│ Units / Precision: mm / 4.6 默认            │
└─────────────────────────────────────────────┘
→ Plot 输出到工程目录 gerber/ 子文件夹
```

### 第二步：钻孔文件 Drill Files

同一对话框点 Generate Drill Files 按钮：

```
┌──────────────────────────────────────┐
│ Drill File Formats                    │
│ (·) Excellon  ← 选这个（行业钻床标准）  │
│ ( ) Gerber(X2)                       │
│ Map File Format: 保持 None 或 PDF     │
│ Drill Units/Precision: mm 默认        │
│ [x] Merge PTH and NPTH holes into one file
│     ← 嘉立创要求合并为单文件           │
└──────────────────────────────────────┘

PTH = Plated Through Hole 电镀孔(过孔、元件孔)
NPTH = Non-Plated 非电镀孔(安装孔等)
```

### 第三步：贴片坐标（可选）

File → Fabrication Outputs → Component Placement (.pos)：SMT 贴片服务需要。

### 第四步：打包

```
gerber 文件夹内容核对清单（二层板）：
[ ] project-F_Cu.gbr
[ ] project-B_Cu.gbr
[ ] project-F_Mask.gbr
[ ] project-B_Mask.gbr
[ ] project-F_Silkscreen.gbr
[ ] project-Edge_Cuts.gbr
[ ] project.drl (或 -PTH.drl + -NPTH.drl)

全选压缩为 zip —— 注意直接压文件，
不要把文件夹套文件夹（板厂解析器有的会懵）。
```

### 第五步：自己先看一遍！

用 KiCad 自带 **Gerber Viewer** 打开刚生成的文件逐层目检：

```
检查项：
[ ] 板框闭合完整
[ ] 各层图形与设计一致（尤其敷铜是否最新）
[ ] 孔位与焊盘对齐
[ ] 无意外的大片空白或多余图形
```

这一步能拦截 90% 的低级输出事故（忘了勾层、旧填充、镜像错误）。

## 5.3 嘉立创下单全流程

以 jlc.com（国际站 jlcpcb.com）为例，2026 年当前流程：

### 上传与识别

```
① 注册登录 → 首页"PCB下单" → 上传 zip
② 系统自动解析并预览：
   - 板子尺寸（自动测量）
   - 层数识别：二层板自动判出
③ 核对识别结果与设计一致（尺寸差太多=文件有问题）
```

### 关键参数选择表

| 参数 | 学习项目推荐 | 说明 |
|------|-------------|------|
| 板层数 | 2 | 自动识别 |
| 板材厚度 | 1.6mm | 默认；薄板选 1.0/0.8 |
| 板材类型 | FR-4 Tg≥135℃ | 默认即可 |
| 阻焊颜色 | 绿色 | 最便宜最快；黑/白加价加时 |
| 丝印颜色 | 白色 | 黑板配白丝印 |
| 表面处理 | **沉金 ENIG** | 推荐+几块钱；喷锡更省 |
| 铜厚 | 内外层 1oz | 大电流另说 |
| 最小线宽间距 | DRC 达标即默认 | |
| 过孔工艺 | 盖油(塞孔) | 推荐防短路；开窗会露铜环 |
| 数量 | 5 片 | 起订量，够用很久 |
| 工程订单号 | 印上 | 免费且方便对账 |

> 【过孔盖油 vs 开窗】盖油=过孔焊盘上覆盖绿油（防焊接短路、防氧化）；开窗=露出金属圈可当测试点。学习板选盖油。

### 高级选项（学习项目保持默认）

- 阻抗控制：多层板高速设计才勾（第六部分详解）
- 半孔/金手指/盲埋孔：本阶段不用
- 拼板：单片 >100×100mm 或批量生产时研究

### 提交后会发生什么

```
① 支付 → 订单进入"审核中"
② 工程师人工审核（约1~4小时）：
   - 有问题会发站内信+邮件说明（如丝印太细、孔径超能力）
   - 按建议修改重新上传即可
③ 生产（二层板通常 24~48h）
④ 发货快递（顺丰 1~3 天）
总周期：付款到收货一般 3~5 天
```

### 钢网要不要买？

钢网 = 激光切割的不锈钢薄片，刷锡膏用的模板。嘉立创打样常送小钢网券：

| 你的情况 | 建议 |
|---------|------|
| 元件 ≥0603 且手焊熟练 | 不用买，拖焊搞定 |
| 有 QFN/BGA/0402 | 买！配合锡膏+热风台回流 |
| 使用嘉立创 SMT 贴片 | 不用买（他们自己有） |

## 5.4 收板验收流程

到手先别激动着上电：

```
① 目检外观：
   - 板边切割平整无崩边
   - 阻焊颜色均匀，无大片气泡
   - 丝印清晰无断笔画
② 透光检查（手机闪光灯贴板背照）：
   - 短路嫌疑区域透光看铜皮是否粘连
③ 万用表复测：
   - 电源轨对地阻抗（对照设计预期）
   - 抽查 3~5 条关键网络的通断
   （通断档量焊盘到焊盘，应蜂鸣）
④ 与 Gerber Viewer 对照抽查丝印和极性标记
⑤ 通过后才进入第五章学过的"安全上电仪式"
```

发现制造问题（非设计问题）拍照留证联系客服，主流厂商对确属制程问题的板子会补打。

## 5.5 迭代节奏：v1.0 到 v1.1

第一版几乎一定有遗憾，这是常态不是失败：

```
v1.0 打样 → 焊接调试 → 记录问题清单：
  [ ] R3 丝印被电容挡住
  [ ] USB 口外壳焊盘虚焊，需加大焊盘
  [ ] 复位键离板边太近不好按
  ↓
原理图/封装/布局逐项修改 → 版本号 v1.1
→ 重跑 ERC/DRC → 重新出 Gerber → 二次打样
↓
两三个版本后趋于稳定 → 这份迭代记录
就是你最宝贵的学习档案
```

> 【职业习惯】每个版本都保留完整的工程快照（zip 归档），并在 README 里记录版本变更日志。三个月后回看，你会感谢现在严谨的自己。
