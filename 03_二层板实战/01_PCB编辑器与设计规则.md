# 第一章 PCB 编辑器与设计规则：开工前的战场布置

> 本章目标：认识 PCB 编辑器的图层体系，理解并配置一套合理的设计规则——每个数字都知道为什么。规则是 DRC 的依据，也是工厂工艺极限的翻译。

---

## 1.1 图层体系：PCB 文件的"频道"

KiCad 的层不是装饰，每一层对应制造中的一个物理对象：

### 铜层（导电）

| 层名 | 含义 | 制造对应 |
|------|------|---------|
| F.Cu | Front Copper 顶层 | 第 1 层铜箔 |
| In1.Cu ~ In4.Cu | 内层（多层板才有） | 中间层铜箔 |
| B.Cu | Bottom Copper 底层 | 最底层铜箔 |

二层板只有 F.Cu 和 B.Cu。

### 非铜层（工艺层）

| 层名 | 含义 | 关键规则 |
|------|------|---------|
| Edge.Cuts | 板框 | 封闭环，铣刀沿它切；圆角半径≥1mm 更利于铣加工 |
| F.Mask / B.Mask | 阻焊开窗 | 绿油开窗区。焊盘自动开窗，无需手动画 |
| F.SilkS / B.SilkS | 丝印 | 线宽≥0.15mm 字高≥0.8mm 保证印刷清晰 |
| F.Paste / B.Paste | 钢网开窗 | 贴片刷锡膏用，自动生成 |
| F.Fab / B.Fab | 装配图 | 给装配工人看的参考图，不出厂 |

> 【新手常见疑问】为什么焊盘不用自己画绿油开窗？因为 KiCad 自动为每个 Pad 在 Mask 层生成开窗（默认单边外扩 0.05~0.1mm）。需要手动处理的是"想露铜但不是焊盘"的地方，比如散热区域：在 Mask 层画图形即可开窗露铜。

## 1.2 设计规则的哲学

File → Board Setup → Design Rules（文件→板设置→设计规则）。

先建立认知框架：

```
你的规则 ≥ 工厂能力
   │         │
   │         └── 嘉立创常规能力（打样）：
   │             最小线宽/间距 5mil(0.127mm)
   │             最小过孔 0.2mm孔径/0.45mm焊盘(常规)
   │             孔铜纵横比 ≤ 8:1
   │
   └── 你设的规则要留安全余量：
       学习项目建议线宽/间距 ≥ 0.2mm，
       过孔 0.3/0.6mm —— 既好造又好焊好修
```

规则的本质是**你和工厂之间的契约**：DRC 检查你守约，工厂按约生产。违规的后果从良率下降到直接报废。

## 1.3 配置全局规则（Constraints 页）

Board Setup → Design Rules → Constraints：

| 参数 | 推荐值(学习) | 打样极限值 | 说明 |
|------|-------------|-----------|------|
| Minimum clearance | 0.2 mm | 0.127 mm | 铜到铜最小间距 |
| Minimum track width | 0.25 mm | 0.127 mm | 最细走线 |
| Minimum via size(diameter) | 0.6 mm | 0.45 mm | 过孔焊盘直径 |
| Minimum via drill | 0.3 mm | 0.2 mm | 钻孔直径 |
| Minimum hole to hole | 0.5 mm | 0.35~0.5 | 孔边到孔边 |
| Minimum silk line | 0.15 mm | 0.127 | 丝印线宽 |
| Minimum annular width | 0.125 mm | 0.075 | 焊环宽度=(焊盘-孔)/2 |
| Copper to edge | 0.3 mm | 0.2~0.3 | 铜到板边 ★常忘 |
| Hole to edge | 0.5 mm | 0.3 | 孔到板边 |

> 【经验】把 Copper to edge 设 0.3mm 以上还有个隐藏好处：板边敷铜时留出的空带让切割应力不作用在铜皮上，减少毛刺翘皮。

## 1.4 网络类 Net Class：分类管理规则

不同性质的网络需要不同规则——电源要粗，信号可细，差分有特殊要求。Net Class 就是给网络分组的容器：

```
Board Setup → Design Rules → Net Classes

默认三个类已存在：Default Class
我们新建两个：
┌────────────┬────────┬────────┬─────────┬──────────────────┐
│ 类名        │ 线宽    │ 过孔    │ 间距     │ 成员              │
├────────────┼────────┼────────┼─────────┼──────────────────┤
│ Default    │ 0.25   │ 0.6/0.3│ 0.2     │ 其余全部          │
│ Power      │ 0.8    │ 0.9/0.5│ 0.25    │ +5V +3V3 VBUS GND│
│ Signal_Fast│ 0.3    │ 0.6/0.3│ 0.2     │ USB_DP USB_DM    │
└────────────┴────────┴────────┴─────────┴──────────────────┘
```

成员添加方式：右侧列表勾选网络名加入该类。

> 【思考题】GND 为什么放 Power 类？因为地线虽然电流方向复杂，但它承载全板的回流电流总和，粗走线永远没错。（多层板里 GND 是整面敷铜或平面，此问题消失——这正是多层板的优势之一，第四章展开。）

### 单个网络的特殊规则

个别网络需要偏离类规则时：Net Classes 页下方的 Custom Rules 或选中走线后属性里覆盖。例如某根时钟线要求加宽隔离。

## 1.5 从原理图同步元件

上一部分末尾已经 F8 同步过，这里系统化一遍：

```
Tools → Update PCB from Schematic (F8)

弹窗选项解读：
[x] Re-link footprints based on reference designators
    按位号重新关联（改名后用）
[x] Delete footprints with no symbols  
    删除多余封装（原理图删了元件，板上同步删）
[ ] ...其余保持默认

→ Apply → 元件堆出现在画布左下原点附近
```

第一次面对几十个堆叠元件不要慌——按 M 全选拖开摆成一排，像发牌一样摊在板框外，准备布局。

## 1.6 板框设计 Edge.Cuts

切换活动层到 Edge.Cuts（右侧层面板点击），然后：

Place → Rectangle / Line / Graphic Polygon（快捷键 Ctrl+Shift+Z 矩形等）

### 板框尺寸的确定方法

以 STM32 最小系统为例，规划 **40×30mm**：

1. 列出大件清单及尺寸：USB口(7.5×5)、MCU(7×7)、排针若干
2. 草图排列估算长宽 → 加 20% 余量定 40×30
3. 画矩形：从原点 (0,0) 到 (40,-30)（Y 向下为正）
4. 圆角：可选 Place → Fillet 加 R2 圆角

### 机械要素清单（专业板必备，学习项目选做）

| 要素 | 规格 | 位置习惯 |
|------|------|---------|
| 安装孔 M3 | 孔径 3.2mm，禁布区半径 4mm | 四角内缩 5mm |
| 基准点 Fiducial | 1mm 铜点+3mm 开窗环 | 对角两个+一个防呆 |
| 板名版本丝印 | 如 STM32_MIN_v1.0 | 底层或角落 |
| 日期/作者 | 20260826 by xxx | 底层角落 |

> 安装孔做法：Footprint 库搜 MountingHole 选 MountingHole_3.2mm_M3 放置即可，自带禁布 courtyard。

## 1.7 视觉辅助工具箱

布板前熟悉这些视图开关（左侧竖条）：

| 工具 | 用途 |
|------|------|
| 显示飞线 Ratsnest | 未连接网络的白色细线，布局的灵魂指引 |
| 高亮网络 U 键 | 点击任何网络高亮整条路径，排查连通神器 |
| 显示焊盘编号 | 密脚芯片核对引脚 |
| 3D 查看(3键/Alt+3) | 实时渲染，随时检查干涉和外观 |
| 单层显示模式 | 隔离观察某一层，排查跨层错误 |

网格策略回顾（第一章零基础讲过）：布局 0.5mm，布线 0.127mm，微调 0.05mm。

自检：

实践作业：

1. 打开你的 STM32 最小系统工程 PCB
2. 完成 Board Setup：全局约束 + Power/Default 两类规则
3. 画 40×30mm 板框 + 四角 M3 安装孔
4. F8 同步，把所有元件拖出摆开
5. 截图存档当前状态（这是布局前的"素板"）
