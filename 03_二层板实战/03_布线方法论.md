# 第三章 布线方法论：让每根飞线体面消失

> 布线是在布局划定的框架内完成电气连接的艺术。本章覆盖二层板布线的全部核心技能：优先级策略、电源加宽、过孔纪律、地的困境与出路、差分对入门。

---

## 3.1 布线优先级金字塔

不要拿起鼠标就随机拉线！按此顺序处理：

```
        ┌──────────────┐
        │ ① 特殊约束网络 │ 差分对/时钟/复位/模拟信号
        ├──────────────┤
        │ ② 大电流电源   │ 主干 +5V +3V3 GND主干
        ├──────────────┤  
        │ ③ 敏感短网络   │ 晶振/去耦电容连线
        ├──────────────┤
        │ ④ 普通信号     │ GPIO/LED/按键
        └──────────────┘
先难后易。普通信号最后走——它们最灵活，
能绕能让，用来消化前面留下的复杂局面。
```

## 3.2 电源布线：宽度即生命

### 载流能力速查（外层 1oz 铜，温升 ≤10℃）

| 电流 | 最小线宽 | 推荐线宽 | 说明 |
|------|---------|---------|------|
| 100mA | 0.15mm | 0.25mm | 信号级 |
| 500mA | 0.3mm | 0.5mm | |
| 1A | 0.4mm | 0.8mm | 学习项目建议直接 1mm |
| 2A | 0.8mm | 1.5mm | |
| 3A | 1.2mm | 2mm+ | 或敷铜+开窗上锡加厚 |

> 精确计算用 KiCad 计算器或 Saturn PCB Toolkit（IPC-2152 标准）。上表已含保守余量。

### 电源树布线路径规划

```
USB 5V入口 ──1mm──→ LDO输入
LDO输出 ──1mm──→ +3V3 主干（贯穿全板）
主干沿途分支 ──0.6mm──→ 各区域
各去耦电容 ──0.3~0.4mm──→ 芯片引脚

原则：主干像树干一样粗壮笔直，
     分支渐细，末梢(去耦)可以细但必须短。
```

### 星型 vs 链式供电

```
星型（推荐小系统）：         链式（大板分区用）：
      +3V3                        +3V3
    ┌──┼──┐                    ┌───┬──┴─┬───┐
   MCU 晶振 LED                  区A  区B  区C
每个负载独立从源头取电            干线上有压降累积
无相互串扰                       但省铜省面积
```

学习项目直接星型；产品级大板用"干线+分区星型"混合。

## 3.3 过孔使用纪律

每个过孔都是"不完美"：约 0.5~1nH 寄生电感 + 额外电阻 + 占双面空间。

| 规则 | 数值依据 |
|------|---------|
| 信号尽量少换层 | 每次换层=一次阻抗扰动 |
| 过孔尺寸统一 | 0.3/0.6mm 全板一致，便于生产统计 |
| 电源过孔加大或并联 | 单个 0.3mm 孔约载 1A，2A 用两孔 |
| 过孔不打在焊盘上（非 BGA） | 手焊时锡会从孔漏走造成虚焊 |
| 孔到孔间距 ≥0.5mm | DRC 会查 |

> 【为什么过孔有电感】电流绕着孔壁转圈，形成一个小线圈。经验公式 L≈5.08×h×[ln(4h/d)+1] nH（h、d 为英寸）。1.6mm 板厚 0.3mm 孔 ≈ 1.2nH。这个数字在低速电路无所谓，高速时是主角——记住量级即可。

## 3.4 二层板的地：诚实的困境讨论

理论上的理想地是"一整块无缝铜"。二层板的现实：

```
顶层：信号+器件
底层：GND 尽量整面敷铜
       ↓ 但是！
信号不可避免要从顶层跨到底层，
每次跨越都在底层 GND 铜皮上挖一个洞；
平行走线把 GND 切成一条条走廊……
最终底层变成"瑞士奶酪"。
```

### 二层板接地生存法则

1. **底层以 GND 敷铜为绝对主体**，允许穿行的只有极少数必要信号，且这些信号走向要垂直于主要信号方向
2. **顶层大面积区域也敷 GND**（与底层同网络），通过密集缝合过孔把两层铜缝成一体
3. **敏感电路下方保持完整地**：晶振下方、模拟区下方的地绝不允许被切断
4. **接受现实**：二层板做不了真正的低 EMI 高速设计。它的定位是低速简单系统（<50MHz 内部时钟的 MCU 板没问题）

> 这个困境正是多层板存在的理由。当你亲手体验过"地在二层板上无处安放"，第四章的地平面理论会瞬间通透。

### 缝合孔 Stitching Via 的用法

```
每隔 λ/20（对 100MHz 约 15cm，实际工程取 10~15mm）打一对
F.Cu↔B.Cu 的 GND 过孔，把两层地"钉"在一起：
 
 顶GND ══╦════════════════
          ║ ║ ║ ║  ← 缝合孔阵列
 底GND ══╩════════════════
```

作用：给回流电流提供就近的层间通道，缩小回路面积。

## 3.5 交互式布线器实战技巧

### 三种推挤模式（Shift+R 切换）

| 模式 | 行为 | 适用 |
|------|------|------|
| Highlight collisions | 只高亮冲突不许过 | 精确控制场景 |
| Shove 推挤 | 自动推开已有走线 | **默认推荐** |
| Walkaround 绕行 | 自动绕障碍 | 密集区 |

### 核心快捷操作流

```
X 开始 → 点击确定起点 → 移动鼠标（自动跟随45°拐角）
  ├─ V 打过孔换层继续走
  ├─ Ctrl+点击 固定一段后重新规划
  ├─ Backspace 回退上一段
  └─ 双击/Esc 结束
U 检查：点任意线段高亮整网络确认连通
D 拖动带线调整（比删了重走快十倍）
```

### 拐角风格

KiCad 默认 45° 圆弧过渡，保持即可。关于"直角走线辐射论"的真相：直角在 <GHz 场景的电气影响微乎其微，禁直角主要是工艺习惯和美观考虑。**45° 是好品味，但不必迷信**。

## 3.6 差分对初体验（以 USB 为例）

CH340 的 USB_D+/D- 是全速 USB（12Mbps），严格说不算高速，但养成正确习惯：

### 定义差分对

原理图侧：给两个网络命名为 USB_DP / USB_DN，且 Net Class 设为差分类（Board Setup → Differential Pairs 里定义该类的目标阻抗，如 90Ω——二层板打样阶段先设规则占位，阻抗控制到多层板再较真）。

PCB 侧：

```
Route → Differential Pair（快捷键 6）
选中 USB_DP 焊盘 → 两线自动并排跟随
规则：
- 两线间距全程恒定（KiCad 按 Net Class 的 pair gap）
- 同步拐角（45°对称）
- 同步打过孔（并排两个，紧挨）
- 长度差 <1mm（低速要求宽松）
```

### 蛇形等长什么时候才需要？

当协议有时序要求时（HDMI/DDR/千兆网），用 Route → Tune Track Length 走蛇形补长。12Mbps 的 USB 完全不需要——**别为了炫技加蛇形线，每一毫米都增加损耗和辐射**。

## 3.7 布线的完成度检查

所有飞线消失只是及格线。优秀布线的验收标准：

```
[ ] 无飞线残留（View → 显示飞线 关掉后再开，确认清零）
[ ] 电源路径宽度达标且有裕量
[ ] 无锐角(<90°)走线
[ ] 过孔总数合理（二层小板通常 <40 个）
[ ] 晶振两条线 ≤5mm 且周围净空
[ ] USB 差分平行等距
[ ] 底层 GND 敷铜连通性良好（U 键点几个不同位置的 GND 焊盘
    确认高亮的是同一片铜）
[ ] 顶层空白区也敷了 GND 并有缝合孔
[ ] 无 DRC 违规（下一章正式跑）
```

## 3.8 常见翻车现场

| 翻车 | 症状 | 解法 |
|------|------|------|
| 电源线细如发丝 | 带载压降大、LDO 振荡 | 对照载流表重铺电源 |
| 过孔打在 0805 焊盘中间 | 手焊锡漏走虚焊 | 孔移出焊盘或改 THT 工艺考虑 |
| 地敷铜被切得七零八落 | 时钟噪声满天飞 | 重规划走线方向保地完整 |
| 忘了还有一根飞线就敷铜 | 敷铜盖住错误静默短路 | 敷铜前飞线必须清零 |
| 差分对两根线各自乱走 | 长度差大、耦合丧失 | 用差分布线工具重走 |
| 蛇形线贴太近自耦合 | 补了长度反而更糟 | 蛇形间距 ≥3倍线宽 |
