# 专题五 DFM 可制造性设计与设计评审

> 设计的终点不是 DRC 清零，而是"工厂愿意接、产线贴得快、良率站得住"。本章讲可制造性设计(DFM)的完整清单与结构化的评审流程——从个人作品到量产产品的分水岭。

---

## 5.1 读懂工厂能力表：一切规则的源头

主流板厂（以嘉立创打样为例）公开工艺能力，学会逐行解读：

| 能力项 | 常规值 | 解读 |
|--------|--------|------|
| 最小线宽/间距 | 3.5~5mil | 你的 Default 规则必须大于它+余量 |
| 最小钻孔 | 0.15~0.2mm | 过孔孔径下限；0.2 以下进激光孔计价 |
| 孔铜厚度 | ≥20μm(平均) | 载流计算按此值而非标称 |
| 纵横比 | ≤8:1 | 板厚÷孔径；1.6mm 板→最小 0.2mm 孔 |
| 最大板厚差? 层压对位 | ±75μm? | 内层阻抗波动来源之一 |
| 阻焊桥最小 | 0.08mm | 相邻开窗间绿油桥，密脚 QFN 可能保不住桥 |
| 半孔/金手指 | 支持加价 | 边缘连接器方案用 |

> 实战习惯：新厂第一次合作前，把它的能力表 PDF 与你的规则表并排核对一次，把差异写进工程 README。

## 5.2 SMT 可装配性设计(DFA)

```
焊盘内过孔 Via-in-pad 的取舍：
优点：寄生最小、省空间
代价：锡从孔流失→虚焊，需树脂塞孔电镀帽(VIPPO)加钱
结论：BGA 区域才值得，普通件别用。

元件间距分级：
机贴：≥0.2mm 即可
手拖焊：≥0.5mm
返修热风：≥1.5mm 才能塞风嘴
→ 学习板按 0.8mm 元件间距规划

钢网开窗与锡量：
细间距 QFP/QFN 开窗建议 0.5:1 缩比防桥连
(在 KiCad Pad 属性的 Paste 外扩负值实现)
密脚芯片旁预留 45° 拖焊通道与检查丝印位号
```

## 5.3 拼板与工艺边

```
什么时候拼板：
小板(<50×50mm)、异形板、SMT 贴片成本摊薄

拼板方式对比：
V-cut：直线切缝便宜，但要求板边平直、不能异形
邮票孔(Router+Tab)：任意形状、边缘有毛刺需后处理 ★通用
正反面拼：注意顶层元件位置错开避免钢网冲突

工艺边(Tooling Rail)五要素：
宽度 5mm、每边基准点×3、边上的测试 coupon?
贴片机夹持区禁元件、与主板连接处邮票孔间距≤1mm
```

## 5.4 设计评审流程(Design Review)

### 三级评审制

```
自评(设计者)：Checklist 全量过一遍 → 出 v0.x
同行评(同事/AI红蓝对抗)：专挑毛病视角：
   "假设我是产线工程师，哪里会卡我？"
   "假设我是维修工程师，哪块最难下手？"
终评(负责人)：对照需求规格书逐条验收签字 → 冻结 Gerber
```

### 评审问题库（高频翻车 TOP20）

```
电源类
□ LDO 输出电容 ESR 不在稳定窗口
□ Buck 电感下方走线穿越
□ 大电流路径有细腰(过孔单颗)
接口类
□ USB CC 电阻缺失/阻值错
□ TVS 远于连接器或地孔单颗
□ 连接器封装镜像错误
高速类
□ 差分 gap 忽大忽小
□ 换层无伴飞地孔
□ 等长组漏一根
制造类
□ 丝印压焊盘/方向倒置
□ 安装孔与外壳柱干涉(没查结构件)
□ BOM 有料但封装缺货
文档类
□ 版本号未更新
□ 电源树图缺失
□ 阻控表与叠层不一致
```

## 5.5 成本意识：每个决策的价格标签

```
驱动总成本的杠杆排序(经验值)：
层数 > 板材等级 > 表面处理 > 盲埋孔 > 最小线宽档位 >
阻焊颜色 > 板厚特殊值 > 拼板方式

省钱组合拳示例：
四层→六层需求评估时先问：能否用"四层+完整地"
方案 B 换掉一层信号层？
ENIG→OSP 在大批量省 8~15%；
颜色黑改绿在打样期免加价加速；
异形板改矩形+后期 CNC 切。
反向教训：为了省几块钱选 Y5V 电容/二手拆机料，
调试烧掉的时间远超物料差价——
**省该省的钱，别省会咬人的钱。**
```
