# 专题七 FPGA 高速板设计要点：Bank、约束与协同

> FPGA 是高速板设计的常客，它的电源域结构、Bank 规则与配置电路自成一派。本章让你具备画一块"能点亮的 Artix/Zynq 底板"的知识框架。

---

## 7.1 电源域地图：以 7 系列为例

```
一颗 Artix-7 的供电需求：
VCCINT   1.0V  核心逻辑(电流大头，随利用率波动)
VCCBRAM  1.0V  块存储(可与 VCCINT 合并供但需独立去耦区)
VCCAUX   1.8V  辅助/配置
VCCO_xN  每个Bank独立的IO电压!(3.3/2.5/1.8/1.5按接口定)
VCCADC?  部分型号模拟域

关键认知：
① Bank 是 IO 电压的边界——同一 Bank 只能一种 VCCO
   引脚分配第一步就是按"接口→Bank"映射
② 上电顺序：手册规定 VCCINT→VCCAUX→VCCO 或用
   PWR_GOOD 链控制；违反=上电冲击电流或损坏
③ 电流估算用官方 Power Estimator 表格，
   VCCINT 的 dI/dt 决定你的 PDN 目标阻抗
```

## 7.2 配置电路：FPGA 板的"开机引导"

```
三种启动模式硬件支持：
JTAG(调试必备) / 主SPI Flash(产品标配) / 从模式

最小配置电路清单：
- 专用配置 Flash(W25Q128JV 类)接 FCS/FCLK/MOSI/DI/DO? 
  按 7 系列引脚名核对
- PROB_B? PROGRAM_B 按钮+10k上拉(复位重载比特)
- INIT_B 上拉 + DONE LED(串470Ω) 
  ——DONE 不亮=配置失败的第一观察窗
- CCLK 走线短且远离干扰；配置数据线组内等长宽松
  但要远离时钟
- JTAG 四线(TCK/TMS/TDI/TDO)+参考地引到标准 2×7 座
```

## 7.3 引脚分配与原理图的协同流程

```
正确顺序(反着来必返工)：
① 列出全部外部接口及其电气需求(电平/速率/差分?)
② 打开厂商工具(Vivado)的 IO Planning：
   按需求选 Bank → 得到候选引脚清单
③ 导出引脚分配表 → 作为原理图绘制的输入
④ 原理图完成后反向生成 XDC 约束文件初稿
⑤ PCB 布局若需调整引脚(如逃逸更顺)，
   回 Vivado 改分配→同步改原理图——闭环管理

禁忌：先随手画完原理图再"找地方放"FPGA 引脚
——那是返工地狱的开始。
```

## 7.4 高速收发的特殊关照（GTP/GTX 收发器）

```
使用 MGT(RocketIO 级硬核)时的增量规则：
- 参考时钟 REFCLK 走专用引脚，差分对全程包地缝孔
- TX/RX 差分对阻抗 ±10% 且禁打过孔(必须打则优化残桩)
- 相邻 MGT 通道间的隔离：3W 以上+地孔墙
- 电源 VCCAUX/VCCINT 的噪声直接影响 PLL 抖动
  → 这两轨的 PDN 目标比普通数字严一个数量级
- 每通道的 AC 耦合电容位置遵循 Transceiver User Guide
```

## 7.5 与 MCU 方案的成本对比决策

| 维度 | MCU(如 H743) | FPGA(Artix-7 级) |
|------|-------------|------------------|
| 单片价格 | ¥20~60 | ¥100~800 |
| PCB 层数 | 4~6 | 6~10+ |
| 开发门槛 | C 语言 | HDL+时序约束 |
| 并行处理 | 弱 | 极强 |
| 接口定制性 | 固定外设 | 任意可编程逻辑 |
| 功耗 | 低 | 数倍以上 |

选型口诀：**控制流用 MCU，数据流用 FPGA，两者都要用 Zynq/STM32MP1。**
