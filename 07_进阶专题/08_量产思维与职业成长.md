## 8.1 版本管理：硬件的 Git 思维

```
硬件版本的三个层级：
vA.x 电气变更(改电路)——必须重打样全测
vb.x 布局变更(不改逻辑只改布线/封装)——可局部验证
vc.x 文档丝印——改文档即可

工程仓库标准结构(建议直接套用)：
project/
├── hardware/
│   ├── v1.0/ (完整快照: sch+pcb+gerber+BOM+报告)
│   ├── v1.1/
│   └── CHANGELOG.md   ← 每版改了什么为什么
├── firmware/
├── docs/ (需求规格/测试报告/认证文件)
└── fab/ (已下单的gerber归档+订单号)

铁律：
- Gerber 冻结后不再手改，任何修改回到源文件重出
- BOM 里每个料给"替代料"列(AVL 意识)
- 打样订单号记录在 CHANGELOG——追溯链完整
```

## 8.2 可靠性设计入门：让产品活过保修期

```
降额设计(De-rating)是第一原则：
电容工作电压 ≤ 标称 70~80%
电阻功率 ≤ 标称 50%
LDO/MOS 结温度 ≤ 最高结温 70%
电解电容寿命公式每降温10℃翻倍 → 远离热源不是玄学

环境适应性检查单：
[ ] 高温存储/工作极限(运输在车里暴晒50℃+)
[ ] 低温启动(-20℃ 电解容/晶振偏差)
[ ] 湿热(表面处理选择、三防漆需求评估)
[ ] 振动(连接器选带锁扣款、大件点胶)
[ ] ESD/浪涌(接口防护等级按使用场景提级)

加速老化试验概念：
高加速寿命测试(HALT)/温度循环，
小团队至少做：72h 高温老化拷机 + 温循 10 次。
```

## 8.3 供应链与生产交接

```
BOM 的量产形态(对比学习版的升级)：
位号 | 描述 | 厂牌料号 | 替代1 | 替代2 | 封装 | 用量 | 单板位置备注
+ 采购状态列(现货/期货/停产预警)

与贴片厂交接包：
Gerber + 钢网文件 + BOM(Excel) + 坐标文件(pos) 
+ 装配图PDF + 特殊工艺说明(如"QFN 需 X-Ray 抽检")

首件确认(FAI)流程：
产线先出 5~10 片 → 你逐项核对(元件方向/极性/焊点)
→ 签字放行才批量——这一步能拦住最贵的事故。
```

## 8.4 硬件工程师的成长地图

```
阶段0 学员(本课程毕业)：能独立交付六层板
阶段1 初级工程师(0-2年)：
  熟练一个产品线全流程；学会被评审；debug 有章法
阶段2 中级(2-5年)：
  主导模块级设计；懂成本/良率权衡；
  能带新人 review;建立个人规则库与器件库
阶段3 高级(5年+)：
  系统级架构决策(选型/分区/成本目标分解)；
  跨部门协作(结构/固件/测试/供应链)；
  处理"没有先例"的问题
阶段4 专家/架构师：
  定义平台与技术路线；对外技术影响力

贯穿所有阶段的三个习惯：
① 每个项目复盘写 NOTES(本课程已在训练)
② 维护自己的知识库(器件档案/踩坑集/Checklist)
③ 保持动手：再资深也要定期焊板子抓波形
```
