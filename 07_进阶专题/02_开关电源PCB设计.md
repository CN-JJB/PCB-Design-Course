# 专题二 开关电源 PCB 设计：Buck 的布局艺术

> 项目六用过 MP2315，本章系统化展开 DCDC 布局的完整方法论。开关电源是"模拟与数字的交界战场"，90% 的电源问题（啸叫、纹波超标、EMI 炸表、带载跌压）根源都在布局。

---

## 2.1 Buck 拓扑与三个致命环路

```
标准同步 Buck：

VIN ──┬──[Cin]──┬──────
      │         │
      └──[HS管]─┤
                ├SW节点──[L]──┬──VOUT
      └──[LS管]─┘             │
           │              [Cout]
          GND               │
                           GND

环路一 输入热回路(Hot Loop)：Cin→HS→LS→回Cin
  ★开关瞬间 dI/dt 最大的路径=EMI 与振铃之源
环路二 输出回路：L→Cout→负载→GND→L (电流连续，温和)
环路三 电感充放电换路：HS导通/LS导通两状态切换
  
黄金法则：热回路面积最小化 = 把 Cin 放在
离 HS/LS 引脚最近的位置，让回路"贴脸"。
```

### 热回路的量化影响

```
回路电感 L_loop 决定 SW 节点的振铃幅度：
V_spike ≈ V_in + I_sw × ... 由 di/dt×L 决定
每 nH 在 1A/ns 下产生 1V 尖峰！

尖峰的危害：
- 击穿低耐压 LS 管(20V 管怕 25V 尖峰)
- 辐射 EMI 主频段 30~300MHz
- 通过 SW 节点电容耦合进反馈线
```

## 2.2 布局铁律十二条（逐条附原因）

```
① Cin 紧贴功率级引脚，容值按纹波电流选
   (陶瓷 10~22μF 起，大电流多颗并联)
② HS/LS 管或集成芯片的 SW 铜皮最小必要面积
   ——既要散热又要小天线，矛盾中取平衡：
   功率 >3W 才扩大铜皮，否则保持紧凑
③ 自举电容 Cboot 紧贴 BOOT/SW 脚(<2mm)
   它驱动高侧管开关，远=驱动不足=发热
④ 反馈(FB)走线远离 SW 和电感 ≥5mm，
   分压电阻采样点在输出电容之后(真输出电压)
   FB 是 µV 级敏感节点，被 SW 耦合=输出抖动
⑤ 电感下方各层净空? 折衷：内层地可以保留，
   但信号线绝不在电感正下方穿过
⑥ 输出电容在电感后立即放置，
   大容值靠后、ESR 补偿考虑 datasheet 要求
⑦ 功率地与信号地单点汇接于芯片 GND 脚
   或利用完整平面+合理过孔分布(多层板推荐后者)
⑧ EN/PWM 逻辑输入加下拉防上电漂浮误触发
⑨ 使能/反馈分压下端就近接地孔
⑩ 输入 TVS/保险丝顺序：TVS 靠后级保护点
⑪ 多相并联 Buck 注意均流与相位交错布线对称
⑫ 预留 snubber RC 焊位(SW-GND 间)——EMI 整改的后悔药
```

## 2.3 纹波与瞬态的验收测量

```
纹波测量(复习PDN章并深化)：
- 探头接地弹簧必用；带宽限制 20MHz 开启看纹波，
  关闭看毛刺
- 测点：输出电容焊盘正负极直接搭接
合格判据参考：
  一般数字供电：±2%~3%
  RF/PLL/ADC基准：±1% 且无高频毛刺包

负载瞬态测试(比纹波更重要！)：
电子负载拉 0.1A↔满载方波(如 10kHz)：
观察 undershoot/overshoot 幅度与恢复时间
恢复波形形态诊断：
  单调快速恢复 → 环路稳定 ✓
  振荡几个周期 → 补偿临界，查 COMP/Rc
  长时间低伏 → 输出阻抗过大，查 Cout/Bulk
```

## 2.4 多轨系统的时序与耦合

```
FPGA/CPU 类多电平系统的经典需求：
核心先于 IO 上电(或按手册时序)否则闩锁损坏。

实现手段对比：
方案A PMIC(集成时序的多路电源芯片)：省心贵
方案B 使能链：前一级 PGOOD 接后一级 EN ★常用
方案C CPLD 统一控制：灵活复杂

PCB 配合：
PGOOD→EN 走线视为控制信号，远离 SW 节点
各轨软启动(SS脚电容)错开避免同时浪涌打趴输入
```

## 2.5 整改案例：一块板的 200MHz EMI 超标

```
背景：MP2315 方案，辐射测试 180~220MHz 超标 8dB
定位：近场探头发现 SW 节点与 Cin 回路区域热点最强
分析：Cin 布局距功率脚 6mm，热回路面积偏大，
     开关沿振铃频率恰落 200MHz
整改组合拳(按性价比排序执行到通过为止)：
① Cin 迁移至紧贴引脚(-5dB)
② SW-GND 间加 snubber 1Ω+1nF(-4dB)
   (代价：效率降 ~0.3%)
③ 若仍不够：换屏蔽电感 / 加共模磁珠于输入
结果：余量 6dB 通过
教训：布局期多花 30 分钟，整改期少熬三宿。
```
