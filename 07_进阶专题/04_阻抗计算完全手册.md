# 专题四 阻抗计算完全手册：所有结构一网打尽

> 理论篇讲透了原理，本手册是工具书：八种常见传输线结构的定义、适用场景、参数表与完整算例，以及与板厂沟通的标准格式。建议打印随身。

---

## 4.1 结构图谱总览

```
单端家族：
① 微带 Microstrip          外层走线，参考下层
② 埋式微带 Embedded        外层走线但表面有阻焊/覆盖层
③ 对称带状线 Sym. Stripline 内层，上下等距参考
④ 非对称带状线 Asym.       内层，上下距离不等
⑤ 共面 CPW                 同层两侧有地
⑥ 共面+地 CPWG             同层两侧地+下层参考 ★RF常用

差分家族(每种单端结构都有对应差分版)：
⑦ 差分微带 ⑧ 边缘耦合带状线 ⑨ 宽边耦合(少用)
```

## 4.2 各结构速查卡

### ① 微带 Microstrip

```
   ═════ w ═════      ← L1 (阻焊覆盖与否影响~1-3Ω)
    ─────────── h     ← PP
   ═══════════════    ← L2 参考平面

参数：w 线宽 / h 介质厚 / t 铜厚 / εr
特点：速度快(er_eff低)、易加工、辐射稍大
典型用途：外层通用信号、USB/MDI/HDMI直达段
JLC04161H 上 50Ω：w≈0.36mm(h=0.2104, 1oz)
```

### ③ 对称带状线 Symmetric Stripline

```
   ═══════════════    ← 上参考平面
    ───── h1 ─────    
   ═════ w ═════      ← 内层信号
    ───── h2 ─────    
   ═══════════════    ← 下参考平面

h1=h2 时为对称；速度慢约 15%(全介质包围)
EMC 最优、串扰最小
典型用途：六层的 L3 主力信号、SDRAM/DDR 走线
同叠层 50Ω：w≈0.15~0.18mm(比微带细!)
注意：内层铜厚常是 H oz(17μm)，计算时别填错！
```

### ⑤⑥ 共面波导族

```
   ○○○○○○○○○○○○○○○○  ← 缝合孔墙(间距≤λ/20)
   ═╦═══ w ═══╦════  ← 同层地——g ——地
    ──────────── h
   ═══════════════

g=间隙。有下层参考称 CPWG。
特点：场束缚好、对厚度容差不敏感、隔离好
典型用途：RF 馈线、板边高速接口
```

## 4.4 容差预算：±10% 从哪里来

```
总阻抗公差的构成因素：
- 蚀刻侧蚀导致线宽波动 ±10~15% → 影响 ~5%
- 层压厚度波动 ±10% → 影响 ~3%
- εr 批次波动 ±0.2 → 影响 ~2%
- 铜厚波动 → ~1%
合成(RSS) ≈ ±6~7%，工厂承诺 ±10% 是安全线。

推论：
±10% 够绝大多数数字协议；
RF 天线馈线要求 ±7% 或更严时要指定"阻抗加严工艺"加价。
设计时把目标定在标称值，不要故意偏移补偿——
工厂按标称生产，你的"小聪明"只会引入系统偏差。
```
