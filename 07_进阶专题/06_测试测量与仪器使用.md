# 专题六 测试测量与仪器使用：让板子开口说话

> 会设计还要会验证。本章覆盖硬件工程师的四大件：示波器、逻辑分析仪、万用表进阶、以及近场探头等 DIY 手段——每样都讲"买什么档位、怎么用才不骗你"。

## 6.1 示波器：选型与正确姿势

### 档位选择

| 级别 | 典型 | 带宽 | 够用场景 |
|------|------|------|---------|
| 入门手持 | DSO 拆机/百元级 | 10~20MHz | 慢速 UART/复位波形 |
| 桌面入门 | Rigol DHO802 类 | 70~100MHz | 本课程全部项目 ★推荐 |
| 进阶 | 200MHz+ 4通道 | 200M+ | HDMI 时钟/DDR 训练 |

### 带宽与上升时间的谎言链

```
示波器测得的 tr_meas² = tr_real² + tr_probe² + tr_scope²
带宽(BW) 与最快可测边沿：tr ≈ 0.35/BW
100MHz 示波器 → 最快分辨 ~3.5ns 边沿
→ 测 1ns 的 USB 高速边沿？根本看不清！
所以 HDMI/DDR 调试要 200MHz+ 起步。
```

### 探头的三个坑

```
坑一 接地长夹线：
   地线环感 ~100nH 级 → 在快速沿上振铃假象
   解法：接地弹簧(探头附件)或直接用刀片抵地
坑二 1x/10x 档位与补偿：
   换档后未校准补偿电容→方波变圆顶/过冲
   定期用板载校准方波调平
坑三 负载效应：
   1x 档输入电容 ~100pF，点在晶振上直接拉停振荡
   高阻节点一律 10x
```

## 6.2 逻辑分析仪：数字世界的广角镜

```
定位：示波器看"波形质量"，逻辑分析仪看"时序关系"
8~16 通道 USB LA(几百元级)足够本课程。

必杀技场景：
① 协议解码：SPI/I2C/UART 一键解析出十六进制
   ——调试传感器通信的第一神器
② 多线时序对齐：SDRAM 初始化序列的 CKE/RAS/CAS 关系
③ 长时间抓偶发：连续录几秒找那一次的异常帧

使用纪律：
地线就近多接(长地线=串扰串台)
采样率 ≥ 被测信号频率×5
阈值电平按被测电平设(3.3V 系统别用默认 TTL)
```

## 6.3 万用表进阶技能

```
四线毫欧测量? 普通表没有——但可以：
用恒流源+电压法测 PCB 走线压降定位大电流瓶颈：
例：3V3 平面上从入口到远端量得 15mV @2A
   → 分布电阻 7.5mΩ → 正常；
   若某段单独占 10mV → 该段是瓶颈(过孔太少)

真有效值的意义：测 Buck 输出纹波 RMS 时，
普通平均值的表会严重低估。

电容档的正确用法：
先放电再测！(带电测=烧表)
在线测不准(并联路径)，关键判断拆一头。
```

## 6.4 近场探头 DIY：EMC 排查神器

```
原理：小环形线圈拾取空间磁场(H场探头)，
     短棍状拾取电场(E场探头)
DIY：同轴线剥出一端做 5~15mm 直径环，
    焊屏蔽层留芯线，接到频谱仪或示波器FFT模式

用法三步：
① 全板扫描画"热力图"，锁定辐射热点
② 沿热点区域缩小环路精确定位到器件/走线
③ 改动前后对比量化 dB 改善
配合示波器 FFT 功能，零预算也能做 EMC 预排查。
```

## 6.5 电流测量的四种武器

| 方法 | 量程 | 特点 |
|------|------|------|
| 万用表串联 | mA~A | 精确但断路操作、无法看动态 |
| 采样电阻+示波器 | 视 R 值 | 看瞬态波形；R 上损耗与压降权衡 |
| 霍尔钳表 | mA~A | 不断路；小电流精度一般 |
| USB 功率计 | 0~3A | 整机能耗统计利器 |

瞬态电流观测示范(SDRAM 写突发)：

```
0.05Ω 串在 VDDQ 支路 → 示波器 20mV/div
看到每个写突发对应 30~60mA 的台阶脉冲
→ 这就是 PDN 章节所有理论的实物证据。
```
