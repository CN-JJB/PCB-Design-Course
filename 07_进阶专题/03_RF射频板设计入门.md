# 专题三 RF 射频板设计入门：2.4GHz 的世界

> ESP32 项目让你学会了敬畏天线净空，本章把 RF 前端的知识补全：传输线的射频应用、匹配网络、微带元件、混合信号隔离。目标是让你能看懂并复刻一颗合格的 WiFi/BT/Sub-G 模组底板。

---

## 3.1 射频视角的刷新：同一块板，两套物理

| 视角 | 数字工程师 | 射频工程师 |
|------|-----------|-----------|
| 走线 | 传输线(关心反射) | 传输线(关心损耗+驻波+辐射) |
| 电容 | 去耦储能 | 匹配元件/谐振器(关心Q值与自谐振) |
| 平面 | 回流路径 | 镜像地/腔体的一部分 |
| 过孔 | 不连续 | λ/20 级的"大障碍物" |
| 阻焊 | 无所谓 | 改变阻抗的介质层! |

2.4GHz 关键数字：

```
λ0 = c/f = 125mm
FR4 中 λg ≈ λ0/√εr_eff ≈ 60mm
λg/4 ≈ 15mm —— 一根 15mm 的悬空线就是天线！
临界长度概念在 RF 永远成立：一切按波长思考。
```

## 3.2 射频走线结构选择

```
共面波导 CPWG(Coplanar Waveguide with Ground)：
   ══════════════════ ← 同层两侧地
   ══ w ══            ← RF线
   ────────────────── h
   ══════════════════ ← 下层完整地 + 密集缝合孔

RF 板首选 CPWG 的原因：
- 两侧地孔墙把场"关进笼子"，抑制泄漏辐射
- 对叠层厚度误差容忍度更高
- 50Ω 线宽比纯微带更窄省面积
代价：计算复杂一点(Saturn 支持)、缝孔要密(<λ/20≈3mm@2.4G)

设计纪律：
- RF 线全程不打过孔不换层
- 缝合孔间距 ≤2~3mm(2.4GHz)
- 距其他任何铜 ≥3w
- 弯折用圆弧或大半径45°双切
```

## 3.3 匹配网络：把能量送进天线

### 为什么匹配

天线阻抗≠50Ω（尤其装进外壳后），失配→反射→驻波→辐射效率暴跌。π 型网络是标配：

```
信号源50Ω ──┬──[串联L]──┬── 天线
          [并联C]    [并联C]
            │           │
           GND         GND

Smith 圆图上沿等电阻圆和等电导圆交替移动到圆心。
新手不需要手推圆图，但要会：
① 用 VNA(矢量网络分析仪)测出原始 S11
② 用 SimSmith/appsmithry 类工具仿真出 L/C 初值
③ 实板焊接后微调(换不同值)迭代到 S11 < -10dB @工作频段
```

### 元件选型细节

```
匹配电容：C0G/NP0 材质！(X7R 的容值随偏压漂移=匹配漂移)
高频感：高自谐振频率的绕线或薄膜型，忌用磁珠替代
封装越小寄生越少：0402 起步，关键链路 0201
预留位技巧：串位焊 0Ω 可跳通，并位留 NC——
调试期自由度就是钱。
```

## 3.4 净空区与屏蔽腔的系统规划

```
模组/裸芯片 RF 输出到天线的完整净空链：
芯片RF脚 → π网 → 50Ω馈线 → 天线净空区

四层 RF 板典型叠层策略：
L1: RF 全部(含匹配件)
L2: 完整 GND(RF 参考生命线，绝无分割)
L3: 电源(各域分割+大量去耦)
L4: 控制信号(GSPI/I2C)

天线区三禁：
禁铜(所有层)、禁丝印大面积(油墨介电影响微但规范起见禁)、
禁结构件投影(螺丝/屏蔽罩边缘/电池)

外壳配合：
塑料壳距天线 ≥5mm 且该区域不能有金属喷涂层
(很多产品死于"金属漆外壳")
```

## 3.5 混合信号的隔离艺术

```
数字噪声源(MCU/SPI Flash) 与 RF 敏感区的隔离手段排序：

★★★ 物理距离：布局分区是最便宜的隔离
★★★ 地完整性：单一完整地平面(不要割地!
     "数字地模拟地单点连接"的老教条在现代多层板上
     已被 Rick Hartley 等权威反复纠错：
     割地制造回流断裂，害大于利；
     正确做法是完整平面+分区布局)
★★ 屏蔽墙：缝孔墙围 RF 区
★★ 电源隔离：RF LDO 独立+π滤波+大面去耦
★ 屏蔽罩：最后的大招(成本+返修代价)
```

## 3.6 发射功率与认证意识（工程边界）

```
做无线产品的合规红线：
SRRC(中国)/FCC ID(美)/CE-RED(欧) 认证
模组方案的价值再强调：用已认证模组+参考电路，
整机可走"模组化认证豁免"路径省下数十万认证费。

自己画 RF 的合规义务：
发射功率/杂散辐射/占用带宽逐项达标，
PCB 改版可能需要重测——这就是为什么量产 RF 版本
变更管理极其严格(哪怕只动了地孔)。
```
