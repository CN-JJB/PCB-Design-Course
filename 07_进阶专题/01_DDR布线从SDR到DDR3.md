# 专题一 DDR 布线：从 SDR 到 DDR3 的约束进化

> 项目六带你走完了 SDR SDRAM，本章把镜头拉远：DDR 系列的完整约束体系——拓扑进化、ODT、写平衡、DQS 选通、VTT 电源。这是高速布线的最高峰。

---

## 1.1 SDR → DDR 的代际差异总览

| 代际 | 数据率/引脚 | 关键新概念 | 布线难度 |
|------|------------|-----------|---------|
| SDR | ~166MT/s | 无 | ★★ |
| DDR1 | 200~400MT/s | 双沿采样、DQS选通、2.5V VDD | ★★★ |
| DDR2 | 400~800MT/s | ODT、 Posted CAS、1.8V | ★★★★ |
| DDR3 | 800~2133MT/s | **Fly-by 拓扑**、写平衡、1.5V、动态ODT | ★★★★★ |
| DDR4 | 1600~3200MT/s | Bank组、DBI、1.2V、点对点为主 | ★★★★★+ |
| LPDDR4X | 更高 | 更低摆幅、命令地址复用 | 极高(手机级) |

规律：速率翻倍 → 时序预算减半 → 拓扑从"多负载共享"走向"点对点"，等长要求从厘米级走向毫米级再到皮秒级预算。

## 1.2 拓扑进化史：理解 Fly-by 为什么出现

### T 型拓扑（SDR~DDR2 主流）

```
        控制器
       ┌──┴──┐
      CLK等长分支到每颗
   ┌──┴──┐ ┌─┴──┐
 芯片A   芯片B  芯片C
地址命令时钟到所有芯片，
每条支路严格等长(T型分叉对称)
```

问题：颗粒一多（服务器 4~8 颗），T 型的分叉树越来越难画，stub 越来越多。

### Fly-by（DDR3 标配）

```
CLK/ADDR/CMD/CTRL 像"串糖葫芦"依次穿过每颗芯片：
CPU ─→ A ─→ B ─→ C ─→ D (末端端接到VTT)

代价：每颗芯片收到的 CLK 有先后相位差
收益的兑现方式：控制器用"写平衡(Write Leveling)"
逐颗测量并补偿这个相位差。
→ 用可测量的延迟换取了布线的极大简化。
```

> 设计启示：Fly-by 不是免费午餐，它把"布线难度"转换成"控制器校准能力"。你的 CPU/MCU 必须支持 Write Leveling 才能玩 DDR3 多颗粒。

## 1.3 DDR3 完整信号分组与规则

```
┌─────────────┬────────────────────────────────┐
│ 组           │ 规则                            │
│ CK/CK# 差分  │ 120Ω? 标准: 差分100~120Ω按规范    │
│ DQ[7:0]+DQS± │ 一个字节组lane：组内 ±25mil级     │
│ DM(掩码)     │ 归入对应字节组                    │
│ ADDR/CMD/CTL │ fly-by链上相对CK匹配             │
│              │ (以第一颗为基准逐颗递增预算)        │
│ CKE/CS/ODT   │ 类似ADDR处理                     │
│ VREFCA/VREFDQ│ 参考电压走线短粗+就近去耦          │
└─────────────┴────────────────────────────────┘
```

### 字节组(Byte Lane)是 DDR 布线的基本单位

```
x16 颗粒 = 2 个 lane：
Lane0: DQ0-7 + LDQS± + LDM
Lane1: DQ8-15 + UDQS± + UDM

每个 lane 内部：
DQS 是"选通时钟"——数据在 DQS 中心采样
所以 lane 内等长的本质 = 保证每个 DQ 
相对自己的 DQS skew 最小化
(写方向靠控制器延迟补偿，读方向靠布线)
```

## 1.4 ODT 与端接策略

```
片内端接 On-Die Termination：
DDR2起端接电阻搬进了芯片内部，
通过寄存器配置 75Ω/60Ω/40Ω 等。

PCB 上还需要什么：
- VTT 电源(=VDD/2)：吸收端接电流的"下水道"
  x16颗粒满负荷时 VTT 电流可达数百mA！
- VTT 必须用独立 LDO(如TPS51200)供电，
  且输出电容紧贴颗粒群中心
- VTT 走线做成"平面岛"或粗网状铺在颗粒区下方
- VREF 电容布局：10nF+1μF 就近每颗芯片
```

## 1.6 调试：内存训练失败排查树

```
开机不识别 DDR3？
① 电源：VTT 精度±2%? VREF 在 VDD/2±1%?
② 时钟：示波器看 CK 差分幅度与交叉点
③ 配置：时序参数(tRFC/tFAW)是否超规格
④ 训练日志：读控制器 write-leveling 结果，
   若某 lane 全错 → 该 lane 物理问题
⑤ 温度相关性故障 → 端接不足或串扰
终极手段：眼图扫描控制器内置测试模式
```
