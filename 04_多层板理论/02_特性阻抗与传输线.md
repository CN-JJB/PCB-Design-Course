# 第二章 特性阻抗与传输线：把 50Ω 从咒语变成公式

> 高速世界的第一性原理。学完本章，你能解释为什么阻抗不连续会反弹信号、手算给定叠层的线宽、判断一根走线"算不算高速"、以及理解差分阻抗为什么不等于两倍单端。

---

## 2.1 从欧姆定律失效说起

低频时（线长 << 波长），一根导线就是导线——处处等电位，欧姆定律管够。但当信号沿走线传播时，事情变了：

```
低速场景(1kHz)：λ = c/f = 300km >> 板长
  → 整根线上电压几乎同时同值，"导线"成立

高速场景(边沿1ns，FR4波速15cm/ns)：
  信号前沿占据的空间 = 1ns × 15cm/ns = 1.5cm
  → 同一时刻线上不同位置电压不同！
  → 必须按"行波在介质中传播"来分析
  → "导线"升级为"传输线"
```

**临界长度判据**：

```
L_critical ≈ tr × v / 6      tr=上升时间，v=板内波速
FR4 中 v ≈ 15 cm/ns (= c/√εr)

例：tr=1ns 的信号 → Lcrit = 1×15/6 = 2.5cm
→ 走线超过 2.5cm 必须按传输线对待！
```

常见信号速查表：

| 信号 | 典型 tr | Lcrit | 管不管 |
|------|--------|-------|--------|
| 按键/LED GPIO | >100ns | >25cm | 随便走 |
| SPI 20MHz | ~4ns | ~10cm | 注意即可 |
| USB 全速 12M | ~8ns | ~20cm | 基本随意* |
| USB 高速 480M | ~0.75ns | ~2cm | ★必须管理 |
| 千兆网 MDI | ~1ns | ~2.5cm | ★必须 |
| HDMI TMDS | <0.3ns | <8mm | ★★严苛 |
| DDR3-800 | ~0.5ns | ~1.3cm | ★★严苛 |

*差分对仍建议规范走线以养成习惯。

> 关键认知：**决定高速与否的是边沿陡峭度 tr，不是时钟频率本身**。一个 8MHz 时钟若驱动器边沿只有 0.5ns，它就是高速信号。查 datasheet 的 rise time 参数，别只盯频率。

## 2.2 特性阻抗 Z0 的物理本质

### 直觉模型：无限长的梯子

把传输线切成无数小段，每段有串联电感 L 和并联电容 C：

```
  ──L──┬──L──┬──L──┬──
       C     C     C     （无限重复）
  ─────┴─────┴─────┴──

信号每前进一小步就要给该段的 C 充电，
充电电流由信号源持续提供。

Z0 = 电压/电流 = √(L/C)   （无损耗近似）
```

三个反直觉要点：

1. 单位是 Ω 但**不是电阻**——不消耗能量，只决定"充进去多少电流"
2. **与长度无关**——每一段都一样
3. 只由几何结构+材料决定——这就是为什么叠层一锁，阻抗就定了

### Z0 由什么决定（微带线）

```
   L1 ═══════ w ═══════    ← 走线宽 w
        ────────────── h   ← 介质厚 h
   L2 ═══════════════════  ← 参考平面

Z0 增大：w 减小 / h 增大 / εr 减小 / 邻近铜皮远离
Z0 减小：w 加大 / h 减小 / εr 增大 / 邻近铜皮靠近
```

灵敏度经验表（50Ω 微带附近）：

| 参数变化 | Z0 变化 | 工程含义 |
|---------|--------|---------|
| 线宽 w +10% | 约 −5% | 最常用调节手段 |
| 介质厚 h +10% | 约 +3~4% | 叠层锁定后不可动 |
| εr +5% | 约 −2.5% | 材料批次波动来源 |
| 铜厚 t +50% | 约 −2~3% | 影响小但存在 |

### 计算工具链

1. **Saturn PCB Toolkit**（免费）：w/h/t/εr 全参数，含差分耦合
2. **嘉立创阻抗计算器**：直接选他家标准叠层，与实际打样吻合度最高 ★打样首选
3. Polar Si9000：行业标准收费工具
4. KiCad 内置计算器：快速估算

## 2.3 反射：一切高速灾难的根源

### 反射系数

```
Γ = (Z_L − Z0) / (Z_L + Z0)

Z_L = 阻抗突变处下游看到的阻抗：
开路(∞) → Γ=+1   全反射同相
短路(0) → Γ=−1   全反射反相
2×Z0   → Γ=+1/3  部分反射
Z0     → Γ=0     完美匹配无反射 ★设计目标
```

### 振铃的形成过程

```
理想方波              失配后的实测波形
      ┌────┐             ┌─╲┌─╲┌──
      │    │             │ ╲╱ ╲╱
──────┘    └──────  ─────┘
                    ↑过冲(可能超芯片耐压)
                     振铃(多次穿越逻辑阈值→误触发)
```

时间轴推演（末端开路 Γe=+1，源头串阻匹配 Γs≈0，单程延迟 T）：

```
t=0    信号出发
t=T    到达末端全反射 → 末端瞬时电压接近翻倍
t=2T   反射回到源头被匹配电阻吸收 → 结束
末端波形 = 主阶跃 + 2T后的台阶叠加 → 一个过冲后稳定

若源头也不匹配 → 来回弹多次 → 连续振铃
```

### 终端匹配三板斧

| 方法 | 接法 | 适用 | 代价 |
|------|------|------|------|
| 源端串联（最常用） | 驱动器出口串 22~33Ω | 点对点 CMOS 标配 | 边沿略缓 |
| 并联下拉 | 末端对 GND 接 R=Z0 | 总线类 | 直流功耗大 |
| 戴维南 | 上拉+下拉到中点 | 已内置偏置的接口 | 功耗中等 |

> 为什么源端串联是 CMOS 世界标配？CMOS 输出阻抗约十几 Ω，加上 22~33Ω 串阻恰好接近 50Ω 走线；且零静态功耗。你的 STM32 GPIO 输出的每个稍长走线，都值得想想这颗电阻。

## 2.4 50Ω 的来历：一个工程折中

新手常问：为什么是 50Ω？不是 25 或 100？

```
历史与物理的双重答案：

① 功率容量最优：同轴结构在约30Ω时功率承受最大
② 损耗最低：   同轴结构在约75Ω时损耗最小
③ 折中取整：   (30+75)/2≈52 → 取50Ω作为通用标准
               75Ω 留给了电视/视频(长距离低损耗)

PCB 上沿用 50Ω 的原因：
- 器件厂商按此标定 IO 和测试夹具
- 板厂工艺在此线宽附近最成熟
- 形成了事实标准生态
```

各接口的阻抗标准速查：

| 接口 | 单端/差分 | 阻抗目标 |
|------|----------|---------|
| 通用单端数字 | 单端 | 50Ω ±10% |
| USB 2.0 高速 | 差分 | 90Ω ±10% |
| 千兆以太网 MDI | 差分 | 100Ω ±15%(建议±10%) |
| HDMI TMDS | 差分 | 100Ω ±15% |
| DDR3 数据组 | 单端(ODT管理) | 40~50Ω 视配置 |
| RF 2.4G 天线馈线 | 单端 | 50Ω ±5%(更严) |

## 2.5 差分对：成双成对的传输线

### 为什么用差分

| 优势 | 物理原因 |
|------|---------|
| 抗共模干扰强 | 外界噪声同时叠加到两线上，接收端只看差值→抵消 |
| 辐射小 | 两线电流反向，远处电磁场互相抵消 |
| 对参考平面不敏感（相对） | 信号"自己带回路" |
| 摆幅小也能工作 | 判决门限是零点，可用小摆幅省功耗提速 |

### 差分阻抗 ≠ 2 × 单端阻抗！

```
两根紧贴的线之间存在互感 M 和互容 Cm：

一根线单独：Z0 = √(L/C)
两根线反相驱动时：
  - 一根线的电流在另一根上感应出反向电动势
  - 等效于每根线看到的 L 变大、C 变大
  → 每根线的"奇模阻抗" Zodd < Z0
  → 差分阻抗 Zdiff = 2 × Zodd < 2 × Z0

数值感受（FR4 微带）：
  单独走 50Ω 的两根线，靠近到间距=1倍线宽：
  Zodd ≈ 43Ω → Zdiff ≈ 86Ω (不再是你以为的100Ω)

所以要得到 90Ω 差分(USB)：
  不是画两根50Ω线！而是按"差分90Ω"目标算出
  合适的线宽+间距组合（如 w=0.20mm, s=0.13mm，
  具体以计算器结果为准）
```

### 奇模/偶模——耦合的两种面孔

```
奇模 Odd Mode：两线等幅反相驱动（差分信号的工作模式）
偶模 Even Mode：两线等幅同相驱动（共模噪声的传播模式）

Zodd < Zeven 恒成立。
差分设计关心奇模；EMC 关心偶模(共模辐射主角)。

耦合度由间距决定：
s/w 越小 → 耦合越紧 → Zodd 越低、抗扰越好
但线越细阻抗越高 → 需要权衡出 (w, s) 组合
```

### 差分布线规则（理论依据版）

| 规则 | 数值 | 理论根源 |
|------|------|---------|
| 间距全程恒定 | — | 阻抗沿程一致，否则反射 |
| 紧耦合 | s ≈ 0.5~1×w | 增强抵消、抗共模 |
| 等长 | 见协议要求(±0.1~5mm) | 保证边沿同时对齐，skew 会转化为抖动 |
| 同时换层换拐角 | 对称操作 | 维持两线环境一致 |
| 远离其他信号 ≥3W | — | 差模场泄漏仍会串扰邻居 |

## 2.6 TDR 与阻抗验收：板厂怎么证明达标

下单勾选"阻抗控制"后，板厂会：

```
① 用他们的叠层参数复核你的线宽组合
② 生产时留出阻抗测试条(coupon)——复刻你的叠层和线型
③ TDR 时域反射仪测 coupon：
   往线里打一个快沿阶跃，采集反射波形
   反射系数随位置的变化直接换算成阻抗-距离曲线
④ 出具阻抗报告(横切面照片+实测表格)
⑤ 实测超差会主动联系你或重做
```

你收到的报告长这样（示例）：

```
Layer: L3 Stripline   Target: 50±10%
Test: w=0.36mm        Measured: 51.2 Ω  PASS
Coupon photo: [横切面显微镜照片]
```

> 【实用技巧】打样时把关键阻抗线型复制一小段放在板边的 coupon 区（或直接依赖板厂自动加的 coupon），收板后可自行测量验证。嘉立创六层以上默认附 impedance report，四层需勾选。

## 2.7 阻抗控制的完整工作流（预告实操）

理论到此为止，实际设计的闭环是：

```
① 定叠层(上一章) → 拿到每层的 h/t/εr
② 查协议要求 → 得到目标阻抗表(如 USB=90Ω差分)
③ 计算器反解 → 得到每类的 (w, s)
④ KiCad Net Class 写入规则(第五部分实操)
⑤ 布线严格按规则
⑥ 下单勾选阻抗控制+填目标表
⑦ 收板核对 impedance report
⑧ 有条件的话示波器/TDR 复测关键网络
```
