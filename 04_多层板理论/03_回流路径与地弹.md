# 第三章 回流路径与地弹：多层板的灵魂

> 这是全课程最重要的概念，没有之一。90% 的"高速玄学问题"——莫名其妙的 EMI 超标、串扰、抖动——根源都是回流路径断裂。本章把电流回家的路彻底讲透。

---

## 3.1 一个颠覆直觉的事实：回流不在你想的地方

问：信号从 A 芯片出发经走线到达 B 芯片，电流怎么回到 A？

小白的回答：沿着地线/地平面随便流回去。

真相：**电流是一个闭合回路，回流的路径由频率决定**：

```
直流 / 低频(<~10kHz)：
  回流走电阻最小的路径 → 在整个地平面上均匀铺开
  （像水漫过平原）

高频(>~100kHz，边沿快的数字信号全是此类)：
  回流走环路电感最小的路径 → 紧贴信号线正下方的
  参考平面上往回流动（像水流沿河床）
  
为什么？高频回路中，环路的磁场储能=环路电感，
环路面积越大电感越大、阻抗越高。
紧贴布线的往返路径围成的环路面积最小。
物理定律自动选择最小环路路径。
```

### 回流密度的分布形状

参考平面上回流不是一条细线，而是一个高斯型分布：

```
俯视图：                    剖面图：
  ═════════════════        平面电流密度
   ↑↑↑↑↑↑↑↑↑↑↑↑            ▲
      ████████ ←信号线       │    ██
      ███████              │  ████
                            │██████
  集中在 ±3h 内(h=介质厚度)  └────────→ 横向距离
```

- 约 **94% 的回流集中在信号线正下方 ±3h 宽度内**
- 这就是 **3W 规则**（线间距≥3倍线宽可降串扰70%）和 **20H 规则** 的物理根源
- h 越薄，回流越集中，串扰越小——这就是为什么多层板介质越薄越好

## 3.2 五大断裂场景：逐个解剖

### 场景一：跨分割缝（最经典）

信号从 L1 出发，L2 是 GND 平面但被分割成 GND 和 PWR 两块：

```
L1:  A ●━━━━━━━━━━━━━━━━━━● B
          ↓ 高频回流想紧贴下方
L2:  [GNNND][缝!][PPWR]
          ✗ 回流被切断！

后果三连：
① 回流被迫绕行分割缝边缘 → 环路面积暴涨
② 环路面积↑ → 电感↑ → 该处呈现高阻抗
③ 大环路 = 一圈天线 → 对外辐射飙升 + 更容易接收干扰
   同时该信号对邻居的耦合也变强(串扰)
```

修复方案排序：

| 方案 | 做法 | 代价 |
|------|------|------|
| ★改道 | 让信号绕开分割缝 | 线长增加 |
| ★改层序 | 分割只放在远离信号的层 | 规划期决策 |
| 缝上跨接电容 | 分割缝两侧放 0.01μF 跨接 | 只救特定频段，且引入新问题 |
| 改叠层 | PWR 不与 SIG 同参考关系 | 早期设计 |

> 【设计铁律】布局阶段就要检查每个高速网络的投影路径下方是否全程有完整参考平面。KiCad 里切到平面层视图，肉眼核对。

### 场景二：换层不换参考（过孔回流）

信号从 L1 打过孔到 L4：

```
L1: ●━━━┓
         ┃via
L4:      ┗━━━●
回流呢？
若 L2=GND 且 L3=GND：
  回流从 L2 经"就近的GND过孔"到 L3 再跟随
  
关键规则：换层的信号过孔旁边 ≤3h 距离内
必须有一个 GND 过孔伴飞！(工程经验值≤1mm)

没有伴飞孔时，回流被迫绕到最近的过孔，
环路面积增大，等效于一个小的跨分割。
```

实操纪律：**每根换层的高速线，旁边立刻补一颗 GND 过孔**。低速线可以放宽到几 mm 内有一颗即可。

### 场景三：参考平面在 GND 与 PWR 之间切换

四层板 TOP-GND-PWR-BOTTOM 中，信号从 TOP(L1, 参考 GND) 打孔到底层(L4, 参考 PWR)：

```
回流路径断点分析：
去程：L1 → via → L4
回流：GND平面 → ??? → PWR平面

两个不同网络(GND/PWR)之间直流不通！
高频下唯一通路 = 就近的去耦电容
   GND ─┤├─ PWR
   
所以底层信号的实际回流绕道了某颗去耦电容！
如果那颗电容很远(5mm外)，环路面积巨大。
```

结论：**方案 A 四层板的底层不适合走重要高速线**；要高速就放顶层，或者选六层让所有信号层都邻 GND。这解释了第一章叠层章埋下的伏笔。

### 场景四：连接器出板边

信号离开 PCB 进入电缆的那一刻，回流怎么办？

- 屏蔽电缆（USB/网线）：回流走屏蔽层——所以连接器外壳必须大面积接 GND，且电缆屏蔽与机壳地良好搭接
- 无屏蔽排线（UART 杜邦线）：回流没有专用通道 → 共模电流通过空间杂散电容回家 → 排线变成辐射天线（EMC 章节的主角剧情）

设计动作：接口连接器周围打密集 GND 过孔墙，把平面引到最贴近连接器引脚处。

### 场景五：晶振与时钟线下方的地被挖穿

时钟是周期性信号，能量集中在基波和谐波，一旦它的回流路径受损，辐射是"梳状谱"一根根竖起来的超标尖峰。晶振下方走线 = 自杀式布局，前文反复强调的原因至此完整闭环。

## 3.3 地弹 Ground Bounce 与 SSN

### 机理推演

芯片内部几十个 IO 同时从 1→0 翻转，所有灌电流都要经过芯片的地引脚流出：

```
设芯片内部接地路径电感 Lg ≈ 1nH(封装+引脚)
8个IO同时翻转，各驱动 10mA/ns 的 dI/dt
总 dI/dt = 80mA/ns

地弹电压 V_bounce = Lg × dI/dt 
                  = 1nH × 80mA/ns = 80mV

看起来不大？放大场景：
32位总线 + 边沿0.5ns + 20mA/ns每脚
dI/dt = 640mA/ns → V = 640mV ≈ 地电位瞬间抬升0.64V！

此时芯片内部的"地"比板上地高出0.64V：
- 输出低电平被抬高，接收端可能误判为高
- 输入端的噪声容限被吃掉
→ 这就是同步开关噪声 SSN
```

### 对策清单

| 层面 | 措施 |
|------|------|
| 封装选择 | 同功能优先选引脚多的封装(电源地引脚多=L小)；BGA 天然优于 QFP |
| 软件配合 | 总线翻转控制(bus hold/slew rate 降档) |
| PCB | 每个电源/地引脚独立过孔，禁止两脚共用一孔 |
| 系统 | 关键 IO 分散在不同 bank 翻转时刻 |

## 3.4 回流路径的设计期检查法

DRC 不会帮你查这个！人工+半自动手段：

```
① 投影审查法(必做)：
   切到每个平面层视图 → 逐条检查高速线的正下方
   是否连续同网络铜皮
   
② 过孔伴飞审查：
   数一遍换层的高速线，确认旁有GND过孔

③ 敷铜后目检孤岛：
   找出平面上的细颈/缝隙区域(过孔群连排处)

④ 极端情况仿真：
   开源 openEMS 或商业 SI 工具抽取实际回流分布
   学习阶段不必，概念清晰即可预防99%的问题

⑤ 实测验证(板子到手后)：
   近场探头扫板找热点；EMC暗室看超标频点对应哪根线
```

## 3.5 综合案例：一次真实的 EMI 超标整改

背景（教学虚构但典型）：一块 STM32+以太网板，30MHz~1GHz 辐射测试在 168MHz 超标 6dB。

排查过程：

```
168MHz 从哪来？72MHz 主频的 PLL 输出 168MHz？查时钟树：
ETH RMII 需要 50MHz REF_CLK……
50MHz×? 不是168。再看：SDIO 时钟 84MHz 的二次谐波=168MHz ✓

定位：SDIO 走线附近用近场探头确认辐射热点
发现：SDIO_CMD 为省空间打了过孔换层，旁边没有地孔，
且换层前后参考平面分别是 GND 和 PWR(分割区)
→ 回流绕行 8mm 外的去耦电容 → 大环路天线

整改(不动原理图)：
① SDIO 三根线全部重走在顶层不换层
② 时钟源输出端加 33Ω 串阻放缓边沿(-15dB 谐波幅度!)
③ 连接器旁补缝合孔
复测：168MHz 下降 11dB，余量充足 PASS
```

三条教训对应本章三个知识点：换层回流、串阻控边沿、缝合孔。**EMC 问题在设计期解决成本为零，在测试期解决要改版。**
