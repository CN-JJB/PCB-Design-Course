## 6.1 过孔的完整解剖

### 寄生参数全模型

```
一个过孔 = 桶壁电感L + 桶壁电容C + 焊盘电容 + 残桩stub

经验公式(h=板厚inch, d=孔径inch)：
L_via ≈ 5.08 × h × [ln(4h/d) + 1]  nH
C_via ≈ 1.41 × εr × T × D1/(D2−D1)  pF
        (T=板厚mil, D1=焊盘, D2=反焊盘隔离孔径)

数值感受(1.6mm板厚, 0.3mm孔)：
L ≈ 1.2 nH    C ≈ 0.5~0.8 pF

影响评估：
- 对 50Ω 系统：单个过孔≈一个微小阻抗扰动
  480Mbps USB：可忽略~轻微；3Gbps HDMI：必须认真对待
- 电感在电源路径上放大纹波(去耦章已讲)
- 电容在阻抗上造成轻微下坠(容性不连续)
```

### 残桩 Stub：隐藏的谐振陷阱

```
六层板信号从 L1 打到 L4，通孔却打穿到 L6：

L1 ●━━━┓
        ┣━━━━━━━━━━━━━━┓ ← L4 接信号
        ┃                ┃
       stub!             ┗ L5/L6 方向的多余段
        
残桩 = 一根开路支线：
- 高频下像"三岔路口"，部分能量进入残桩
- 到达开路末端全反射回来 → 与主路叠加
- 当残桩长度 ≈ λ/4 时反射同相叠加最凶 → 频率响应凹陷

危险频率估算：
f_notch ≈ v / (4×L_stub)
FR4 v≈15cm/ns，残桩1.0mm→ f≈37GHz(安全)
残桩 8mm → f≈4.7GHz(HDMI 3.4Gbps 已受威胁!)

对策排序：
① 布线规划避免深层换层(短距离用浅层对)
② 板厚大+速率高 → 指定背钻工艺(贵)
③ HDI 用盲孔天然无残桩(更贵)
学习项目通孔即可，但要建立"残桩意识"：
高速线换层尽量选靠近目标层的层对。
```

## 6.2 串扰：邻居的噪声是怎么爬过来的

### 两种耦合机理

```
容性耦合(电场)：侵略者的 dV/dt 通过互容 Cm 
               在受害者上注入电流
感性耦合(磁场)：侵略者的 dI/dt 通过互感 Lm 
               在受害者回路感应电压

近端串扰 NEXT：回到受害者源端(往回传)
远端串扰 FEXT：传到受害者远端(继续往前)

FR4 微带线上两者量级相近；
带状线上 FEXT 因屏蔽显著小于 NEXT。
```

### 影响因素与量化

| 因素 | 影响 | 数值感受 |
|------|------|---------|
| 间距 s | 主导变量 | s 从 1w→2w，串扰约降一半；→3w 再降 |
| 平行走线长度 | 累积效应 | 平行越长 NEXT/FEXT 越大 |
| 边沿速度 | 正比 dV/dt | 同样布线，快沿芯片串扰翻倍 |
| 参考平面距离 h | 回流集中度 | h 小则场束缚好、串扰小(多层优势) |

**3W 规则的本质**：线中心距 ≥3w 时，典型叠层下串扰可压到 −70% 左右。它不是魔法数字，是高斯回流分布(第三章)的直接推论。

### 包地 Guard Trace 的真相

```
流行观点：在两根线之间加一根接地的保护线能隔离串扰。

实验事实(业界共识)：
- 保护线只在【多点接地】时才有效！
- 一根悬空或单点接地的保护线反而成为新的
  耦合通道(它的谐振会把能量再辐射给受害者)
- 有效条件：缝合孔间距 < λ/20@关心频率
  对 500MHz 场景即 <15mm——密集打孔后才有意义

结论：
低速板：与其包地不如拉开间距(3W成本更低效果好)
高速敏感线：包地+密缝孔墙 = 屏蔽走廊，有效但费面积
```

### 屏蔽墙 Shield Wall

沿敏感区域边缘打一排密集 GND 过孔（间距 ≤λ/20）：

```
 ╔══════════════════╗
 ║ ○○○○○○○○○○○○○○○○ ║ ← 过孔墙
 ║   [敏感区:晶振/RF]  ║
 ║ ○○○○○○○○○○○○○○○○ ║
 ╚══════════════════╝
配合顶层敷铜构成"半封闭法拉第笼"
RF 模组周围的标准操作(项目3实战应用)
```

## 6.3 AC 耦合电容：高速串行的标配细节

千兆网/HDMI/PCIe 采用交流耦合（隔直电容串联在线中）：

```
布局规则：
① 放在接收端附近(协议惯例，如以太网规定收端)
② 两颗电容对称摆放，差分两线同时经过
③ 封装选 0402 且焊盘出线无Stub
④ 电容本体造成阻抗微降(容性)，选小封装减小扰动
⑤ 不允许打过孔(保持参考连续)

原理一句话：隔断直流偏置让收发两端各自偏置自由，
           电容与两侧走线构成高通网络，
           截止频率须远低于信号基频。
```

## 6.4 时钟的特殊照顾清单

时钟是频谱污染源之首（能量集中在基波+谐波，梳状谱根根致命）：

```
布局
[ ] 晶振紧贴芯片、下方净空(全课程反复出现)
[ ] 时钟输出远离 I/O 区和电缆 ≥20mm
[ ] 时钟线走在内层(带状线)最佳
布线
[ ] 长度最小化，不打或少打过孔
[ ] 3W 以上间距，必要时包地走廊
[ ] 串阻 22~33Ω 就近放在驱动端
系统级
[ ] 有扩频时钟(SSC)功能的启用之：
    把窄带尖峰摊成宽带矮丘，峰值轻松降 5~15dB
[ ] 不用的时钟输出门控关闭
[ ] 分配时钟树时避开长总线扇出
```

## 6.5 参考平面切换的缝合电容

回流章节讲过 GND↔PWR 参考切换的问题。当不得不这样切换时：

```
缝合电容 Stitching Capacitor：
在换层过孔旁放一颗 0.01~0.1μF 电容跨接两个参考平面
(GND 与 PWR)，为高频回流提供桥。

摆放纪律：
- 距离换层过孔 <2mm
- 每个换层点一颗(不能几条线共用远处一颗)
- 电容自身安装电感要低(双孔落地)

优先级提醒：
能用"全程 GND 参考"就永远别制造需要缝合电容的场景。
它是补救手段，不是常规武器。
```

## 6.6 高速接口约束速查总表

本课程涉及及常见接口的设计要求一页纸总结（具体数值以各协议规范和芯片手册为准）：

| 接口 | 速率级 | 阻抗 | 等长要求 | 特殊处理 |
|------|--------|------|---------|---------|
| UART/SPI ≤50MHz | 低速 | 无要求 | 无 | 串阻可选 |
| USB 全速 12M | 低速 | 宽松 | <5mm | 差分并行即可 |
| USB 高速 480M | 中速 | 90Ω差 ±10% | <1.5mm? 实践<1mm | 90Ω+共模电感预留 |
| RMII 50MHz | 中速 | 单端50Ω宽松 | CLK等长±2.5mm 内 | REF_CLK 星型分配 |
| 千兆 MDI(网变后) | 高速 | 100Ω差 ±10% | 组内<0.5mm | Bob Smith 端接 |
| RGMII 125MHz DDR | 中高速 | 50Ω | CLK→数据 ±0.25ns | 源同步需按 tCO 补偿 |
| HDMI TMDS | 高速 | 100Ω差 ±10% | 组内 ±0.1mm 级 | 三对数据+一对时钟组间 ±5×组内 |
| DDR3-800 数据组 | 高速 | 40~50Ω | fly-by/拓扑规则多 | 专题见项目6 |
| SDIO 50MHz | 中速 | 宽松50Ω | CMD/DAT 相位余量大 | 上拉配置正确 |

## 6.7 眼图：把所有概念合成一张图

高速验收的终极图形语言：

```
示波器无限余辉叠加无数个比特的眼状轨迹：

      ____          ____
     /    \        /    \      ← "眼皮"(最大摆幅)
    /      \______/      
   /      /      \        
  ━━━━━━●━━━━━━━━●━━━━━  ← 判决电平交叉点
   \      \______/        /
    \                    /   ← "眼睛"张开=质量好
    
眼睛闭合的原因对应关系：
眼皮变薄   → 损耗(ISI码间干扰)
交叉点模糊 → 抖动Jitter(反射/串扰/SSN)
上下不对称 → 占空比失真
整体塌陷   → 阻抗失配链式反射

你学过的每一章都在这只眼睛里留下了痕迹。
```
