# 第一章 叠层设计基础：多层板的"楼层规划"

> 叠层（Stackup）是多层板设计的第一个决策，也是影响最深远的决策：它决定了阻抗、回流质量、EMC 表现、成本和可制造性。本章从材料物理讲到具体方案选型，学完你能为任何需求排出正确的层。

---

## 4.1 为什么需要多层板——从二层板的痛说起

回顾你在二层板上经历的挣扎：

| 二层板的痛 | 根源 | 多层板的解药 |
|-----------|------|-------------|
| 地被走线切得稀碎 | 只有 2 层铜可用 | 专用完整 GND 平面 |
| 电源线绕来绕去压降大 | 电源也要占走线资源 | 专用 PWR 平面 |
| 布线拥挤互相让位 | 走线空间不足 | 每个信号层独立布线 |
| 高速信号回流路径混乱 | 无邻近参考平面 | 每个信号层紧邻平面 |

一句话总结：**多层板用"专层专用"换取信号完整性、电源完整性和 EMC 的全面提升**。代价是成本上升——四层板约为二层板的 2~2.5 倍。

判断标准速查：

```
以下情况直接上四层：
- 有 >50MHz 时钟或 >100Mbps 接口
- 板上有 RF/WiFi/BT
- 元件密度高到二层布不开
- 产品要过 EMC 认证且不想整改

以下情况六层起步：
- DDR2/3 内存
- 千兆以太网/HDMI/LVDS
- 多路高速接口并存
- 密度极高(BGA 0.8mm 以下)
```

## 4.2 材料体系：叠层的"建材清单"

### FR4 的构成

FR4 不是单一物质，而是玻璃纤维布浸渍环氧树脂压制而成：

```
玻璃纤维布（骨架）+ 环氧树脂（肉） + 固化剂等添加剂
        ↓
   影响介电常数 εr     ↓
                      影响树脂含量(影响厚度)
   
常用玻纤布型号（数字代表编织规格）：
7628 布：粗厚，含胶量低 → 做厚介质(约0.18mm)
2116 布：中等 → 约0.12mm  
1080 布：细薄，含胶量高 → 约0.07mm
106 布：极细 → 约0.05mm
```

> 【为什么关心玻纤布】①它决定每层介质厚度，直接影响阻抗；②玻纤有编织空隙，极高频(毫米波)时 εr 会随位置波动（纤维效应）——GHz 以上要用平整化材料或旋转布纹。学习阶段记住前一条即可。

### 关键参数表

| 参数 | 普通 FR4 | 中损耗(如 IT180A/S1000-2) | 高速板材(M6/Megtron6) |
|------|---------|--------------------------|----------------------|
| εr @1MHz | 4.2~4.7 | ~3.9 | ~3.6 |
| tanδ @1GHz | 0.02 | 0.012 | 0.002~0.005 |
| Tg | 130~140℃ | 150~170℃ | 180℃+ |
| 相对价格 | 1× | 1.5~2× | 5~10× |
| 适用 | <1GHz 大多数场景 | 千兆网/DDR3 够用 | >5Gbps 必须用 |

结论先行：**嘉立创打样的普通 FR4 完全胜任本课程全部六个项目**（最高速率 HDMI 3.4Gbps 用普通 FR4 打样可行，量产才考虑升级板材）。知道何时该换料比盲目上贵料重要。

### 芯板 Core 与半固化片 Prepreg

这是理解叠层数值的关键概念：

```
芯板 Core：工厂买来时就已是"两面覆铜的硬化板材"
          厚度固定(如0.21mm)，铜箔已压合，不可压缩
          
半固化片 PP：未完全固化的树脂+玻纤布，本质是"胶水"
           压合时熔化流动→填充间隙→固化粘接各层
           最终厚度取决于压力和树脂流出量(约±10%公差)

四层板结构 = 铜箔 + PP + 芯板 + PP + 铜箔
              L1      L2=L3的载体    L4
              
内层(L2/L3)图形在芯板上蚀刻，
外层(L1/L4)在压合后的外表面铜箔上蚀刻。
```

### 铜厚体系再认识

| 标称 | 公制 | 用途 |
|------|------|------|
| H oz (0.5oz=17μm) | 内层常见 | 内层走线足够 |
| 1 oz (35μm) | 外层默认 | 兼顾精细与载流 |
| 2 oz (70μm) | 大电流 | 电源层/功率板 |

注意：内层用 H oz 是行业惯例（省成本），载流靠内层大面积平面而非走线宽度。阻抗计算时必须填对应铜厚！

## 4.3 对称原则与翘曲控制

**铁律：叠层关于中心面（中轴）上下镜像对称。**

```
对称的四层板：                不对称的反例：
L1 铜 35μm                   L1 铜 35μm
PP 0.21                      PP 0.50    ← 上厚下薄
Core 0.71                    Core 0.71
PP 0.21                      PP 0.11    ← 
L4 铜 35μm                   L4 铜 70μm ← 铜也不对称

不对称后果：压合冷却时上下收缩率不同
→ 板子翘曲成"薯片"(banana/warpage)
→ SMT 贴片偏移、BGA 虚焊、插不进机壳
```

翘曲标准：IPC-TM-650 允许 ≤0.75% 对角线翘曲，但贴片厂希望 ≤0.5%。对称设计天然满足。

其他对称性细节：

- 铜分布也尽量对称：若 L1 有大片敷铜，L4 对应位置也应有相近铜量（软件里看铜密度）
- 四层板的标准结构天然对称，无需操心；八层以上自己排层时要时刻检查

## 4.4 四层板方案大全

### 方案 A：TOP - GND - PWR - BOTTOM（最经典）

```
L1 SIG ─┐ 微带线，参考 L2 GND，阻抗好算好控
L2 GND ─┤ 完整地平面，全板回流基石
L3 PWR ─│ 电源平面(可分割多轨)
L4 SIG ─┘ 参考 L3 PWR —— 注意！参考的是电源不是地
```

优点：结构简单、两层都有紧邻参考、成本最低。
缺点：**L4 的参考平面是 PWR**，信号回流要经去耦电容跨到 GND（第四章详解这个隐患）；PWR 平面离 GND 平面的耦合电容较小。

适用：低速为主、少量中速信号的通用板。**嘉立创免费四层叠层的默认形态**。

### 方案 B：TOP - GND - GND - BOTTOM（双地层）

```
L2 和 L3 都是 GND，两平面间形成平板电容，
高频阻抗极低；L1/L4 都参考 GND。
```

优点：EMC 极佳，两信号层参考一致。
缺点：没有电源平面，所有电源走粗线（回到二层板的电源方式）。
适用：模拟/混合信号小系统、RF 前端板、对电源轨数量少但质量要求高的场合。

### 方案 C：TOP - PWR - GND - BOTTOM

与 A 镜像，无实质差异，个别厂家的默认顺序而已。同样存在底层参考 PWR 的问题。

### 四层方案决策树

```
电源轨 ≤2 种 且 EMC 要求高？ → 方案 B
常规嵌入式(1种主电源+若干LDO)? → 方案 A ★80%的选择
有敏感模拟区？ → 方案 A + 分割 PWR 平面给模拟单独区域
```

### 实际数值示例：嘉立创 JLC04161H 系列

打样最常见的免费四层叠层（数值以厂家最新公布为准，此处为典型值展示量级）：

| 层 | 名称 | 材料 | 厚度(mm) |
|----|------|------|---------|
| L1 | TOP 信号 | 铜箔 35μm(1oz) | 0.035 |
| — | 介质 | PP 2116 | 0.2104 |
| L2 | GND | 内层铜 17μm(H oz) | 0.0175 |
| — | 芯板 | Core | 0.71 |
| L3 | PWR | 内层铜 17μm | 0.0175 |
| — | 介质 | PP 2116 | 0.2104 |
| L4 | BOTTOM | 铜箔 35μm | 0.035 |

总板厚 ≈ 1.62mm ≈ 标准 1.6mm。

用这些参数算 50Ω 微带线（L1）：h=0.2104mm，εr≈4.4，t=35μm → 线宽约 **0.36mm**。这个数字第五章会用 KiCad 算一遍。

## 4.5 六层板方案深度对比

六层是"真正的多层板设计"起点，方案选择直接影响成败：

### 方案一：SIG - GND - SIG - PWR - GND - SIG ★经典推荐

```
L1 SIG  ─ 参考 L2 ✓
L2 GND  ┐
L3 SIG  ┘ 两信号层夹在两个平面之间=带状线，屏蔽最好
L4 PWR
L5 GND  ┐
L6 SIG  ┘ L6 参考 L5 ✓；L4/L5 构成平板电容
```

优点：
- 三层布线空间，其中 L3 是完美带状线环境
- 两个完整地平面，EMC 一流
- L4/L5 平面对提供额外高频去耦

缺点：L4 的 PWR 与 L3 之间隔了个……不对，L3 参考 L2 GND，很好。真正缺点：电源平面只有一个，多电源域需在 L4 分割。

**适用：绝大多数六层需求，本课程项目 4/5/6 的主力方案。**

### 方案二：GND - SIG - SIG - PWR - GND - BOTTOM? 

非主流排列，问题在于相邻的两个信号层（L2-L3）互相串扰严重且都只有单侧参考——除非正交布线（一层横一层竖），否则不推荐新手。

### 方案三：SIG - GND - SIG - GND - PWR - SIG

把 L4 也给 GND，电源走粗线。适合电源种类少、信号质量要求极高的板（如纯高速数字背板思路）。缺点同方案二里的电源处理负担。

### 六层方案决策要点

```
问自己三个问题：
① 需要几种独立电源域？>2 种 → 方案一里认真做分割，
   或考虑八层加一个 PWR 层
② 最快的信号是什么？
   ≥1Gbps 的尽量放 L3 带状线（两侧屏蔽）
③ EMC 目标等级？
   Class B(家用严格) → 必须保证每个信号层都有紧邻 GND
```

## 4.6 八层及以上：一眼看懂

```
典型高性能八层：
L1 SIG / L2 GND / L3 SIG / L4 GND
L5 PWR / L6 GND? 
标准排法：SIG-GND-SIG-GND-PWR-GND-SIG-GND 或
         GND-SIG-GND-SIG-PWR-SIG-GND-SIG
核心思想不变：信号永不远离参考，
            GND 数量 ≥ SIG 层数。
```

十层以上出现于服务器/交换机，配合盲埋孔 HDI 工艺，超出本课程范围。你需要的核心认知：**层数增加的本质是增加"参考平面"和"布线资源"，而不是单纯堆信号层**。

## 4.7 盲埋孔与 HDI：概念与成本直觉

| 孔类型 | 工艺轮次 | 成本倍率(相对通孔) | 何时用 |
|--------|---------|------------------|--------|
| 通孔 Through | 钻一次 | 1× | 默认 |
| 盲孔 Blind(L1→L2) | 先钻后压合再钻 | +30%~60% | BGA 逃逸、手机级密度 |
| 埋孔 Buried(L2→L3) | 压合前后两次钻孔 | +40%~80% | 密度极限时 |
| 微孔 Microvia(激光) | 激光逐层堆积 | 更高 | HDI 手机主板 |

经验法则：**能用通孔解决就不上盲埋孔**。BGA 0.65mm 以下间距才开始考虑。本课程全部项目用通孔即可完成。

## 4.8 平面层的设计纪律

平面层虽是"整片铜"，也有讲究：

### GND 平面的三条军规

1. **绝不走线穿过**——每一根穿过的线都在平面上挖沟，切断下方信号的回流路径（第三章详述）
2. **过孔密集区的"防孤岛"意识**——大量过孔挨太近会形成连续挖空带，等效于开槽；DRC 无法发现这种"合法但有害"，靠眼睛和间距纪律（缝合孔保持 ≥0.5mm 间距一般安全）
3. **板边处理**——GND 到板边留 0.5mm 左右（比普通铜到边略宽），边缘一圈不打元件

### PWR 平面的分割规则

```
分割 = 把一块整铜切成几个互不相连的区域，各自接不同电压

┌──────────────────┐
│ +3V3 区域          │
│      ┃ 0.5mm隔离缝 │
│      ┃            │
│ +1V8 区域 │ +5V 区 │
└──────────────────┘

铁律：
① 不同电压区域之间的缝隙 ≥0.5mm(耐压考虑)
② 信号绝不允许跨越分割缝！(第四章回流章节解释为什么)
③ 每个区域的形状尽量方正，避免狭长半岛
④ 去耦电容骑在分割缝两侧的器件供电处
⑤ 分割边界优先用直线，KiCad 里画 Zone 边界即得
```

### 负片层（Negative Plane）了解

老牌 EDA 和部分 Gerber 流程支持"负片"表达：图形表示的是挖空区域而非铜本身，文件更小。KiCad 统一用正片表达，你只需知道这个词在看老文档时指什么。

## 4.9 从需求到叠层：完整决策流程

拿到新项目时的思考链：

```
Step1 列出接口与时钟清单 → 找出最快的信号
Step2 数电源域数量 → 决定要不要独立 PWR 层
Step3 估算布线规模(网络数×平均长度) → 决定信号层数
Step4 对照成本预算 → 定层数上限
Step5 选定方案模板(4.4/4.5节) → 按对称原则微调
Step6 向板厂索取该方案的叠层参数表(或用其官网计算器)
Step7 把参数填入 KiCad Board Setup(下一部分手把手)
Step8 用参数算出各层目标阻抗线宽 → 写入 Net Class 规则
```

案例演练：ESP32 底板

```
最快信号：USB 全速 12Mbps + WiFi 模组板载天线(不算板内信号)
时钟：外部 40MHz 晶振(模组内置)
电源域：5V输入、3.3V 主力、(模组峰值电流大)
布线规模：中等，GPIO 引出较多
→ 结论：四层方案A(TOP-GND-PWR-BOT)，
  PWR 层分割出模组专属 3.3V 大区域+其余区域。
  成本最优，性能足够。
```
