# 第四章 电源完整性 PDN：电容为什么永远不够用

> 芯片要的是"无论何时伸手都有干净的电"。本章讲清楚：为什么 VRM 帮不上高频的忙、目标阻抗法五步设计流程、电容的真实嘴脸（不是你以为的那个电容）、以及安装方式比容量更重要的残酷真相。

---

## 4.1 问题的本质：需求与供给的频段错位

```
芯片对电源的需求随时间变化的频谱：

负载电流瞬变：dI/dt 可达 A/ns 级
→ 需求能量集中在 高频段(MHz~数百MHz)

而供电系统的各个成员各管一段频段：

DC-DC/LDO (VRM)：只能响应 kHz~MHz 级变化
  （环路带宽限制，典型 10kHz~1MHz）
大电解电容：    mHz~kHz 段的蓄水池
陶瓷去耦电容：  MHz~百 MHz 段主力
PCB 平面电容：  百 MHz~GHz 段
芯片内部电容(die cap)：GHz 以上

结论：VRM 在最需要它的时刻(纳秒级瞬态)是缺席的，
     必须由"本地水库"(去耦网络)顶上。
```

类比：市政水厂(VRM)不可能为你冲一次马桶(芯片瞬态)实时加压，你家楼顶水箱(去耦电容阵)才是即时供水者。

## 4.2 目标阻抗法：把模糊问题变成数字

### 公式

```
Z_target = ΔV_max / ΔI_max

ΔV_max = 允许的最大电压波动
ΔI_max = 最大瞬态电流变化

保守版：ΔI 用满幅值的 50%(经验假设同时翻转一半)
```

### 完整算例：STM32H7 的 VDD 3.3V 轨

```
已知：
- 总电流估计 500mA
- 瞬态假设 50% 同时翻转 → ΔI = 250mA
- 允许波动 ±3% → ΔV = 3.3 × 0.03 = 99mV

Step1: Z_target = 99mV / 250mA = 0.396Ω ≈ 400mΩ

Step2: 这个阻抗要在多高频率内成立？
      取决于 dI/dt。设边沿 1ns，关心到 f ≈ 0.35/tr ≈ 350MHz
      （实际平面电容接管 >100MHz 段，设计到 100MHz 即可）

Step3: 分配各成员负责的频段：
      DC-DC 环路管到   100kHz  (Z≈mΩ级轻松达标)
      Bulk 电解/固态    管 1k~1MHz
      陶瓷电容阵列      管 1M~100MHz  ← 设计重点
      平面电容          管 100M+

Step4: 计算陶瓷阵列需要的总 ESL 决定数量：
      在 100MHz 处每颗 0402 电容已呈感性，
      阻抗≈2πf×ESL_total ≤ Z_target
      → ESL_total ≤ 0.4 / (2π×100M) = 0.64nH
      单颗安装后 ESL 约 1.5~2nH → 需要 3~4 颗并联
      
Step5: 低频段校核 Bulk：
      1MHz 处需 ≤0.4Ω → 单颗低 ESR 固态电容或
      几颗陶瓷大容值即可满足
```

> 【重要观念】目标阻抗法的价值不在精确仿真，而在**给出可执行的量化目标**——它把"多放几颗电容心里踏实"变成"3~4 颗低感安装 + 一颗 Bulk"。

### 各协议/场景的目标阻抗速查

| 场景 | ΔV 要求 | 特点 |
|------|---------|------|
| 普通 MCU 数字轨 | ±3% | 本节算例 |
| DDR 内存轨 | ±2% 甚至更严 | 电流大且突发性强 |
| RF/PLL 供电 | ±1% + 专用滤波 | 相位噪声敏感 |
| ADC 基准/VDDA | ±1% + RC/磁珠隔离 | 抖动=丢精度 |

## 4.3 电容的真实面目：S 曲线

教科书电容 C 是理想元件；真实电容 = C + ESR + ESL 串联：

```
阻抗-频率曲线呈"V字/滑板坡道"：

log Z
 │＼            ／
 │ ＼          ／ ← 感性区：Z=2πf·ESL
 │  ＼        ／
 │   ＼      ／
 │    ＼____／ ←谷底=f_SRF 自谐振频率，Z最低点=ESR
 │     
 └────────────── log f
   容性区：Z=1/(2πfC)

f_SRF = 1/(2π√(LC))

数值感受(0402封装)：
  0.1μF + ESL≈0.5nH → SRF ≈ 22MHz
  超过 22MHz 后它就"变成电感"了！
  
  1μF 同封装 → SRF ≈ 7MHz
  10μF 大封装1206 → SRF 更低
  
推论①：大电容管不了高频(自谐振太低)
推论②：小电容也不是越小越好用——
       它在低频段阻抗反而高于大电容
推论③：所以需要多种值并联接力覆盖宽频带
```

### 并联网络的组合效应

```
三种容值(10μF+1μF+0.1μF)并联的理想曲线：

Z│＼＼    ／／／
 │  ＼＼／／／   ← 三条V曲线的下包络
 │   ＼／＼／
 │   ／＼／＼   注意谷间的"反谐振峰"！
 │ ／    ＼
 └───────────── f
 反谐振峰：大电容已感性、小电容还容性的交接处
 两者的感性和容性互相抵消形成高阻抗尖峰
 
压制反谐振峰的手段：
① 选择 ESR 稍大的型号(钽/固态天然阻尼)
② 多颗同值并联(峰被摊平)
③ 平面电容兜住高频段
```

## 4.4 安装电感：决定成败的最后一环

**同样的 0.1μF，焊得好和焊得差，高频效能可以差 5 倍。**

```
安装电感的组成：
ESL(本体) + 焊盘出线电感 + 过孔电感

糟糕安装(常见新手版)：
  VDD───8mm细线──┤├───8mm细线──过孔(远处)──GND
  引线 16mm ≈ 16nH !! 比本体的0.5nH恶劣32倍
  这颗"0.1μF"实际上是个"16nH电感"

优秀安装：
  VDD脚 ──0.5mm──┤├──0.5mm──双过孔──GND
  总电感 ≈ 0.5 + 1 + 0.6 ≈ 2nH 级别
```

### 安装规范排序（从好到坏）

| 排名 | 方式 | 说明 |
|------|------|------|
| 1 | Via-in-pad 孔在焊盘里 | 电感最小；普通打样怕漏锡需塞孔工艺 |
| 2 | 焊盘两侧短出线即打双孔 | ★打样最优实践 |
| 3 | 单孔就近落地 | 及格线 |
| 4 | 出线 >2mm 再落地 | 开始失效 |
| 5 | 电容放芯片背面但过孔绕远 | 看似省正面空间实则打折 |

铁律：**先连电容再连别的**——去耦电容的引脚必须直接落在 VDD 引脚的延长线上，不允许"顺路捎带"。

## 4.5 平面电容：免费的隐藏福利

电源平面与地平面正对构成平板电容：

```
C_plane = εr × ε0 × A / d

以 50mm×50mm 重叠区、FR4(εr=4.4)、层距0.1mm(薄PP)：
C = 4.4 × 8.85e-12 × (0.05×0.05) / 0.0001
  ≈ 970 pF ≈ 1nF

看似不大，但它：
- 没有引线电感，直到 GHz 都保持电容性
- 分布在全板每个芯片脚下
六层方案一(TOP-GND-SIG-PWR-GND-SIG)中
L4/L5 相邻的 PWR-GND 对就是这功能。
若叠层允许把 PWR/GND 层距压到 0.1mm 以内，
平面电容可达数 nF，是 GHz 段的中流砥柱。
```

这就是"六层比四层好"的隐性理由之一。

## 4.6 PDN 布局布线的军规清单

按优先级排列：

```
★★★ 每个电源引脚一颗 0.1μF，≤2mm 就位，短出线双孔落地
★★★ Bulk 电容放在电源入口和各大功耗器件旁(不用挨着每个IC)
★★★ 电源平面完整不分割给无关信号穿越(分割规则见叠层章)
★★  电容的 GND 过孔不要与别的大电流共享路径
★★  VDDA/PLL/RF 电源用磁珠+RC 从主干隔离并单独滤波
★   多种容值并存(10μF/1μF/0.1μF)覆盖频段
★   板级入口加 TVS+大容量防浪涌(EMC章详述)
```

反面教材速查表：

| 错误 | 后果 |
|------|------|
| 全板共用一大块"电容区"集中摆放 | 安装电感毁掉一切 |
| 只放 0.1μF 一种值 | 中频段(几MHz)出现缺口 |
| 只放一个大电解 | 高频全靠运气 |
| 电容 GND 孔接到了窄条铜上 | 回流瓶颈 |
| LDO 输出电容离 LDO 很远 | LDO 稳定性下降甚至振荡 |

## 4.7 验证：怎么知道你的 PDN 合格

### 设计期

- 目标阻抗手算+工具复核（Saturn 有 PDN 粗算模块）
- KiCad 9 的 PDN 分析工具（高级版功能）或外部工具

### 到板后实测

```
纹波测量标准姿势：
① 示波器带宽 ≥200MHz，探头调到 1:1 小衰减档
② 接地线换成"接地弹簧"(绕在探头尖上的短弹簧)
   ——长地线夹会在高频引入巨大环路噪声假象！
③ 探针直接点在芯片的电源引脚上(不是电容上)
④ 触发模式抓瞬态：单次触发捕捉启动瞬间+运行中毛刺
合格判据：峰值纹波 < 目标 ΔV(如±3%)，
         无周期性振铃(振铃=PDN在某频段失守)
```
