# 第五章 EMC 基础：不干扰别人，也不被别人干扰

> EMC 是产品上市的法定门槛（3C/CE/FCC 认证必测）。它常被当成"玄学"，其实是回流路径理论的自然延伸。本章建立完整的 EMC 设计观：辐射从哪来、怎么在设计期掐灭、超标了怎么低成本整改。

---

## 5.1 电磁兼容的两个战场

```
EMI 发射(不干扰别人)          EMS 抗扰(不被别人干扰)
├─ 辐射发射 RE 30M~6GHz      ├─ 静电放电 ESD ±4~8kV
├─ 传导发射 CE 150k~30MHz    ├─ 射频场抗扰 RS
└─ 谐波电流/闪烁             ├─ 电快速脉冲群 EFT
                            ├─ 浪涌 Surge 1~2kV
                            └─ 电压跌落 Dips
认证测试里最常翻车的是：RE 辐射发射 和 ESD。
本章以这两者为主线。
```

### 限值标准一览（了解即可）

| 标准 | 适用 | Class A / B |
|------|------|-------------|
| CISPR 32 / EN 55032 | 信息技术设备 | A=工业环境 B=住宅环境(B 更严 ~10dB) |
| FCC Part 15 | 美国市场 | 同上分级 |
| GB/T 9254 | 中国 3C | 对标 CISPR |

Class B 在 30~230MHz 的辐射限值约 **30dBμV/m @3m**——换算成天线上的功率是微瓦级。这就是为什么几毫安的共模电流就能让产品超标。

## 5.2 辐射的两大来源：差模与共模

### 差模辐射：小环天线

```
信号走线出去、参考平面回来 → 构成一个小环路

环路辐射强度 ∝ I × A × f²  （A=环路面积）

数值感受：
1cm² 环路、10mA、100MHz 的三次谐波分量…
就足以逼近 Class B 限值！

控制差模辐射 = 控制环路面积：
- 高速信号的回流路径连续(上一章的全部内容)
- 晶振/时钟紧贴芯片
- 电源去耦就近
```

### 共模辐射：电缆天线（真正的魔王）

```
共模噪声怎么产生？
高速开关经杂散电容耦合到地系统，
在"信号地"与"真正大地/机壳"之间形成电位差，
驱动整根外接电缆像单极天线一样辐射。

单极天线长度 = λ/4 时辐射最强：
  150MHz → λ/4 = 50cm   ← 一根 USB 线刚好！
  300MHz → λ/4 = 25cm

恐怖之处：驱动它的电流只需 μA 级！
  (对比差模需要 mA 级)
且它辐射的是电缆整体，面积巨大。

结论：EMC 整改的主战场几乎总是共模。
```

### 判断超标的到底是哪种

```
经验诊断法：
① 拔掉所有外接电缆再测：
   超标消失 → 共模(电缆)问题
② 换短电缆/套磁环：
   明显改善 → 共模确认
③ 近场探头扫板找热点对应时钟谐波频率：
   板内环路问题 → 差模/回流路径缺陷
④ 超标频点对照时钟树找源头：
   f_超标 = n × f_晶振或倍频 → 锁定元凶
```

## 5.3 设计期的 EMC 军械库

### 武器一：控边沿（性价比之王）

辐射能量 ∝ dI/dt 和 dV/dt——边沿越陡谐波越丰富：

```
33Ω 串阻放缓边沿 → 三次以上谐波可降 10~20dB
GPIO 配置降 slew rate(STM32 有 OSPEEDR 档位)
能不用高速沿就不用
一颗几分钱的电阻省一次整改，没有比这更划算的买卖。
```

### 武器二：接口滤波三件套

对外接口的标准处理模板（以带屏蔽的高速接口为例）：

```
            ┌── TVS(ESD防护,接地近)
芯片 ──串阻──┼── 共模电感(扼流圈)
            └── 对地小电容(Y电容类)

各司其职：
TVS：    静电浪涌钳位，必须放在最靠接口处
共模电感：对共模高阻抗拦住出板；对差模近乎透明
对地电容：给残余高频提供就地入地通道

布局铁律：三件套一字排开横跨"干净区/脏区"边界，
         全部就近接地，信号先过保护再进板内。
```

不同接口的标配方案速查：

| 接口 | 保护+滤波配置 |
|------|--------------|
| USB 2.0 | ESD阵列(如USBLC6) + 差模0Ω可选 + 外壳地 |
| 以太网 | 网变自带隔离 + Bob Smith端接(75Ω+1nF/2kV) |
| UART/排针 | 串阻22~33Ω + 可选TVS + RC滤波 |
| CAN | 共模电感 + TVS(CAN专用如PESD1CAN) |
| 电源输入 | 保险丝+TVS+大容量+π型滤波 |

### 武器三：地与缝合的体系化

前两章的知识在此收网：

```
① 完整 GND 平面是一切的地基(回流章)
② 板边缝合孔间距 ≤λ/20@最高关心频率
   (按1GHz算≈15mm，工程取10mm整齐打一圈)
③ 接口区局部地岛通过密集孔墙与主地一体
④ 屏蔽罩(如有)四周落地焊盘过孔密度加倍
⑤ 多层板的 L2 做完整 GND 是 EMC 性价比最高的决策
```

### 武器四：屏蔽罩设计要点

```
法拉第笼原理，但缝隙是漏洞：
缝隙泄漏判据：最大缝隙尺寸 < λ/20
  1GHz 时 λ/20 = 15mm —— 屏蔽罩和盖板搭接
  必须多点连续，不能只靠卡扣点接触

PCB侧配合：
罩脚焊盘间隔 ≤10~15mm，每脚旁接地过孔×2
罩内敏感线尽量走内层
```

## 5.4 ESD 专题：8kV 来袭的那 1ns

```
人体模型：人碰金属门的静电可达 ±8~15kV
接触放电测试等级：±4kV(常规)/±8kV(严苛)
上升沿 <1ns，峰值电流可达数十安培！

ESD 电流的路径设计决定生死：
理想路径：接口引脚 → TVS → 地平面 → 大地/机壳

布局三原则：
① TVS 距连接器 <5mm(先泄放再进板)
② TVS 接地过孔≥2个且直接落平面(低感泄放通路)
   泄放回路电感每多1nH，残压抬高数十伏！
③ 被保护线避免长距离并行走线(防耦合到邻居)

常见翻车：TVS 位置正确但地孔只有一个且远
→ 测试时 TVS 形同虚设，后级芯片照样死。
"TVS 选对了但布局错了"是 ESD 整改第一大坑。
```

## 5.5 低成本整改案例库

真实世界的整改思路集锦（教学浓缩版）：

### 案例A：USB 打印机 120MHz 超标

```
诊断：拔线消失→共模；120MHz=24MHz晶振×5
整改：
① USB 口共模线上加贴片共模电感(90Ω@100MHz款)
② 查出 D+/D- 换层无伴飞地孔→补孔重投
结果：-12dB 通过
```

### 案例B：工控板金属外壳反而更差

```
诊断：外壳与 PCB 地仅两点螺丝接触，
     接触阻抗形成谐振，电缆被激励
整改：外壳内侧加弹片与 GND 平面多点搭接(间距<λ/20)
     → 共模电流有了低阻回家路
结果：150~300MHz 段下降 15dB
教训：屏蔽不是"扣个铁壳"，是"低阻抗等电位搭接"
```

### 案例C：某板子复位脚被静电打挂

```
诊断：复位按键裸露在面板，静电从按键注入
整改：
① 复位线串 100Ω + 对地 1nF(吸收+限流)
② 加双向 TVS 到地
③ 面板按键选带接地屏蔽壳型号
教训：凡是通向"人会摸的地方"的线都是 ESD 天线
```

## 5.6 EMC 设计检查清单（设计期全量）

```
叠层与地
[ ] 至少一个完整无分割 GND 平面
[ ] 板边缝合孔一圈，间距≤10mm
[ ] 所有换层高速线有伴飞地孔

时钟与高速源
[ ] 晶振紧贴芯片下方净空
[ ] 时钟线远离板边≥10mm、远离接口≥20mm
[ ] 关键时钟输出串阻(22~33Ω)评估
[ ] 能扩频(SSC)的接口已启用

接口与电源
[ ] 全部对外接口有 ESD 器件且位置≤5mm
[ ] TVS 接地双孔直接落平面
[ ] 高速接口考虑共模抑制器件预留位(焊0Ω占位)
[ ] 电源入口：保险丝+TVS+Bulk+π滤

布局
[ ] 干净区(晶振/MCU/模拟)与脏区(接口/电源开关)物理隔离
[ ] 无信号跨分割
[ ] RF/天线区净空且周边缝孔墙

软件配合(别忘了这层)
[ ] 未用 GPIO 设为输出低或模拟输入(不当天线)
[ ] 可降摆幅的接口降档
[ ] 时钟不用时门控关闭
```
