# 02｜STM32H743 电源、时钟与启动架构

> H7 的板子经常不是“CPU 太快”把人难住，而是供电、VCAP、时钟、cache、MPU 和外部存储启动顺序一起出现时，没有把问题分层。

---

# 1. 把“3.3 V MCU”拆掉

AN4938 对 H74x/H75x 明确区分 VDD、VDDLDO、VCAP、VDDA、VREF+、VBAT 以及 USB supply。

## VDD

官方硬件指南典型要求：每个 VDD pin 配局部 100 nF，并配 package bulk。PCB 目标不是数量正确，而是局部供电回路低电感。

## VDDLDO / VCAP

H743 使用内部 LDO 为 core domain 生成 VCORE。VCAP 是 regulator stabilization / core support 节点，不是普通外部电源 rail，不能拿去带外部负载。

## VDDA / VREF

即使是数字板，也要问 ADC 精度、VREF 来源与 analog return 是否受到 SDRAM/PHY switching current 污染。

---

# 2. SDRAM 的 3.3 V 单独看

AS4C4M16SA 同时有 VDD/VDDQ/VSS/VSSQ。

目标：

- supply pin group 有局部高频去耦；
- DQ switching current 回路短；
- 3V3_SDRAM 不 neck-down；
- SDCLK / DQ reference plane 连续。

---

# 3. PHY 电源单独 Review

LAN8742A/Ai 有 VDD1A、VDD2A、VDDIO、VDDCR、exposed ground pad 和 RBIAS。单 3.3 V 模式下内部 regulator 产生 1.2 V core rail。

因此 PHY 不是普通数字 IC，它的 analog front-end 直接连接 transformer/cable。

---

# 4. V3 Power Tree

~~~text
5V_IN
  │
  ├─ protection / input filter
  │
  └─ 3V3 regulator
       ├─ 3V3_MCU
       ├─ 3V3_SDRAM
       ├─ 3V3_PHY branch
       ├─ VDDA / VREF branch
       └─ USB related supply
~~~

branch 不一定等于独立 regulator，而是让电流路径、阻抗、噪声和布局 ownership 可审。

---

# 5. Clock Tree

CPU 480 MHz 不代表所有外设也跑 480 MHz。

V3 冻结 **FMC_SDCLK = 100 MHz**。这是基于 MCU datasheet revision/voltage/load 条件后的 first-spin 教学基线，而不是 SDRAM 本身速度限制。

RMII 使用连续 50 MHz REF_CLK。LAN8742A 可用 25 MHz crystal 并输出 50 MHz REFCLKO 给 MCU。

---

# 6. SDRAM 启动顺序

~~~text
Power stable
→ MCU reset release
→ core clock
→ GPIO/FMC clock
→ SDRAM initialization
→ basic memory test
→ MPU/cache policy
→ allocator / large buffer usage
~~~

不要在 SDRAM 尚未初始化时就把 stack、heap 或 C runtime data 放进去。

---

# 7. Cache / MPU 是 PCB Bring-up 的“伪故障源”

小范围读写正常、DMA 后错、开 cache 后偶发，并不自动说明 PCB 坏。

必须区分：

1. physical memory failure
2. FMC timing
3. PCB SI
4. cache coherency
5. MPU attributes
6. DMA ownership

bring-up 第一阶段先建立简单 memory test 硬件基线，再逐步打开 cache 和 DMA。

# 增补｜把 H743 Power / Clock 变成可审核架构

## A. Power Requirement Matrix

不要只画“3V3 → MCU”。对 exact device/package 建表：

| Domain / Pin Group | Source | Mandatory external network | Startup / constraint | Source |
|---|---|---|---|---|
| VDD/VSS | TBD | decoupling | datasheet | ST |
| core regulator support pins | device-defined | exact capacitor requirement | datasheet/AN4938 | ST |
| VDDA/VSSA/VREF | TBD | filter/decoupling | ADC/reference requirement | ST |
| VBAT | project choice | source/isolation | project | ST |
| PHY rails | exact PHY | per datasheet | reset/clock relation | vendor |
| SDRAM rail | 3V3_SYS candidate | local decoupling | memory datasheet | Alliance |

禁止从 F4 项目机械复制 VCAP / analog power 规则；H7 必须重新按 exact part / revision 核对。

## B. Clock Source Decision Record

每个 clock 都写：

```text
purpose
source
frequency
accuracy/jitter requirement
startup behavior
PCB-sensitive nodes
firmware dependency
measurement point
fallback
```

至少覆盖：

- HSE / system source；
- LSE（若使用）；
- FMC / SDRAM；
- RMII 50 MHz；
- USB 48 MHz domain。

## C. Boot / Reset / Brownout Bring-up Tree

上电失败不要直接切外部晶振。建议：

```text
power rails valid
→ NRST state
→ boot strap
→ SWD ID
→ internal clock firmware
→ external HSE
→ PLL
→ peripheral clock
```

每一步只增加一个变量。

## D. Errata Matrix

建立表格：

| Item | Silicon revision affected | HW impact | FW workaround | PCB action | Status |
|---|---|---|---|---|---|

Part 7 任何 clock / FMC / Ethernet 结论若受 revision 影响，都必须进入这张表，而不是只在正文提一句“注意 errata”。
