# 1. 先冻结产品问题，不先冻结 PCB

V3 教学产品定义：

> 一块可作为工业控制 / 网络控制核心的六层 STM32H743 板，带 8 MiB 外部 SDRAM、10/100 Ethernet、USB FS、SWD 和基础扩展接口。

| 功能 | V3 冻结 |
|---|---|
| MCU | STM32H743ZIT6 |
| Package | LQFP144 |
| CPU | 最高 480 MHz，实际运行点由系统冻结 |
| External RAM | 8 MiB SDR SDRAM, x16 |
| SDRAM clock | 100 MHz project baseline |
| Ethernet | 10/100, RMII external PHY |
| USB | USB 2.0 Full-Speed |
| Debug | SWD |
| PCB | 6-layer, controlled impedance |
| Input | 5 V nominal |
| Main rail | 3.3 V |

# 2. 为什么这次不是“功能越多越好”

H743 有大量外设，但 V3 不同时塞 HDMI、ULPI、camera、SDMMC、LCD、双 CAN-FD 等功能。原因是它们会同时抢 pin、layer、connector edge、power 和 review attention。

Part 7 的主角只有两个：

1. **FMC SDRAM**
2. **Ethernet**

# 3. Resource Freeze 的四张表

## Peripheral Table

| Block | Peripheral | Clock dependency | PCB priority |
|---|---|---|---|
| SDRAM | FMC | FMC kernel / SDCLK | P0 |
| Ethernet | ETH RMII | 50 MHz REF_CLK | P0 |
| USB | OTG FS | 48 MHz domain | P1 |
| Debug | SWD | system | P0 |
| HSE | RCC | oscillator | P0 |
| UART/I2C | peripheral | bus clock | P2 |

P0 表示在 floorplan 和 pin planning 时，其他功能必须给它让路。

## Connector Table

每个 connector 都要记录 connector 类型、外部 cable、ESD exposure、shield、chassis strategy、placement side 与 keepout。Ethernet RJ45 会把 cable、magnetics、common-mode 和 ESD 直接带进 PCB。

## Power Table

必须区分 5V_IN、3V3_SYS、3V3_MCU、3V3_SDRAM、3V3_PHY、VDDA/VREF、VCAP 与 USB supply。

这些 rail 可以来自同一个 regulator，但在 PI Review 中不能用一个“3V3 网名”结束分析。

## Clock Table

| Clock | Source | Frequency | Destination | PCB concern |
|---|---|---:|---|---|
| HSE | crystal/oscillator | project-defined | MCU | local loop |
| FMC_SDCLK | MCU | 100 MHz | SDRAM | synchronous timing |
| RMII_REF_CLK | PHY | 50 MHz | MCU | reference + edge |
| USB | internal PLL | 48 MHz domain | PHY | supply/jitter |
| SWDCLK | debugger | variable | MCU | bring-up |

# 4. Pin planning：先锁 SDRAM，再锁 RMII

x16 SDRAM 会占用 DQ[15:0]、A[11:0]、BA[1:0]、SDCLK、CKE、CS、RAS、CAS、WE、NBL[1:0]。

NUCLEO-H743ZI2 官方 RMII baseline 使用：

- PA1 REF_CLK
- PA2 MDIO
- PA7 CRS_DV
- PB13 TXD1
- PC1 MDC
- PC4 RXD0
- PC5 RXD1
- PG11 TX_EN
- PG13 TXD0

为了避免 SDRAM control 与 RMII 冲突，V3 优先采用：

- PH5 → FMC_SDNWE
- PH6 → FMC_SDNE1
- PH7 → FMC_SDCKE1

这说明 pin planning 本身就是 PCB architecture。
