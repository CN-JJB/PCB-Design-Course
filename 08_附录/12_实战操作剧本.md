# 附录十二 实战操作剧本：一块四层板从零到下单全记录

> 把全书操作串成一部"可跟做"的连续剧。主角：四层 STM32 最小系统板(项目二的浓缩版)。每一场戏都有精确的菜单路径与预期画面，跟着演完你就拥有完整的多层板肌肉记忆。

---

## 第一幕 工程奠基（预计 25 分钟）

**场次 1 新建工程**
- 操作：File → New Project → 命名 `stm32_min_4l_v1` → 勾选新建文件夹
- 预期：工程管理器出现三个核心文件图标
- 检查点：路径无中文无空格

**场次 2 叠层设定**
- 操作：打开 PCB Editor → File → Board Setup → Physical Stackup → 层数改 4
- 动作细节：逐层填入 JLC04161H 参数(L1/L4 铜 0.035、介质 0.2104、芯板 0.71、内层铜 0.0175)、勾选 L1 的阻抗控制
- 预期：叠层图显示对称结构
- 检查点：截图存档到 docs/ 文件夹

**场次 3 规则体系**
- 操作：Board Setup → Design Rules：
  - Constraints：clearance 0.2 / track 0.25 / via 0.6-0.3 / copper-edge 0.4
  - Net Classes 新建 `PWR`(0.8mm) 加入 +5V/+3V3/GND
- 预期：类列表两行(Default/PWR)
- 检查点：故意把一根线画 0.15mm 应报错(冒烟测试)

**场次 4 板框与机械**
- 操作：切 Edge.Cuts 层 → 画 36×28 矩形 → 放 4×M3 安装孔封装
- 预期：闭合轮廓+四角孔
- 检查点：测量对角尺寸无误

## 第二幕 原理图速成（预计 60 分钟）

**场次 5 电源页**
- 操作流：Schematic Editor → A 放 USB-C/AMS1117/电容阵 → W 连线 → P 落电源符号
- 关键动作：CC1/CC2 各放 5.1k；VBUS 加 TVS+保险丝
- 检查点：电源树注释文本写明每路电流

**场次 6 MCU 页**
- 操作流：A 放 STM32F103C8Tx → 六大模块逐一展开(去耦/时钟/复位/BOOT/SWD/GPIO 引出)
- 关键动作：每个 VDD 就近放 100nF 并命名 C_VDDx
- 检查点：OSC 网络 <8 字符语义化

**场次 7 质检闭环**
- 操作流：Q 补 no-connect → Inspect→ERC 清零 → Tools→Assign Footprints 批量分配 → File→Export→BOM 核对现货
- 预期：ERC 零错误零未解释警告
- 检查点：BOM 每行有立创编号

## 第三幕 布局战役（预计 45 分钟）

**场次 8 同步入板**
- 操作：PCB 编辑器按 F8 → Apply → 全选拖散
- 预期：元件堆摊开在板框外
- 检查点：总数与 BOM 一致

**场次 9 三锚定死**
- 操作：USB-C 贴上边 → MCU 居中偏右 → SWD 排针右上角
- 手法：粗网格 0.5mm，R 旋转找最佳出线角度
- 检查点：飞线交叉肉眼可见地少

**场次 10 分区推进**
- 操作顺序：电源链直线排布 → 去耦阵列贴脸(≤2mm) → 晶振净空圈 → 复位/BOOT/LED 收尾
- 关键动作：晶振周围 3mm 内清空一切
- 检查点：布局自查清单 22 条全过

## 第四幕 布线决战（预计 90 分钟）

**场次 11 规则内布线**
- 操作流：网格切 0.127 → X 起线(推挤模式 Shift+R 确认)
- 顺序执行：USB 差分(6 键)→ 电源粗线入 L3 平面 → 晶振短线 → SWD/GPIO
- 关键动作：换层必按 V 后顺手补 GND 孔伴飞
- 检查点：飞线清零截图

**场次 12 敷铜与缝合**
- 操作流：Ctrl+Shift+Z 画顶/底 GND 区 → Thermal 参数确认 → B 填充 → Tools→Via Stitching 板边 10mm 网格生成
- 预期：双层绿意盎然，孔墙整齐
- 检查点：U 键抽查三处缝合孔连通性

**场次 13 平面与收尾**
- 操作：L3 放 PWR Zone(+3V3 全域) → B 刷新 → 单层视图逐层巡检
- 关键动作：In1(GND) 确认零走线穿过
- 检查点：分割地图符合设计

## 第五幕 出货冲刺（预计 40 分钟）

**场次 14 三清仪式**
- 操作：ERC 清 → DRC 清(Inspect→DRC→Run) → Net Inspector 长度表导出
- 预期：两份报告存档 docs/
- 检查点：无未解释警告

**场次 15 Gerber 出厂**
- 操作流：File→Fabrication Outputs→Gerbers → 勾全部铜层+Mask+Silk+Edge → 勾 Check zone fills → Plot → Generate Drill Files(Excellon 合并)
- 自检：Gerber Viewer 逐层目检四层画面
- 检查点：zip 内文件数正确(7~8 个)

**场次 16 下单与归档**
- 操作流：嘉立创上传 → 选 ENIG/盖油/绿色/5 片 → 提交审单 → 工程快照 zip 归档 → CHANGELOG 写 v1.0 条目
- 预期：订单进入"审核中"
- 检查点：等板期间测试计划已写完
