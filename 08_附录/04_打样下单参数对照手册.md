# 附录四 打样下单参数对照手册

> 以嘉立创(JLC)打样体系为参照的完整下单决策表。其他厂商(捷多邦/华秋/PCBWay)结构类似，参数口径以各自官网当期公布为准。

## 一、板材参数对照

### 层数与价格量级(10×10cm 内、5 片起)

| 层数 | 常规价 | 周期 | 适合阶段 |
|------|--------|------|---------|
| 1 | ¥5~20 | 24h | 玩具级 |
| 2 | ¥10~30 | 24~48h | 项目一二层板 |
| 4 | ¥40~80 | 48~72h | 课程主力 |
| 6 | ¥120~250 | 3~5天 | 高速实战 |
| 8+ | 按需报价 | 一周 | 进阶自研 |

### 板材选项解读

| 参数 | 选项 | 怎么选 |
|------|------|--------|
| 厚度 | 0.4~2.0mm | 默认 1.6；插板卡槽注意限高；薄板抗翘弱 |
| Tg | 130/150/170 | 无铅回流或高温场景 ≥150 |
| 铜厚 | H/1oz/2oz/3oz | 大电流外层 2oz 或敷铜开窗加锡 |
| 阻焊色 | 绿/红/蓝/黑/白/黄/紫 | 绿最稳最快；黑色手焊目检困难 |
| 表面处理 | HASL有铅/无铅、ENIG、OSP | 学习推荐 ENIG；量产按 BOM 与成本 |
| 半孔 | 支持 | 板对板边缘连接用 |
| 阻抗控制 | 勾选+填表 | 四层起高速必勾 |

## 三、下单流程十步清单

```
① Gerber zip 就绪(Viewer 自检通过)
② 上传→核对自动识别尺寸层数
③ 选参数(对照上表)
④ 阻抗控制：填目标表→等工程师反算确认
⑤ 过孔工艺：默认盖油
⑥ 数量：学习 5 片；调试中期可 10 片摊薄单价
⑦ SMT 选项：基础库免费贴清单核对
⑧ 钢网：需要 QFN/BGA 手贴才买
⑨ 提交→审单回复问题(丝印细/孔径小等)
⑩ 生产跟踪→收货→验收流程(见下)
```

## 四、SMT 贴片服务要点

| 项 | 说明 |
|----|------|
| 基础库拓展库 | 基础库元件免物料费/低价贴；扩展库加钱 |
| 元件高度限制 | 一般 ≤12mm，高于则手补 |
| 最小封装 | 支持到 0201(费率上升)；BGA 需 X-Ray 选项 |
| 工程费 | 每款一次性，拼版算一款 |
| 配料模式 | 全自配/全代购/混合；自配料要贴好标签寄送 |
| 良率兜底 | 少数连锡飞件属正常损耗范围，合同有约定比例 |

新手建议路线：项目一全手焊练技能；项目二起 MCU 用 SMT；项目四以后密脚全部 SMT。

## 五、收货验收 SOP

```
A. 包装外观：防静电袋完好、数量正确
B. 目检：阻焊均匀无气泡、丝印清晰、板边无崩边
C. 版本核对：丝印版本号=订单版本
D. 层数断面：数铜层亮线
E. 电气抽测：
   - 各电源轨对地阻抗
   - 3 条关键网络通断
   - 相邻电源域绝缘(MΩ 级)
F. 阻控单核对：报告数值逐行 vs 下单表
G. 问题取证拍照 → 客服工单
全部通过 → 归档 gerber+报告 → 进入焊接流程
```

## 六、常见审核退回原因与预防

| 退回原因 | 预防动作 |
|---------|---------|
| 丝印字符过细 | 字高≥0.8mm 线宽≥0.15mm |
| 孔径低于能力 | 过孔≥0.2/0.45 |
| 缺钻孔文件 | 导出后 Viewer 复查 |
| 铜距板边不足 | 规则设 0.4mm |
| 阻抗表线宽不可实现 | 先用其计算器反算再定规则 |
| 文件名含特殊字符 | 简洁英文命名 |
