# 附录二 器件选型速查手册

> 常用功能模块的"默认答案"。新项目启动时从这里抄起点，再按需求微调。所有推荐以立创商城常备现货为前提(具体型号库存以当期为准，思路永不过时)。

---

## 一、电源链选型决策树

```
输入电压 → 输出电压需求分析：

压差 <1V 且电流 <500mA？
 └─ 是 → 高效LDO(ME6217/SGM2212类) 或 大封装AMS1117
压差大 或 电流 >800mA？
 └─ 是 → Buck：MP2315(3A小体积)/TPS54331(3A经典)
         /LM2596(老但好买，手焊友好SOT? 实际TO-263)
需要隔离？→ 加 DC-DC 隔离模块(B0505S 类百元内方案)
超低噪声(ADC基准/PLL)？→ LDO 专用低噪款(TPS7A02/ADP7182)
                          + π滤波 + 独立走线
多轨时序需求？→ 集成 PMIC 或 PGOOD 使能链
电池供电？→ 效率优先：同步Buck+轻载PSM模式
```

### 各电压域典型配置表

| 轨道 | 来源 | 典型电流 | 输入电容 | 输出电容 | 备注 |
|------|------|---------|---------|---------|------|
| USB 5V | 直入 | ≤500mA | 10μF+0.1μF | — | 加 TVS+保险丝 |
| +3V3 数字 | Buck/LDO | 视系统 | — | 22μF+分布去耦 | 主力域 |
| +1V8 | LDO from 3.3 | ≤300mA | 1μF | 10μF×2 | IO Bank/SDRAM |
| +VCORE 1.1V | 内置稳压或专用Buck | 数百mA~A 级 | — | 按手册 | VCAP 类生命级 |
| +VDDA | 磁珠或专用LDO | ≤20mA | — | 1μF+0.1μF+10μF | ADC 精度之源 |

| 功能 | 首选 | 备选 | 关键外围坑 |

| 以太网 PHY 百兆 RMII | KSZ8081RNA | LAN8720A | REF_CLK 50MHz 星型 |

## 四、存储器速查

| 需求 | 型号家族 | 接口 | 注意 |
|------|---------|------|------|
| 参数存储小容量 | AT24Cxx EEPROM | I2C | 页写延时；百万次擦写 |
| 固件/文件 SPI Nor | W25Q64/W25Q128 | SPI Quad | 4KB 扇区擦除模型 |
| 大容量 SPI Nand | GD5F 系列 | SPI | 需坏块管理(FTL) |
| SDRAM SDR | W9825G6KH-6 | FMC | 项目六主角 |
| DDR3L | MT41K128M16 类 | 专用控制器 | Fly-by/ODT 全家桶 |
| TF 卡 | 标准卡座+SDMMC | SDIO 4bit | CD 检测脚处理 |

## 五、传感器模块速查

| 测什么 | 首选型号 | 总线 | PCB 要点 |
|--------|---------|------|---------|
| 温湿度 | SHT30/SHT40 | I2C | 上拉4.7k；远离热源(自身CPU) |
| 气压 | BMP280/BME280 | I2C/SPI | 通气孔朝下防积液 |
| 加速度计 | MPU6050/LSM6DSO | I2C | 远离振动源固定牢 |
| 光照 | BH1750/APDS9960 | I2C | 开窗对光/环境光滤波 |
| 距离 ToF | VL53L0X | I2C | 光路净空 |
| 电流检测 | INA219/INA226 | I2C | 采样电阻开尔文接法! |
| 温度精密 | PT100+MAX31865 | SPI | 三线制补偿走线对称 |

> 开尔文接法强调：采样电阻的两端电压检测点必须直接落在电阻焊盘上，从主电流路径分叉后取样会把导线电阻算进测量——精度杀手第一名。
