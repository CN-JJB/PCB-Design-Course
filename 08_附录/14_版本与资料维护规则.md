# 附录十四｜版本与资料维护规则

## 1. Source Classes

所有可变信息标记来源类别：

1. Device Requirement
2. Interface / Standard Requirement
3. Tool Documentation
4. Fabricator Capability
5. System Design Target
6. Teaching Example / Heuristic

## 2. Last Reviewed

容易过时的内容建议在页首记录：

```text
Last reviewed:
Tool version:
Device revision:
Standard edition:
Fab query date:
```

## 3. Reopen Triggers

出现以下变化必须重新核对相关章节：

- KiCad major version；
- MCU/FPGA silicon revision；
- memory / PHY exact MPN；
- errata；
- protocol/standard edition；
- PCB fab / stackup；
- assembly process；
- BOM alternate。

## 4. Legacy Conflict

若旧版 01～08 与 Part 0～9 冲突：

```text
latest primary source
→ current Part
→ legacy appendix
```

不为兼容旧文而保留已知错误。

## 5. 数字纪律

任何关键数字至少带一种身份：

```text
REQ
TARGET
FAB
MEASURED
EXAMPLE
HEURISTIC
```

这样读者知道它能不能被复制到另一个项目。
