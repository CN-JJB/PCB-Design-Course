# 附录十 常见电路模块图集（文字版）

> 24 个嵌入式硬件最高频电路模块的"标准答案"。ASCII 图+工作原理+参数计算+PCB 要点四位一体。设计新板时像查字典一样取用。

---

## 模块01 USB Type-C 设备口（仅供电+USB2.0）

```
VBUS ──┬────────── +5V
       [TVS]         │
        │          [0.5A保险丝]
       GND           
CC1 ──[5.1k]── GND    ← 无此电阻 C-C 线不供电
CC2 ──[5.1k]── GND
D+ / D- ── 差分直连芯片，90Ω 目标
外壳四条接地腿 ── 大面积接 GND
```
原理：CC 引脚的 5.1k 下拉向源端宣告"我是设备，需要 5V"。
参数：下拉必须 5.1k±10%（规范值），TVS 选低结电容款。
PCB：差分 <15mm 直达；接地腿足锡防插拔应力虚焊。

## 模块02 LDO 最小系统

```
VIN ──┬──[LDO IN]  LDO  [OUT]──┬── VOUT
    [Cin 1μF~10μF]   │      [Cout 按手册]
                    GND        │
                             [可选分压反馈]
```
原理：线性降压=压差×电流全部变成热。
参数：压差裕量核算(输入最低值−输出 ≥ 手册 dropout+余量)；输出电容 ESR 在稳定窗口内；功耗 P=(Vin−Vout)×Iout 核对封装热阻。
PCB：进出电容各贴各脚；GND 腿接大片敷铜散热；远离热敏元件。

## 模块03 Buck 开关电源核心

```
VIN ─[Cin]─┬─[HS]─┬─SW─[L]─┬─VOUT
           │      │        │
          [Cboot]─┘     [Cout]  [FB 分压自 VOUT]
           └─[LS]─┴─GND          
```
原理：HS/LS 高频斩波把直流切成方波，L+C 滤回直流。
参数：电感 Isat≥1.3×峰值电流；Cin 纹波电流额定核对；FB 分压按反馈基准算(Rtop/Rbot=(Vout/Vref)−1)。
PCB：热回路面积最小化、FB 远离 SW、电感下方信号净空（详见专题二十二条铁律）。

## 模块04 MCU 复位电路

```
VDD ──[R 10k]──┬──── NRST
             [C 0.1μF]
                │
              [按键并联于 C]── GND
```
原理：上电 RC 充电延时保证电源稳定后才释放复位。
参数：τ=RC 覆盖手册最短复位脉宽×3 以上。
PCB：NRST 走线短、远离干扰源；若引出面板加防护三件套。

## 模块05 无源晶振电路

```
OSC_IN ──┬─[XTAL]─┬── OSC_OUT
       [CL1]    [CL2]
         │        │
        GND      GND      (四脚晶振的外壳脚就近接地)
```
原理：皮尔斯振荡器，外接电容与晶体等效参数共同决定振荡频率精度。
参数：CL1≈CL2≈2×CL−Cs。
PCB：<4mm 对称走线、下方全层净空、远离一切干扰。

## 模块06 按键输入（带消抖）

```
VDD ──[10k 上拉]──┬── GPIO
                 [按键]
                   │
                  GND      (软件消抖 10~20ms 或硬件 R+0.1μF)
```
原理：未按下读高，按下读低；机械触点抖动需消抖。
参数：上拉 10k 通用；硬件消抖 τ≥5ms。
PCB：远距离引出时串 100Ω 保护并对地小电容。

## 模块07 LED 状态灯

```
GPIO ──[限流电阻]──▶|── GND   (推挽高有效)
或
VDD ──[限流电阻]──▶|── GPIO   (灌电流低有效，驱动能力更强)
```
原理：限流防烧；灌电流架构利用 MCU 下管更强特性。
参数：R=(VOH−VF)/IF。
PCB：位号旁丝印功能名(如 PWR/HEART/ERR)，调试效率翻倍。

## 模块08 I2C 总线挂载

```
VDD ──[Rp 4.7k]──┬── SDA ──┬──┬── 器件A/B/C...
VDD ──[Rp 4.7k]──┴── SCL ──┘  │
                          (整条总线一对上拉即可)
```
原理：开漏输出+线与逻辑，必须外部上拉才能输出高。
参数：Rp 上限由总线电容决定(400kHz 典型 2.2k~4.7k)；地址冲突查各器件地址表。
PCB：短于 30cm 板内随意；上拉电阻放总线中点附近。

## 模块09 SPI Flash 存储

```
MCU SCK ──→ CLK      CS# ──[10k 上拉 VDD]←── 防误选中
MOSI/MIO、D2/D3(Quad 时上拉 10k×2)
VCC ── 0.1μF+0.01μF 双去耦
HOLD#/WP# 按手册处理(Quad 模式复用为数据脚)
```
原理：时钟同步全双工，CS 低电平期间通信。
参数：模式 0/3 与器件匹配；Quad 使能后 D2/D3 别再接固定电平。
PCB：四线等长要求宽松(<10mm 差)；时钟串 22Ω 可选。

## 模块10 UART 转 RS485 半双工

```
MCU TX ←→ DI          RE#──┐
MCU RX ←→ RO   收发器  DE ──┤ 由一个 GPIO 控制
A ──[120Ω 终端可选]── B    (方向控制时序是软件要点)
A/B 各串 [自恢复保险丝]+[TVS 到 GND]
```
原理：差分传输抗长距离干扰，半双工靠 DE/RE# 切换方向。
参数：终端 120Ω 只在总线两端；失效保护偏置电阻视系统配置。
PCB：A/B 差分走线；TVS 贴接口；共地参考必须引出。

## 模块11 CAN 总线节点

```
MCU CANTX → TXD  [CAN收发器]  CANH ──┬──[TVS 双向]──┬── 总线
MCU CANRX ← RXD              CANL ──┘  [共模电感可选]
STB/S 引脚模式配置；终端 120Ω 位于物理总线两端
```
原理：差分显性/隐性电平，仲裁靠 ID 逐位竞争。
参数：位速率与总线长度反比(1Mbps@40m 内)；终端必须恰好两端各一。
PCB：CANH/L 并行差分；收发器去耦贴脚。

## 模块12 ADC 分压采样

```
被测高压 ──[Rtop 100k]──┬──[Rbot 10k]── GND
                        ├──[RC 1k+100nF]── ADC_IN
                       (采样点)
```
原理：分压把高压缩到 ADC 量程内，RC 提供充电电流并滤噪。
参数：分压比留 20% 量程裕量；Rtot 权衡精度(太大小电流易漂)与功耗；ADC 输入阻抗匹配查手册源阻上限。
PCB：采样走线远离开关噪声；必要时加运放缓冲。

## 模块13 电池供电与充电管理

```
USB 5V ──[充电IC 如 TP4056]── BAT+ ──[防反接]── 系统电源路径
        PROG 电阻定充电电流         │
        CE 使能                 [电池温度 NTC 可选]
BAT 经 [升压或 LDO] 给系统
```
原理：恒流-恒压两段式充电曲线。
参数：充电电流按 PROG 电阻设(典型 0.5C)；保护板三重保护(过充/过放/过流)确认在电池包内或板上补齐。
PCB：充电 IC 散热焊盘足铜；NTC 走线远离功率路径。

## 模块14 MOS 开关控制高边

```
VCC ──[PMOS S极]──D极── 负载 ── GND
G 极经 [NPN 或专用驱动] 控制拉低开通
GS 并 [100k 下拉] 保证默认关断
```
原理：高边 PMOS 通断整条电源轨；N 沟道高边需自举或泵电荷(复杂场景直接选集成负载开关)。
参数：Vgs(th) 与驱动电压匹配；连续电流按 Rds(on) 算发热。
PCB：大电流回路粗铜；栅极走线短防振荡。

## 模块15 蜂鸣器驱动

```
有源蜂鸣器: GPIO ──[100Ω~1k]── BUZZER+ ，BUZZER− ── NMOS ── GND
无源蜂鸣器: 同结构但 GPIO 输出 PWM 音调
并联续流二极管(感性)反向跨接
```
原理：MCU 只给控制不给功率；NMOS 下管架构最通用。
参数：限流按蜂鸣器工作电流；PWM 频率=谐振频率附近最响。
PCB：驱动回路面积小；远离麦克风类敏感输入。

## 模块16 继电器控制强电

```
GPIO ──[1k]── NPN 基极
VCC ──[线圈]── 集电极，发射极 GND
续流二极管反向并联于线圈两端 ★必须
触点侧走线远离弱电区并留爬电距离
```
原理：小电流线圈磁吸开关大电流触点；断开瞬间线圈反电动势可达数十伏必须泄放。
参数：二极管选快恢复(如 1N4148 或 SS14)；触点容量按负载浪涌(电机类×5)选。
PCB：强弱电间距≥爬电要求(220V 场景 ≥2.5mm 起步)；驱动回路独立地路径。

## 模块17 光耦隔离信号

```
MCU ──[限流电阻]── LED侧 ──┐
                          (光耦合，电气完全隔离)
受控侧 ──[上拉]── C ── E ── 输出
```
原理：光传输实现两侧地系统彻底隔离。
参数：CTR 电流传输比随温度衰减需留 3 倍余量；速度等级按波特率选(6N137 类高速款)。
PCB：两侧器件与走线严格分区，隔离带≥爬电要求。

## 模块18 电源反接保护三方案

```
方案A 串联肖特基: 简单但恒损 VF×I
方案B PMOS 高边: 反接时 MOS 关断，正常时近乎零损 ★推荐
方案C 理想二极管控制器: 效率最优成本高
```
原理：利用 MOS 的体二极管方向性与栅控特性。
参数：MOS 的 Vds 耐压>最大反压；Rds(on) 核算发热。
PCB：功率路径宽铜；栅极保护电阻+稳压管防尖峰。

## 模块19 电平移位（3.3V↔5V）

```
单向: MCU TX ──[74LVC1T45/晶体管反相级]── 5V 器件
双向I2C: [BSS138+N×10k 上拉经典结构 ×2路]
```
原理：多数 5V 老芯片能读 3.3V 高电平(VIH 兼容)，反向则必须移位。
参数：逐引脚查双方 VIH/VOH 兼容表，别凭"感觉兼容"。
PCB：移位器靠近接收端；速率高时选专用双向自动方向芯片。

## 模块20 温度检测（NTC 分压）

```
VDD ──[固定电阻 Rf]──┬── ADC_IN
                   [NTC]
                     │
                    GND
```
原理：NTC 阻值随温度指数变化，分压后 ADC 读电压查表得温度。
参数：Rf≈NTC 中点温度阻值使曲线线性度最好段落在工作区间；自热校核 I²R<0.5mW。
PCB：NTC 贴近被测点(如功率管)；走线远离开关源。

## 模块21 红外接收头

```
VDD ──[100Ω]──┬── VCC(IR)
            [4.7μF+0.1μF]
OUT ──[10k 上拉]── GPIO   (载波 38kHz 解调后的脉宽编码)
```
原理：内置解调输出逻辑电平脉冲串，供电纹波直接变误码。
参数：供电 RC 按手册(纹波抑制关键)；上拉保证空闲高。
PCB：★供电独立性是第一要点，长 RC 就近贴头。

## 模块22 SD 卡座接口

```
SDMMC CMD/DAT0-3 ── 各串 [22~33Ω 可选]── 卡座
CD 检测脚 ──[上拉或下拉]── GPIO
VDD ──[10μF+0.1μF] 贴卡座
```
原理：SDIO 四位并行协议，初始化阶段低速后提速。
参数：上拉配置按模式切换(初始化需要 CMD/DAT 上拉)；高速档注意等长宽松但长度差 <15mm。
PCB：卡座金属壳接地腿全焊；插拔应力由壳腿承担。

## 模块23 WS2812 灯珠链

```
GPIO ──[330Ω]── DIN ──[灯珠1] DOUT ──[灯珠2] ...
每颗灯珠 VDD 就近 [0.1μF]
电源入口按每颗 60mA 峰值预算总电流
长链末端加 [数据缓冲/中继]
```
原理：单线归零码级联，每颗再生整形转发。
参数：首端串阻抑振；超过 ~30cm 或 20 颗考虑中继；供电压降核算(铜箔也扛不住几十颗同亮)。
PCB：电源按"分段注入"布线；DIN 走线短而直。

## 模块24 板间连接的"黄金组合"

```
信号: 2.54 排针+排母 或 BTB 板对板(密度高时)
电源: 每轨至少 2 针并联 + 多根 GND
防护: 关键信号串 100Ω + 对地 TVS
定位: 一角防呆(缺针)或键位错位设计
```
原理：插拔寿命、接触电阻、误插风险三者共同决定方案。
参数：每针按 1~3A 降额；GND 针数≥电源针数总和。
PCB：对接公差用腰孔或定位柱消化；排针焊接面朝向统一。

---

> 使用心法：先抄模块骨架保功能正确，再按本课程理论做本地化优化(去耦位置/回流路径/防护等级)。模块是起点不是终点。
