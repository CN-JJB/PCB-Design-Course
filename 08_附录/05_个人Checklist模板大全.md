# 附录五 个人设计 Checklist 模板大全

> 三份可直接复制的模板：每次设计逐项打勾，每完成一个项目把新教训补进去。版本号随迭代递增——这份文件就是你作为工程师的成长曲线。

---

## 模板 A：原理图评审 Checklist

```
版本: ____  日期: ____  评审人: ____

电源体系
[ ] 电源树图完整(每路来源/去向/电流)
[ ] 每个电压域的容量与降额核算过
[ ] 上电/掉电时序敏感器件已识别并处理
[ ] 保护链完整(保险丝/TVS/反接保护按需)

主控与数字
[ ] 每个 VDD/VDDA/VDDIO 引脚去耦电容齐全
[ ] VCAP/PDR_ON 等生命级引脚专项确认
[ ] BOOT/STRAP 配置脚全部有确定电平
[ ] 复位 RC 值核算且按键可强制
[ ] 晶振 CL 与外接电容匹配计算存档

接口
[ ] USB CC 电阻按规范配置
[ ] 差分对网络命名成对(P/N 后缀)
[ ] 外设接口的上拉/串阻对照参考设计
[ ] 所有对外接口有 ESD 预留位

质量闭环
[ ] ERC 零错误,警告书面豁免理由齐全
[ ] 封装分配 100% 且经 3D 目检
[ ] BOM 含立创编号+替代料列
[ ] 图纸分区注释可读性自查通过
```

## 模板 B：PCB 出货 Checklist(多层板全量版)

```
版本: ____  Gerber 冻结时间: ____

叠层与阻抗
[ ] 叠层对称性核对(材料+铜厚镜像)
[ ] 每信号层紧邻参考平面确认
[ ] 阻抗目标表填写并经厂家计算器反算闭环
[ ] 各 NetClass 线宽=计算值且冒烟测试通过

布局
[ ] 接口贴边/主控居中/电源直线链
[ ] 敏感区净空(晶振3mm圈/RF全层禁铜)
[ ] 元件距边≥3mm、安装孔禁布区干净
[ ] 高元件无干涉(3D 核对)

回流路径
[ ] 全部高速网络平面投影审查通过
[ ] 换层伴飞 GND 孔 100% 覆盖
[ ] 无跨分割信号(分割地图核对)
[ ] 缝合孔墙闭合(板边≤10mm)

差分与等长
[ ] 对内 gap 全程恒定(pad 豁免区除外)
[ ] 等长报告达标并存档
[ ] 蛇形 Pitch≥3w 复查

电源完整性
[ ] PDN 计算书与实际配置一致
[ ] Bulk/去耦位置距离量化复核
[ ] 平面分割缝宽≥0.5mm 且无穿越

EMC 预防
[ ] ESD 器件距连接器<5mm 双地孔
[ ] 时钟线远离边缘与接口
[ ] 未用 GPIO 策略已备注给固件组

制造交付
[ ] DRC 清零+报告归档
[ ] Gerber Viewer 六层? N 层全检
[ ] Check zone fills before plotting 已勾
[ ] 快照 zip 归档+CHANGELOG 更新
```

## 模板 C：焊接调试与复盘 Checklist

```
上电前
[ ] 放大镜目检(连锡/极性/pin1 方向)
[ ] 电源轨对地阻抗测量记录
[ ] 版本丝印与预期一致

上电仪式
[ ] 限流供电或快速触温检测
[ ] 各轨电压逐一核对±3%
[ ] 静态电流记入档案(基线)

功能验证
[ ] 心跳灯/调试口连接确认
[ ] 关键外设逐一初始化测试清单
[ ] 异常按"假设树"排查并记录每步证据

复盘(NOTES.md 四问)
[ ] 最大困难与解法
[ ] 设计不足清单(诚实!)
[ ] 新知识条目
[ ] 重来一次的改法

资产沉淀
[ ] 个人 Checklist 新增条目≥2 条
[ ] 踩坑案例入库(现象/根因/预防三段式)
[ ] 本项目可复用模块标注(下次直接搬)
```

使用建议：把三份模板打印塑封各一张，放在工位。电子版放工程仓库 docs/ 目录随版本走。**每一条勾选都是对未来的自己和团队同事的承诺。**
