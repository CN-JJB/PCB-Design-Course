# 为什么改

不同产品可能：

- 没有外壳；
- 没有 SMT 量产；
- 没有 EMC 认证；
- 没有 ICT；
- 没有 calibration；
- 有 FPGA / DDR / BGA；
- 有安全/汽车/医疗附加要求。

所以更可靠的方式不是“第 84 步必须做 ICT”，而是：

> **每个阶段有明确输入、输出和 Release Gate。**

# 使用原则

不要问：

> “我做到第几步了？”

优先问：

> **当前 Gate 的证据齐了吗？**

例如 Design Freeze Gate 必须证明 source/BOM/FW/Test 一致；Pilot Gate 必须有 FAI、FPY、defect 与 CAPA；Production Gate 必须能追溯完整产品配置。

这比机械完成 100 个动作更适合真实项目。
