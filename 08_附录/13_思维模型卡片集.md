# 附录十三｜思维模型卡片集

> 这些卡片是**提问工具，不是设计铁律**。每张卡都必须同时知道：为什么有用、何时适用、何时失效、最后如何工程检查。

## 卡片 01｜水系模型：电源路径

**Model**：把供电看成 source → path → load → return。  
**Why**：帮助发现压降、瓶颈和回路。  
**Use when**：电源树、去耦、DC IR、Buck。  
**Fails when**：把电磁传播简单等同于低频水流。  
**Engineering check**：画真实 current loop，并分别检查 DC / transient / frequency-domain。

## 卡片 02｜回声模型：反射

**Model**：阻抗不连续会让波产生反射。  
**Why**：建立 source-line-load 直觉。  
**Use when**：快边沿、长互连、connector/via。  
**Fails when**：只看“有没有回声”而忽略损耗、串扰、jitter。  
**Check**：td/tr、Z0、termination、TDR/IBIS/measurement。

## 卡片 03｜河床模型：Return Path

**Model**：信号导体与 reference 共同构成能量通道。  
**Why**：迫使你检查回流连续性。  
**Use when**：跨 split、换层、连接器。  
**Fails when**：把回流误解成“固定走最短几何路径”。  
**Check**：reference projection + transition map。

## 卡片 04｜天线直觉：EMC

**Model**：source + coupling path + antenna structure 才形成有效辐射/敏感路径。  
**Why**：避免“有时钟就一定超标”的单因素思维。  
**Use when**：EMI/EMC 诊断。  
**Fails when**：用 λ 的简单比例替代正式标准和实际结构。  
**Check**：source/path/antenna/return + A/B experiment。

## 卡片 05｜座位表模型：Placement

**Model**：器件位置由电流、信号、机械和热的邻接关系决定。  
**Why**：避免先摆整齐再补救。  
**Use when**：floorplan。  
**Fails when**：只按功能 block，不考虑装配/测试。  
**Check**：mechanical → connector → power → sensitive/high-speed → debug。

## 卡片 06｜先难后易：Routing Priority

**Model**：先处理最难返工、约束最强的路径。  
**Why**：保护 scarce routing resources。  
**Use when**：多接口综合板。  
**Fails when**：固定成“永远先时钟/永远先电源”。  
**Check**：对本项目做 routing-risk ranking。

## 卡片 07｜过孔收费站：Via Parasitics

**Model**：via 带来寄生、reference transition 和 routing resource 代价。  
**Why**：提醒“换层不是免费”。  
**Use when**：SI/PI/BGA。  
**Fails when**：变成“via 越少越好”。  
**Check**：layer span、stub、antipad、return transition、current capacity。

## 卡片 08｜谐振双刃剑：Capacitors

**Model**：真实 C/ESR/ESL 会产生频率相关行为。  
**Why**：避免“电容越多越好”。  
**Use when**：PDN/filter。  
**Fails when**：忽视 bias、安装电感和 load transient。  
**Check**：effective C、SRF、anti-resonance、layout、measurement。

## 卡片 09｜安装比本体贵：Mounting Inductance

**Model**：器件性能可能被连接几何支配。  
**Why**：解释去耦/TVS/滤波器为什么“料对但效果差”。  
**Use when**：高 di/dt / dv/dt。  
**Fails when**：把所有问题都归咎于距离。  
**Check**：完整 loop，不只量器件中心距离。

## 卡片 10｜对称是制造约束之一：Stackup Symmetry

**Model**：对称 stackup 有利于制造稳定性。  
**Why**：提醒翘曲/铜平衡。  
**Use when**：stackup/fab review。  
**Fails when**：把“视觉对称”当唯一 stackup 优化目标。  
**Check**：fab capability + reference adjacency + impedance + copper balance。

## 卡片 11｜参考决定场结构：Reference

**Model**：signal layer 的邻近 plane 决定主要场与 return behavior。  
**Why**：让层角色可解释。  
**Use when**：stackup / layer routing。  
**Fails when**：只说“最近 plane”而不看介质厚度、网络/continuity。  
**Check**：layer-role map。

## 卡片 12｜换层要带回流：Reference Transition

**Model**：signal via 与 return-current transition 必须一起设计。  
**Why**：减少 discontinuity / EMI。  
**Use when**：layer transition。  
**Fails when**：机械套用“旁边放一颗 GND via”。  
**Check**：前后 reference 是谁、是否同网、回流如何跨层。

## 卡片 13｜目标阻抗是预算：PDN Ztarget

**Model**：允许电压扰动与 transient current 可形成阻抗目标。  
**Why**：把“电源要稳”量化。  
**Use when**：系统级 PI 规划。  
**Fails when**：把教学 Ztarget 当器件官方 sign-off。  
**Check**：ΔV/ΔI assumptions + frequency range + device requirement。

## 卡片 14｜边沿是频谱入口：Edge Rate

**Model**：数字风险更多受 rise/fall time 驱动，而非只看 fundamental clock。  
**Why**：筛选 SI/EMC critical nets。  
**Use when**：高速判断。  
**Fails when**：把 edge rate 当唯一决定因素。  
**Check**：td/tr + geometry + source/load + interface requirement。

## 卡片 15｜屏蔽先问电流：Shield/Chassis

**Model**：shield 的价值取决于高频电流如何闭合。  
**Why**：避免“接地/不接地”的口号战。  
**Use when**：connector/cable/enclosure。  
**Fails when**：用 λ/20 等单一经验数字替代结构分析。  
**Check**：seam、bond、chassis current path、compliance evidence。

## 卡片 16｜TVS 是电流路径器件：ESD

**Model**：TVS 的 clamp 只有在低寄生 current path 下才有意义。  
**Why**：解释 placement 的重要性。  
**Use when**：外部接口防护。  
**Fails when**：固定成“必须离连接器 X mm”。  
**Check**：entry → TVS → return → protected node。

## 卡片 17｜等长是时间预算的表达

**Model**：长度差只是传播时间差的一种代理。  
**Why**：避免为视觉等长制造蛇形。  
**Use when**：SDIO/FMC/DDR。  
**Fails when**：不看 protocol timing / layer delay / via。  
**Check**：timing margin → ps → geometry → actual route。

## 卡片 18｜DRC 只检查可编码规则

**Model**：自动检查只能覆盖明确表达给工具的约束。  
**Why**：提醒 manual Design Review。  
**Use when**：任何 release。  
**Fails when**：反过来否定自动化价值。  
**Check**：DRC/ERC + manual SI/PI/EMC/DFM + evidence。

## 卡片 19｜实物是模型的校验器

**Model**：实测用来验证/修正设计假设。  
**Why**：避免只凭仿真或经验。  
**Use when**：bring-up/validation。  
**Fails when**：一次测量被当作普遍结论。  
**Check**：probe、condition、repeatability、A/B。

## 卡片 20｜复盘复利：Fault Log

**Model**：每个 bug 都转成可复用规则/测试。  
**Why**：让经验可积累。  
**Use when**：debug/ECO。  
**Fails when**：只写“以后注意”。  
**Check**：symptom → root cause → fix → side effect → retest → checklist。

## 卡片 21｜诚实的保守主义：Engineering Claim

**Model**：明确知道什么、假设什么、还没验证什么。  
**Why**：防止 TBD 被包装成事实。  
**Use when**：所有 Design Review / release。  
**Fails when**：变成“不敢做任何决策”。  
**Check**：REQ / TARGET / FAB / MEASURED / EXAMPLE / HEURISTIC 标签化。

## 使用规则

抽一张卡时不要背标题。至少回答：

1. 它解释什么？
2. 它在哪些条件下有用？
3. 什么情况下会误导？
4. 对当前板子要检查哪一项 evidence？
