# 13｜Part 9 参考资料与工具基线

## 1. KiCad

当前课程工程交付基线：

- KiCad 10.0.x stable；
- CI pin：`kicad/kicad:10.0.5` 官方 Docker image；
- `kicad-cli`；
- Jobsets；
- Design Variants；
- ERC / DRC；
- Gerber / drill / position；
- IPC-D-356 / ODB++ / IPC-2581 / STEP 等输出能力。

实际 release 前核对当前稳定 patch 与官方文档。

官方入口：

- https://docs.kicad.org/10.0/en/cli/cli.html
- https://www.kicad.org/download/docker/

## 2. 制造与装配资料

优先使用：

1. PCB fabricator current capability / stackup；
2. assembly house process / rotation convention / panel rule；
3. component manufacturer package / handling documents；
4. applicable IPC / IEC / product standards。

课程不会用单一板厂规则冒充全行业标准。

## 3. Source Freeze

每个 production release 保存：

```text
source
document/revision
retrieved date
applies to
local design decision
reopen trigger
```

## 4. Tool Freeze

同时保存：

```text
KiCad version
Vivado version (FPGA)
firmware toolchain
test software
fixture revision
```

工具版本是硬件可复现性的一部分。
