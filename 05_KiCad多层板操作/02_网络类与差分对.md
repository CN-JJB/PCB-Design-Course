# 第二章 网络类与差分对：规则的精细化管理

> 目标：把"不同网络不同待遇"做到极致——Net Class 体系、自定义规则语法（.dru）、差分对定义与布线的全部细节。

---

## 2.1 Net Class 进阶：多层板的标准类配置

六层项目的典型网络类规划：

| 类名 | 线宽 | 过孔(盘/孔) | 差分? | 典型成员 | 设计依据 |
|------|------|------------|------|---------|---------|
| Default | 0.2 | 0.6/0.3 | 否 | 普通GPIO | 工艺+手焊 |
| POWER_3V3 | 0.5~0.8 | 0.8/0.4 | 否 | +3V3 主干 | 载流 |
| POWER_1V8 | 0.5 | 0.8/0.4 | 否 | DDR供电 | 载流 |
| USB_HS | 计算值 | 0.6/0.3 | 是 | USB_DP/N | 90Ω±10% |
| ETH_MDI | 计算值 | 0.6/0.3 | 是 | TXRX0_P/M… | 100Ω±10% |
| CLK_50M | 0.25 | 0.6/0.3 | 否 | REF_CLK | 等长±2mm |

要点回顾（二层板章已学）+ 多层板新增技巧：

### 技巧一：用原理图属性自动归类

原理图里给符号加字段 `Net Class`，KiCad 同步时自动入类。适合大规模网络管理。

### 技巧二：Default 类保持最宽松

所有漏网网络都落 Default——它应该是"安全但保守"的兜底配置，绝不要把高速要求塞进 Default。

## 2.2 自定义规则 Custom Rules：超越类的表达力

当类无法表达的细粒度需求出现（如"某两根线之间间距必须 ≥0.5mm"、"BGA 区域内过孔缩小"），用规则语言。Board Setup → Design Rules → Custom Rules，语法基于 KiCad DRU：

```
示例1：USB 差分对到其他任何铜的间距 ≥ 0.3mm
(rule usb_isolation
    (constraint clearance (min 0.3mm))
    (condition "A.NetClass === 'USB_HS' && B.NetClass !== 'USB_HS'")
)

示例2：所有过孔孔径不得小于0.25
(rule via_min
    (constraint hole_size (min 0.25mm))
    (condition "A.Type === 'via'")
)

示例3：时钟线长度限制
(rule clk_length
    (constraint length (max 60mm))
    (condition "A.NetName === 'REF_CLK50'")
)
```

常用条件字段：`A.NetClass / A.NetName / A.Layer / A.InDiffPair()` 等。完整参考：官方文档 Custom Design Rules 页面。

> 【策略】能用 Net Class 解决的不写规则；规则文件(.kicad_dru)随工程保存可复用——积累一年后你会有一套自己的规则库。

## 2.3 差分对的定义与验证

### 定义三要素

Board Setup → Differential Pairs（差分对）页，每个差分类需要：

| 参数 | 含义 | USB90 例 | ETH100 例 |
|------|------|----------|-----------|
| Gap 间距 | 两线边缘距 | 由计算器反解 | 同左 |
| Trace width | 单根线宽 | 同上 | 同上 |
| Via size/drill | 对内过孔 | 0.6/0.3 | 0.6/0.3 |
| Uncoupled allowed? | 松耦合段容许 | 勾选(焊盘附近必然松耦) | 勾选 |

**关键认知**：Gap 和 Width 必须来自阻抗计算器按目标差分阻抗的反解（第四部分第二章的方法论），不是拍脑袋。

### 网络命名触发差分识别

KiCad 通过后缀识别差分对：

- `_P/_N`：USB_DP / USB_DN
- `+/-`：ETH_TX0+ / ETH_TX0-
- `_p/_n` 小写同样有效

命名对了，布线工具才认得这是一对。

### 验证流程

```
① 原理图确认两个网络的命名成对
② Board Setup 里该类的 w/gap 已填计算结果
③ PCB 里 Route → Differential Pair 试走一小段
④ 选中走线看属性面板显示的实际 gap
⑤ 用 U 高亮整对确认无断裂
```

## 2.4 差分布线的操作细节大全

### 基本动作

```
快捷键 6 或 Route → Differential Pair
点击 P 线焊盘出发：
- 两线自动镜像跟随
- V 同时打一对孔
- Shift+R 切换推挤模式同单线
- 结束双击

拐角纪律：45° 对称拐，禁止一先一后的阶梯拐
出焊盘段：允许松耦合（gap 变大），
         但离开 pad ≥0.5mm 后必须收紧到目标 gap
```

### 松耦合段的 DRC 管理

焊盘附近天然做不到紧耦合，两种处理：

1. KiCad 默认对差分对只查"对内间距 ≤ 设定 gap 的容差"，出焊盘区域自动豁免一部分
2. 严格协议（HDMI）手工检查每一段，或用 Custom Rule 限定"除 pad 1mm 内外全程 gap=目标"

### 差分对换层的回流配套

理论篇铁律的操作化：

```
每次 V 打对孔后，立刻在孔旁补 1~2 个 GND 孔
（距离 ≤1mm）。养成肌肉记忆：
打一对差分孔 = 顺手再点两个地孔。
```

## 2.5 单端线的等长意识预置

不是只有差分需要长度概念。源同步总线（RGMII/SDRAM 的时钟与数据）需要"组内相对等长"——这属于第三章 Length Matching 的范畴，此处先建立规则占位：

```
为每组需要匹配的网络建一个 Group：
右键网络 → Assign Net Class? 不对，
是 PCB 编辑器的 Nets 面板中选中多个网络
→ 右键 Create Group from Nets → 命名如 DDR_D0_7
之后等长工具以 Group 为单位工作。
```

## 2.6 规则配置的验收测试

规则配完不等于生效，做三个冒烟测试：

```
测试1：故意把一根 Power 网络画成 0.2mm
      → DRC 应报 track width 违规 ✓
测试2：故意让 USB 对内 gap 拉大到 0.5mm 一小段
      → DRC 应报 diff pair gap 违规 ✓
测试3：Custom Rule 若写了隔离规则，
      在 USB 对旁边 0.25mm 处拖一根普通线
      → 应报 clearance ✓

三个测试通过 = 你的规则体系真实生效。
这套"故意犯规"验证法值得用于任何规则修改之后。
```
