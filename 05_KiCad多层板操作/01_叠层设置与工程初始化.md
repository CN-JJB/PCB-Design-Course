# 第一章 叠层设置与工程初始化：六层板的开工仪式

> 目标：30 分钟内在 KiCad 中完成一个六层工程的全部初始化——叠层参数、板框、层命名、预定义尺寸。这是每个多层板项目的固定第一步，练到形成肌肉记忆。

---

## 1.1 Board Setup 总览

PCB 编辑器 → File → Board Setup（文件→板子设置）：

```
┌─ Board Setup ──────────────────────────┐
│ ├─ Design Rules 设计规则                │
│ │   ├─ Constraints 约束(全局最小值)      │
│ │   ├─ Pre-defined Sizes 预定义尺寸      │
│ │   └─ Net Classes 网络类               │
│ ├─ Layers / Board Stackup 层叠管理 ★    │
│ ├─ Differential Pairs 差分对 ★          │
│ ├─ Text and Drawings 文字默认值         │
│ ├─ Masks and Pastes 阻焊钢网外扩        │
│ └─ Default Fields 默认字段              │
└────────────────────────────────────────┘
本章处理 Stackup 与板框，其余各章展开。
```

## 1.2 层数设置与叠层编辑

### 切换层数

Layers（图层）页 → Copper Layers 下拉：4 或 6。

> 注意：KiCad 的层数切换是全局的。从二层改四层后，In1.Cu/In2.Cu 出现；改六层出现 In1~In4。

### Stackup 编辑器——本节核心

进入 Board Setup → Physical Stackup（物理叠层）。KiCad 9 提供完整的制造级叠层表达：

| 可编辑项 | 填什么 | 来源 |
|---------|--------|------|
| 每铜层的 Thickness | 如 0.035mm | 板厂参数表 |
| Dielectric 介质层 | 类型选 Core/Prepreg | 同上 |
| 介质厚度 | 如 0.2104mm | JLC 官方层压结构 |
| εr / tanδ | 4.4 / 0.02 | 材料规格 |
| Layer Name | 自定义如 SIG_TOP | 你的命名习惯 |
| Layer Type | Signal / Power plane / Mixed | 影响显示与规则 |
| Impedance Control 勾选 | 对需要控阻的层打勾 | 你的设计需求 |

以 JLC 六层 JLC06161H-1708 类方案填写示例：

```
L1  F.Cu   Signal  铜 35μm    ── PP 0.1mm
L2  In1.Cu GND     铜 17μm    ── PP 0.21mm  
L3  In2.Cu Signal  铜 17μm    ── 芯板 Core 0.3mm
L4  In3.Cu PWR     铜 17μm    ── PP 0.21mm
L5  In4.Cu GND     铜 17μm    ── PP 0.1mm
L6  B.Cu   Signal  铜 35μm
总厚 ≈1.6mm（数值以厂家当期公布为准）
```

### 为什么必须认真填叠层（而不是随便过）

三个下游功能吃这些参数：

1. **内置阻抗计算**：填好后走线时状态栏可显示实时阻抗估算
2. **Gerber X2 元数据**：板厂解析时自动获得叠层意图
3. **团队沟通**：叠层即文档，评审者打开就懂

## 1.3 层命名与颜色规范

Board Setup → Layers 页可以重命名每层并设颜色。推荐命名法：

```
L1: TOP_RF? / SIG_TOP
L2: GND1
L3: SIG_MID1
L4: PWR_PLANE
L5: GND2
L6: SIG_BOT

配色建议(个人习惯即可)：
GND 层统一深绿、PWR 统一橙、信号层红/黄/青区分。
一眼识别"这根线在哪类层"减少误操作。
```

## 1.4 多层板特有的约束项

Constraints 页在二层板基础上增加关注点：

| 参数 | 六层板推荐 | 说明 |
|------|-----------|------|
| Minimum clearance | 0.15mm | 打样能力内留余量 |
| Minimum track width | 0.13mm | 高密度区域允许更细 |
| Min through via | 0.45/0.2mm | 标准 |
| Min blind/buried via | 不启用 | 本课程不用盲埋孔 |
| Hole to hole | 0.5mm | 过孔密集区防孤岛带 |
| Copper to edge | 0.4mm | 平面层留边更宽 |

## 1.5 板框与机械层再升级

多层板的板框流程同二层板，补充三点：

### 安装孔阵列模板化

复杂板安装孔多（四角+中部+屏蔽罩脚），先放一个 MountingHole 封装调好属性，Ctrl+D 复制其余，坐标用 Place → Drill/Place Origin 配合定位。

### 分区规划先行

六层板元件多，开工前在 Edge.Cuts 内侧用 User.Drawings 层画分区参考框（不参与制造），布局时按区推进：

```
┌─────────────────────────────┐
│ [接口区]  [电源区]  [MCU区]    │
│           [存储区]           │
│ [调试区]                      │
└─────────────────────────────┘
```

### 3D 检查常态化

六层板高度方向的干涉风险更高（屏蔽罩、排针、模组天线），养成每完成一个区按 3 看一次的习惯。

## 1.6 工程初始化 Checklist（背下来）

```
新六层工程 30 分钟标准流程：
[ ] 新建工程+命名规范(项目名_vX.Y)
[ ] Board Setup: 层数 6
[ ] Stackup: 按板厂参数表逐层填入(截图存档对照)
[ ] 层重命名+配色
[ ] Constraints: 全局最小值
[ ] Net Class: 创建 Signal/PWR/DIFF_USB/DIFF_ETH 等
[ ] Differential Pairs: 定义各类的线宽/间距目标
[ ] Pre-defined Sizes: 预设常用线宽/过孔快捷档位
[ ] 板框+圆角+安装孔
[ ] 从原理图 F8 同步元件
[ ] 保存快照 zip
```
