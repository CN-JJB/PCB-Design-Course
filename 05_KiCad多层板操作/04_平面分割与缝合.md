## 4.1 电源平面分割实战

### 场景设定

六层方案一（SIG-GND-SIG-PWR-GND-SIG），L4 是 PWR 平面，需要承载：+5V（入口）、+3V3（主）、+1V8（DDR 供电）、+1V1（H7 核心供电，假设）。

### 分割设计原则回顾（理论篇）+ 操作化

```
① 先在纸上画分割地图：
   按各电压域的负载物理位置切块——
   DDR 集中在一角 → +1V8/+1V1 放那一角
   MCU 在中央 → +3V3 占中央大区
   入口在板边 → +5V 一条带
② 区域间隔离缝 ≥0.5mm(耐压) 
   同为低压域也建议 ≥0.5mm 保持工艺一致
③ 每个区域尽量方正，杜绝细长走廊和半岛
④ 高速信号投影检查：
   L3 的信号绝不能跨缝！(L3 参考 L2 GND 不受 L4 影响，
   但 L1/L6 若参考了 PWR? 本叠层不涉及——
   这正是选好叠层的红利)
```

### KiCad 操作流

```
方法：同层多个 Zone + 优先级

① Zone1: 整层先铺 +3V3（Priority 0，垫底）
② Zone2: +1V8 区块（Priority 1）
③ Zone3: +1V1 区块（Priority 1）
④ Zone4: +5V 条带（Priority 1）

填充逻辑：优先级高的 Zone 先"挖走"自己的地盘，
剩余区域归低优先级的大 Zone —— 天然实现分割。

每个 Zone 的设置：
- Layer: In3.Cu (PWR 层)
- Net: 对应电压网络名
- Pad connection: Direct(平面无热焊盘问题? 
  实际上平面上的过孔连接用 Thermal 与否影响焊接，
  电源过孔多为免焊导通 → Direct 即可)
```

### 分割的验收检查

```
[ ] B 重填充后切换到该层单层视图目检：
    各区域边界清晰无缝隙重叠
[ ] 缝宽实测 ≥0.5mm（测量工具量）
[ ] 无任何走线/过孔落在缝上或跨缝
    （DRC 的 zone to zone clearance 会抓大部分）
[ ] 每个用电芯片的正下方属于它的电压域
    （对照布局图逐个核对供电来源）
[ ] 域边界处有去耦电容骑缝
    （跨域器件如电平移位器的两侧各配电容）
```

## 4.2 多层板的敷铜策略全景

六层板每层的铜角色分工：

| 层 | 角色 | 敷铜策略 |
|----|------|---------|
| L1/L6 外层信号 | 走线为主 | 空白区铺 GND，与内层地通过缝合孔连成一体 |
| L2/L5 地 | 回流基石 | **整层实心 GND，零分割零走线** |
| L3 内层信号 | 带状线 | 空白区铺 GND |
| L4 电源 | 分配 | 按上文多 Zone 分割 |

外层空白区铺 GND 的价值：

- 为表层走线提供共面参考改善阻抗一致性
- 散热扩散
- 屏蔽（配合缝孔墙形成半封闭笼子）

注意外层敷铜与高速线的间距适当放大（0.3~0.4mm），避免共面耦合改变阻抗（理论篇 Coplanar 概念）。

## 4.3 缝合孔墙的系统布置

### 三大地带必布

```
① 板边一圈：间距 10mm（λ/20@1GHz 判据）
② 接口区周边：更密(5~8mm)，把地引到最前沿
③ 敏感区围墙：RF/晶振/时钟区四周
```

操作上用上一章的 Via Stitching 工具批量生成，再手工补密关键点。

### 缝合孔的三查

```
查连通：U 键抽查任意缝合孔是否高亮到主 GND 网络
       （被反焊盘孤立的孔是无效装饰！）
查间距：孔边到孔边 ≥0.5mm 防止连续挖空带
查位置：不在细走线之间硬挤（挤出的蛇形走线得不偿失）
```

## 4.4 散热焊盘与过孔阵

QFN/BGA 中央盘、DCDC 功率地、LDO 接地腿的热管理：

```
热路径设计：
正面焊盘 → 过孔阵(2×2 到 5×5 视功耗) → 背面大片铜

过孔阵参数经验：
- 孔径 0.3mm / 盘 0.6mm
- 中心距 0.8~1.0mm
- 打样阶段孔内塞锡(手焊时从背面补)提升导热

KiCad 操作：
封装自带 thermal pad 已含过孔阵(官方库多数已做)
自制封装时手动阵列复制即可
```

## 4.5 电源树的文档化落地

复杂电源域必须有一张图防止接线混乱：

```
+5V ──┬─ USB VBUS 直通
      ├─ DCDC1 → +3V3 主域 ──┬─ MCU/PHY/Flash…
      │                      ├─ LDO → +1V1 核心域(H7)
      │                      └─ LDO → +VDDA 模拟域
      └─ DCDC2 → +1V8 DDR 域

PCB 落地核对表：
[ ] 每条域在 PWR 层有专属 Zone 或明确粗线路径
[ ] 每个芯片引脚可追溯到唯一源头(防串域)
[ ] 域间的电平转换器件两侧去耦齐备
[ ] 上电顺序敏感的域(如核心先于IO)有软启动电路
```
