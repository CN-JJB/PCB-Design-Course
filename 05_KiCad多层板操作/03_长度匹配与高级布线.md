# 第三章 长度匹配与高级布线：蛇形线的艺术

> 目标：掌握 KiCad 三种长度调节工具的适用场景、蛇形线的设计纪律，以及推挤布线、批量过孔缝合等高级操作。学完你就有资格碰 HDMI 和 DDR。

---

## 3.1 什么时候需要等长：先算账再动手

等长不是仪式，是时序预算：

```
FR4 中信号延迟 ≈ 6~7 ps/mm（外层略快内层略慢）

判断流程：
① 查协议/芯片手册的 skew 预算
   例：HDMI 组内允许 ±0.15×Tbit? 
       3.4Gbps 时 Tbit≈294ps → 允许差约 ±44ps?
       换算长度容差 ≈ ±6mm? 实践按规范书给的 mm 值执行
② 量实际布线长度差
③ 差值 > 容差 → 补长(蛇形)
④ 差值 < 容差 → 别动它！

反例警示：给 12Mbps USB 走精确等长纯属浪费时间；
          给 HDMI 数据对不做组内匹配则是真事故。
```

各协议等长要求速查（详见理论篇总表）：

| 对象 | 匹配对象 | 典型容差 |
|------|---------|---------|
| USB 高速 | 对内 | <1mm |
| 千兆 MDI | 对内 | <0.5mm |
| HDMI 数据对内 | 对内 | ±0.1~0.2mm |
| HDMI 对间(数据vs时钟) | 组间 | ±5×对内容差 |
| RGMII CLK↔DATA | 组间 | 按 tCO 算，常 ±0.25ns≈±35mm 内 |
| SDRAM fly-by | 地址命令时钟链 | 拓扑序+分段预算 |

## 3.2 KiCad 的三种调长工具

Route 菜单下的 Length Tuning 家族：

| 工具 | 快捷键 | 用途 |
|------|--------|------|
| Tune Track Length 单线调长 | 7? （Route→Tune） | 把一根线补到目标长度 |
| Tune Differential Pair | Route→Tune Diff Pair | 把一对补到目标 |
| Tune Skew of Diff Pair? / Match Tuning? | — | 以参照线为基准补齐差值 |

### 工作流：以"匹配组"为中心

```
① 建组：Nets 面板选中同组网络 → Create Group
        如 HDMI_D2±、HDMI_D1±、HDMI_D0±、HDMI_CLK±
② 先全部正常布通（不管长度）
③ 找出最长的一根作为基准
④ 逐根用 Tune 工具补长：
    点击目标走线 → 移动鼠标实时生成蛇形
    屏幕显示 当前长度/目标长度 进度条
⑤ 目标设定方式二选一：
    - 手动输入目标值（从测量最长者得到）
    - Tune to baseline? 选基准线自动对齐(KiCad 9 支持选参照)
⑥ 全组完成后跑 DRC + 用"网络长度报告"复核
```

### 长度报告

Inspect → Net Inspector（网络检查器）列出每根线的实际长度——等长验收的最终依据。可导出 CSV 存档进设计文档。

## 3.3 蛇形线设计纪律

蛇形不是越密越好：

```
参数三要素：
Amplitude 振幅 A：蛇形单元的高度
Pitch 间距 P：相邻平行段中心距
Segment 段长

铁律：
P ≥ 3w（否则蛇形自身自耦合，
      等效阻抗变化+边沿降速，越补越糟）
A ≥ 2×gap? 一般取 A=5~10×w 视空间
避免在 BGA 逃逸区/过孔密集区蛇形

位置选择：
优先在开阔区域补；靠近接收端或驱动端均可，
但全组保持一致风格（都靠收端或都靠发端）
```

## 3.4 推挤布线的高级玩法

多层板密度高，Shove 模式是主力：

```
Shift+R 循环切换：Highlight → Shove → Walkaround
Shove 下再配合：
- 拖动整段已有走线(D 键)让邻居自动让路
- Ctrl+点击 在任意点固定当前形状继续规划
- 删除半段后重连：Backspace 回退

密集区心法：先拉主干通道(预留 ≥3w 间距的走廊)，
           再让支线汇入——像修高速公路网而不是迷宫。
```

## 3.5 过孔缝合工具：一键缝完板边

手动打几十个缝合孔是苦役，KiCad 有自动化工具：

```
Tools → Via Stitching/Fill Areas → Stitching? 
（工具→过孔填充/缝合）

设置面板关键项：
- Grid pitch 缝合网格间距：10mm(EMC 推荐 λ/20@1GHz)
- Via size/drill：0.6/0.3 标准款
- Net: GND
- Scope: 只缝指定区域还是全板
- 与现有铜的最小距离 clearance

生成后它们是普通过孔，可单独删除微调。
板边一圈+敏感区周边是必缝地带。
```

同理有 **Via Filling Zones**（铜区自动阵列地孔），用于大敷铜区的均匀钉扎。

## 3.6 微调与返工技巧

| 场景 | 技巧 |
|------|------|
| 蛇形加完后想改路径 | 直接拖动，蛇形跟随变形 |
| 等长差一点不够空间蛇形 | 换到更宽松的另一层重新走该段 |
| 组里一根被迫绕远导致全员重配 | 接受新基准，全组重新 Tune（工具会删旧蛇形重排） |
| 密脚 BGA 出线拥挤 | 相邻两列交替向不同方向逃逸+错开过孔 |
