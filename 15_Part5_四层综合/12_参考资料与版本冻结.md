# 12.1 STM32F407 核心资料

## Product / Datasheet

- STM32F407VG product page  
  https://www.st.com/en/microcontrollers-microprocessors/stm32f407vg.html

用途：

- 外设能力；
- package / memory / communication overview；
- active product status。

当前 ST 产品页仍列出：

- up to 168 MHz Cortex-M4；
- 2 × CAN 2.0B；
- SDIO；
- USB 2.0 FS OTG on-chip PHY；
- Ethernet MAC 等。

V2 只选择其中 USB/CAN/SDIO。

# 12.2 RM0090 Reference Manual

ST RM0090：STM32F405/407/415/417 等 Reference Manual。

重点用于：

- clock tree；
- GPIO alternate function；
- USB OTG FS；
- bxCAN；
- SDIO；
- DMA；
- reset / RCC。

RM0090 对 SDIO 描述包括：

- CK；
- CMD；
- D[7:0]；
- SD card 1-bit / 4-bit bus；
- SDIO adapter clock 与 PCLK2 约束。

但 Reference Manual **不能替代 silicon errata**。

---

# 12.3 ES0182 Device Errata

STM32F405/407xx and STM32F415/417xx device errata。

Part 5 重点：SDIO。

当前 errata 明确列出：

- hardware flow control 可导致错误数据；
- response CRC status 特定限制；
- clock divider BYPASS 限制；
- NEGEDGE mode data corruption；
- 特定 clock relationship 下的 underrun/错误传输风险。

因此 release 时必须记录：

```text
MCU silicon revision:
Errata revision reviewed:
SDIO workarounds implemented:
Firmware owner:
Validation evidence:
```

# 12.4 ST AN4488 Hardware Development

用途：

- VDD/VSS；
- VDDA/VSSA；
- VCAP；
- reset/boot；
- oscillator；
- hardware bring-up 基础。

任何 MCU special power pin 的设计优先遵循器件 datasheet / AN4488，而不是通用 PI 公式。

---

# 12.5 ST AN4879 USB Hardware and PCB Guidelines

当前检索版本：**AN4879 Rev 10, January 2025**。

用途：

- STM32 USB peripheral implementation；
- FS/HS distinction；
- USB PCB guideline；
- ESD placement；
- VBUS / connector considerations。

V2 是 USB FS device-only，因此不要把 HS external PHY 的要求混进来。

---

# 12.6 USB-IF Type-C Specification

USB Type-C Cable and Connector Specification 当前公开 Release 2.5：

- 发布：2026-04-08。

用途：

- receptacle pin/function；
- CC behavior；
- source/sink role；
- connector requirements。

V2 只做 USB2 device/UFP，不做 PD/Alt Mode。

**Type-C connector ≠ USB Power Delivery。**

# 12.7 CAN 资料

## STM32

STM32F407 的 controller 是 bxCAN / classic CAN 2.0B。

## Transceiver

本课程 V2 以 TI `TCAN332` / TCAN33x family 作为 3.3 V transceiver 学习参考。

当前 TCAN33x datasheet：

- Rev F；
- revised May 2025。

最终量产选型要重新核：

- bus fault voltage；
- common-mode range；
- IEC ESD；
- standby；
- temperature；
- propagation delay；
- supply / logic compatibility。

## Protection Reference

TI TIDA-00629：

- CAN IEC ESD；
- EFT；
- Surge；
- external protection topology；
- verified test approach。

它用于学习“保护路径如何验证”，不是要求 V2 照抄 BOM。

# 12.10 Source Hierarchy

当资料冲突时，优先级通常是：

1. 当前器件 datasheet / errata；
2. 当前 official interface specification；
3. vendor hardware/application guide；
4. target fabricator capability；
5. verified reference design；
6. textbook / engineering handbook；
7. forum / blog / community experience。

论坛能帮你发现问题，但不要让论坛成为关键限制的唯一依据。
