# 04｜布局分区与器件优先级：先放“不能错的位置”，再放“还能挪的器件”

> 综合板布局不是把器件摆得整齐，而是决定以后所有电流、回流、保护、布线和调试是否容易。

---

# 4.1 先做 Board Zoning，不急着放 0402

先只画功能区：

```text
┌──────────────────────────────┐
│ USB-C / ESD │ MCU CORE │ SWD │
│              │          │     │
│              │          │     │
│ CAN / TVS    │ POWER    │ SD  │
└──────────────────────────────┘
```

这不是最终布局，只是在回答：

- 哪些功能必须靠板边；
- 哪些功能必须靠 MCU；
- 哪些噪声源要和敏感区隔离；
- 哪些连接器需要自然的流向。

---

# 4.2 第一类：机械位置几乎锁死的器件

优先放：

1. USB-C receptacle；
2. CAN connector；
3. microSD connector；
4. mounting holes；
5. SWD / programming interface；
6. 按键、LED、用户可触及器件。

为什么？

这些器件受：

- 外壳；
- 插拔方向；
- 人手；
- 线缆；
- fixture；

约束，比电气走线更难事后移动。

---

# 4.3 第二类：必须紧贴边界的保护器件

## USB

```text
USB-C
→ ESD
→ optional tuning
→ MCU
```

ESD 的“靠近”不是追求某个固定 mm 数，而是：

- connector 进板后尽快进入 protection；
- unprotected branch 尽可能短；
- discharge path 短、宽、低感；
- protected-side 与 unprotected-side 不在空间上重新耦合。

## CAN

```text
CAN connector
→ TVS / protection
→ optional CMC / termination zone
→ transceiver
→ MCU
```

把 bus transient 尽量限制在 connector zone。

---

# 4.4 第三类：MCU 周围的“黄金位置”

MCU 周围的位置非常稀缺。

优先顺序：

1. VCAP；
2. 每个 VDD decoupler；
3. VDDA decoupling；
4. HSE crystal + load network；
5. USB source/tuning footprints；
6. SDIO_CLK source resistor footprint；
7. reset/boot small parts。

普通 LED、电阻阵列、排针不要抢这些位置。

---

# 4.5 去耦布局看完整 Loop

正确思维：

```text
Cap VDD pad
→ MCU VDD pin
→ internal switching load
→ MCU VSS pin
→ GND plane
→ Cap GND pad
```

布局 Review 不只测“电容中心到引脚多少 mm”。

还要看：

- VDD pin → cap 是否直接；
- cap GND 是否直接落 L2 GND；
- 是否多个 cap 共用长窄 neck；
- via 是否造成大 detour；
- capacitor orientation 是否让 loop 变长。

---

# 4.6 晶振区：不是“禁铜区”，而是受控小回路

目标：

- 晶振与 MCU oscillator pins 形成极小回路；
- 不让其他高速/大电流线穿过；
- 参考与 guard 策略按 ST oscillator guidance；
- load capacitors 的回流清楚；
- crystal node 不靠近 connector / SW node / CAN bus。

不要用一句：

> “晶振下面必须什么都没有。”

替代具体芯片和 oscillator guideline。

---

# 4.7 USB Placement

理想拓扑：

```text
board edge
│ USB-C │ ESD │      D+/D-       │ MCU │
```

检查：

- connector 到 ESD 无 branch；
- D+/D- 不绕过其他 block；
- pair 能保持相似环境；
- path 下方 L2 GND 连续；
- 不被 SDIO/CAN connector 迫使换层；
- VBUS 与 D+/D- 不产生大段不必要平行。

---

# 4.8 SDIO Placement

microSD 最好和 MCU 某一侧形成**短、扇形、低交叉**的连接。

优先观察：

- CLK 能否直接；
- CMD / D0-D3 是否自然展开；
- connector pin order 是否制造交叉；
- source resistor 是否能靠 MCU；
- pull-up 是否能放在不妨碍 routing 的位置；
- card power decoupling 是否靠 connector supply pin；
- card detect 是否远离高速组。

### 不要为了“等长”牺牲布局

如果布局本身很差，再用大量 meander 补长度，只是在把错误藏起来。

先减少：

- outlier；
- via 数；
- crossing；
- parallel aggressor exposure。

再谈需要多少 matching。

---

# 4.9 CAN Placement

CAN transceiver 不是必须紧贴 MCU。

它更应该服务于**connector boundary**。

常见合理关系：

```text
MCU  ─ logic traces ─  CAN PHY ─ protection ─ connector
```

逻辑侧通常比 CANH/CANL bus-side 更容易在板内延伸。

所以：

- transceiver 靠 connector zone 通常更合理；
- bus-side protection 更接近 connector；
- CANH/CANL 不穿 MCU core；
- termination/CMC 有空间；
- bus ground/shield 可以在边界处理。

---

# 4.10 Power Placement

USB 5 V 从 connector 进入后：

```text
VBUS
→ input protection / bulk
→ regulator
→ 3V3 distribution
```

不要让 5 V entry path 穿过晶振、USB pair 或 SDIO group。

Regulator placement 同时考虑：

- input cap loop；
- output cap loop；
- thermal copper；
- 3V3 distribution；
- test points；
- 未来可能替换 buck 的空间。

---

# 4.11 SWD / Test Point Placement

调试接口要考虑实际手：

- cable 插头高度；
- probe body；
- USB-C 插头同时存在；
- CAN terminal 线材；
- microSD 插卡方向。

Test point 建议至少覆盖：

- 5V；
- 3V3；
- GND；
- NRST；
- SWDIO；
- SWCLK；
- USB D+/D-（如果测量方案需要）；
- CAN TX/RX logic；
- CANH/CANL 测量位；
- SDIO_CLK；
- optional UART TX/RX。

测试点本身也有寄生，不能随便给关键高速线拉长 stub。

---

# 4.12 Placement Review：按电流而不是按美观

对每个 block 问：

### USB
- connector → ESD → MCU 是否单向流动？
- ESD discharge path 到哪里？

### CAN
- cable transient 在哪里被截住？
- bus current 在哪里闭合？

### SDIO
- CLK 从 source 到 card 是否短且直接？
- return plane 连续吗？

### MCU power
- 每个 decoupling loop 真的小吗？

### Debug
- 人真的能插进去吗？
