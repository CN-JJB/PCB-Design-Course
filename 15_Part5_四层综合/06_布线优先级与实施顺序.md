# 06｜布线优先级与实施顺序：不是“先电源还是先信号”，而是先处理最难返工的路径

> 综合板 routing 的核心不是速度，而是顺序。顺序错了，后面会用越来越多 via、蛇形、绕路和 cutout 给前面的决策擦屁股。

---

# 6.1 Routing 前最后一次问：Placement 真的定了吗？

如果下面任何一项还在漂，不要开始大面积布线：

- USB connector / ESD / MCU 相对位置；
- microSD 与 SDIO pin side；
- CAN connector / TVS / PHY；
- regulator 与 power entry；
- crystal；
- SWD；
- major decouplers。

**Routing 不是修复 Placement 的工具。**

---

# 6.2 推荐的 V2 Routing Priority

一个可执行顺序：

```text
0. GND / decoupling topology sanity check
1. HSE / VCAP / critical local loops
2. USB D+/D-
3. SDIO_CLK
4. SDIO_CMD + D0~D3
5. CANH/CANL bus side
6. CAN logic / SWD / UART
7. 3V3 / 5V local distribution
8. low-speed GPIO / LEDs / keys
9. pours / stitching / cleanup
10. DRC + manual review
```

这个顺序不是宇宙定律，但它保护了最难改、最敏感的路径。

---

# 6.3 Step 0：先看 reference，不急着画线

打开 L2 GND，检查：

- 有没有 cutout；
- mounting hole antipad 是否形成窄颈；
- connector through-hole pins 是否把 GND 挤断；
- via clusters 是否形成 slot；
- board edge keepout 是否影响 return path。

你即将布的每一根关键 L1 signal 都要有可用 reference。

---

# 6.4 HSE：最短、最局部、最安静

HSE 先布是因为：

- source/receiver 都在 MCU 周围；
- 节点高阻/敏感；
- 一旦其他线穿进去就很难清理；
- 后续 EMC 问题很容易被时钟谐波放大。

检查：

- 不穿 connector 区；
- 不靠 VBUS/CAN bus；
- 不被 SDIO_CLK 平行夹击；
- load cap ground path 合理。

---

# 6.5 USB：把“漂亮”让位给连续结构

优先目标：

1. connector → ESD → MCU 单向；
2. pair geometry 连续；
3. L2 GND 连续；
4. 尽量不换层；
5. 不绕 test point；
6. 不出现一根先绕 ESD、一根直穿的 asymmetry。

## 拐角

不需要迷信 45° 是“高速必须”。

真正关心：

- pair spacing；
- local impedance；
- 对称；
- reference。

## Length matching

USB FS 的目标不是用大量蛇形把两根线“数字上完全相等”。

先让：

- 拓扑一样；
- via count 一样；
- path 简单；
- geometry 一样。

再处理必要的 skew。

---

# 6.6 SDIO_CLK：把它当 aggressor

先画 CLK，因为它：

- 周期连续；
- edge 可能很快；
- 会对 CMD/DATA 和邻近网络产生耦合；
- source-series footprint 在 MCU 端。

推荐：

```text
MCU pin → source R footprint → direct trace → microSD CLK
```

避免：

- 先绕一圈再到 R；
- R 放 card 端；
- 大段贴着 D0~D3 平行；
- 多个 via；
- reference slot。

---

# 6.7 SDIO CMD / D0~D3：先消灭 outlier

组内 routing 目标：

- route family 看起来像一组；
- 不出现某一根比其他线长很多；
- via count 不离谱；
- reference 相似；
- 不和 CLK 长距离紧贴。

如果需要 length tuning：

- 先确定真正 timing budget；
- 再只补必要量；
- meander 放在有 reference、空间足够、不会强耦合邻线的区域。

---

# 6.8 CANH/CANL：先保护 bus-side 拓扑

CAN bus-side 路径：

```text
connector
→ protection
→ optional CMC/termination zone
→ transceiver
```

关注：

- H/L 对称；
- TVS branch 很短；
- CMC pinout 不造成交叉；
- termination footprint 不制造长 stub；
- bus 不绕进 MCU core；
- connector-side transient current 路径明确。

CAN logic TX/RX 后画通常没问题，因为短逻辑线的物理约束比 bus-side 小。

---

# 6.9 SWD：时钟也需要尊重

SWCLK 是 edge-driven digital signal。

如果 SWD header 离 MCU 较远：

- 不要和 HSE 平行；
- reference 连续；
- 可以预留 source damping；
- connector GND pin 足够；
- debug cable 是系统的一部分。

调试接口在 Bring-up 时可能跑得比你想象中快。

---

# 6.10 Power：先看 loop 和 drop，再看“线宽好不好看”

## 3V3

优先用：

- L3 plane/pour；
- Top local copper；
- short wide neck；
- 多点合理 via connection。

检查：

- regulator → plane entry；
- MCU cluster；
- microSD branch；
- CAN PHY branch；
- narrow neck；
- via bottleneck。

## USB 5V

VBUS 不要：

- 从 pair 中间穿；
- 穿 crystal 区；
- 沿 SDIO_CLK 大段平行。

---

# 6.11 Via：每打一颗都问三个问题

1. signal 为什么要换层？
2. reference 会不会变？
3. return transition 怎么完成？

如果回答只是：

> “这里挤不下。”

那应该先回去检查 Placement/Routing Order。

---

# 6.12 Stitching Via 不要做成装饰

GND via 的用途可能是：

- return transition；
- connector shield/current path；
- plane connection；
- edge field containment；
- thermal connection。

每种用途的“应该放哪里”不同。

不要最后选中全板，等间距打满一圈，然后称之为 EMC design。

---

# 6.13 Pours 最后不是“自动变好”

敷铜后重新检查：

- 是否产生孤岛；
- 是否形成 narrow slot；
- 是否改变 controlled trace 邻近环境；
- 是否在 USB pair 一边近、一边远；
- 是否制造隐藏 return detour；
- thermal relief 是否符合大电流/装配目标。

Copper pour 是几何结构的一部分，不是绿色背景。

---

# 6.14 Routing 完成后的第一轮人工审查

不要立刻 Gerber。

按 network review：

### USB
- pair topology
- reference
- via
- ESD
- connector

### SDIO
- CLK first
- group outlier
- parallelism
- reference

### CAN
- bus symmetry
- protection
- termination stub
- connector current path

### Power
- VCAP
- decoupling loops
- 3V3 neck
- SD transient path

### Debug
- physical access
- SWCLK
- ground reference
