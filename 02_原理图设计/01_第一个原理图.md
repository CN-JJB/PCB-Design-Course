# 第一章 第一个原理图：从 LED 到 STM32 最小系统

> 本章目标：在 KiCad 中完整画出两个电路——入门的"电池点亮 LED"，进阶的 STM32F103 最小系统。掌握原理图编辑的全部核心操作。本章所有菜单路径基于 KiCad 9.x，中英对照。

---

## 1.1 工程准备

```
① 启动 KiCad → File → New Project（文件→新建工程）
② 选择存放位置：建议专门建一个课程目录，
   如 D:\kicad_projects\01_led_blink
③ 勾选 "Create a new folder for the project"（为工程新建文件夹）
④ 命名规则：小写字母+下划线，避免中文和空格
   （某些工具链对中文路径支持不佳，养成习惯）
```

打开 Schematic Editor（原理图编辑器），进入主战场。

---

## 1.2 入门电路：USB 供电 LED 灯

目标电路：

```
+5V ──[R1 330Ω]──[LED1 红]── GND
        (限流)     (发光)
```

### 步骤一：放置元件

| 操作 | 菜单路径 | 快捷键 |
|------|---------|--------|
| 放置符号 | Place → Symbol（放置→符号） | **A** |

按下 A 后弹出符号选择器（Choose Symbol）：

- 搜索框输入 `R` → 选 `Device:R`（通用电阻）
- 移动到画布中间点击放下
- 再按 A：搜索 `LED` → 选 `Device:LED`
- 再按 A：搜索 `GND` → 选 power 库的 `GND`
- 再按 A：搜索 `+5V` → 选 power 库的 `+5V`

> 【技巧】放错了按 Esc 取消当前放置，Del 删除已放的；位置不满意 M 移动，R 旋转。

### 步骤二：连线

| 操作 | 快捷键 |
|------|--------|
| 开始画导线 | **W** |
| 结束/取消 | 双击终点 / Esc |
| T 形自动连接点 | KiCad 自动添加junction圆点 |

从 +5V 符号底部拉出导线到 R1 左端——**光标靠近引脚端点时会吸附变红**，此时点击才有效连接。常见新手错误：线画到了元件旁边但没接到引脚上，放大检查每个连接处是否有吸附动作。

### 步骤三：设置参数值

选中 R1 按 **E**（Edit Properties 编辑属性）：

- Value 字段：`330Ω`（或写 330R）
- Footprint 字段：先跳过，第四章批量分配

同样给 LED1 的 Value 填 `红色指示灯`。

### 步骤四：标注位号 Annotate

KiCad 新版默认自动标注（放置时即分配 R1/R2）。老版本需要手动：

Tools → Annotate Schematic（工具→标注原理图）→ 全部按默认 → 标注。

作用：给每个元件唯一编号，是生成网表和 BOM 的前提。若你手动改过位号导致重号，ERC 会报错。

### 步骤五：电气规则检查 ERC

Inspect → ERC（检查→电气规则检查）→ Run ERC。

本例可能的报错与处理：

| 报错 | 原因 | 处理 |
|------|------|------|
| "Input Power pin not driven by any Output Power pins" | 电源符号没被识别为驱动源 | 见下方说明框 |
| pin not connected | 有引脚悬空 | 补线或加 no-connect 叉号(Q键) |

> 【KiCad 特有概念】power 符号的引脚类型默认是 Power Input，需要一个 Power Output 来驱动它。解决：在任意电源符号属性里勾选不适用时……更简单的官方推荐做法：确保至少使用了标准 power 库符号（它们自带驱动定义），且 ERC 设置里把该类警告级别调到你认可的程度。具体：File → Board Setup 不存在于原理图侧——正确路径是 Inspect → ERC → Severity（严重性）标签页，将 "Input Pin not driven by any output pin" 设为 Ignore 或 Warning，前提是你确认供电逻辑没问题。

第一个电路完成！File → Export → PDF 导出留档。

## 1.3 进阶实战：STM32F103C8T6 最小系统

现在把第三章读过的那张图亲手画出来。这是贯穿全课程的"母版工程"。

### 规划页面布局

好的原理图像好的文章——分区排版：

```
┌─────────────────────────────────────┐
│  [左上] 电源区    │ [中] MCU 本体     │
│  USB口→LDO→3V3   │  F103C8T6        │
│                  │                  │
│  [左下] 去耦阵    │ [右上] 时钟+复位  │
│  0.1μF × N       │ 8MHz + RC       │
│                  │ [右下] BOOT+SWD  │
└─────────────────────────────────────┘
```

### 第一步：放置主控

A → 搜索 `STM32F103C8T6` → 选择 `MCU_ST_STM32F1:STM32F103C8Tx`。

LQFP48 符号会以大矩形出现，四周引脚分组排布：

- 左侧：电源和地
- 上方：晶振、复位、BOOT
- 右侧：GPIO
- 下方：更多 GPIO 和调试口

> 【符号库知识】ST 官方符号把同组功能引脚合并显示（如所有 VDD 显示为一个 VDD 引脚），这是正常现象，实际封装里每个物理引脚都会正确映射。

### 第二步：电源区

```
放置清单：
- Conn_USB: Connector USB Micro-B (Connector_Specialized 库)
- U_LDO: Regulator_Linear 库搜 AMS1117-3.3
         (若无则用 Regulator_Linear:AP1117-33 等价替代)
- 电容: C 10μF×3 (Value 写 10μF)
- 电源符号: +5V、+3V3、GND
```

连线顺序：USB VBUS → LDO IN → LDO OUT → +3V3 网络。每颗电容并联在对应节点与 GND 之间。

> 【网络名规范】直接使用 power 库里的 +3V3/+5V/GND 符号，不要自造名字，保证全局统一。

### 第三步：去耦电容阵

MCU 每个 VDD 引脚旁放一颗 0.1μF：

```
操作流：C 放置一颗电容改值100nF → Ctrl+C复制 → 连续粘贴4次
连法：每个 VDD 类引脚 → 0.1μF → GND
另加：VDDA 脚接 0.1μF+1μF 组合
```

原理图阶段不用管物理距离（那是 PCB 的事），但要在心里标记：这批电容将来必须贴着芯片放。

### 第四步：时钟与复位

时钟（对照第三章图）：

```
Y_OSC: Device 库搜 Crystal（两脚晶振）
Y 接 OSC_IN/OSC_OUT
两端各接 C 22pF 到 GND
```

复位：

```
R 10k 从 NRST 上拉到 +3V3
C 0.1μF 从 NRST 下拉到 GND
SW_Push（按键）并联在 C 两端
NRST 引出网络标号 "NRST"
```

### 第五步：BOOT 与 SWD

```
R 10k: BOOT0 下拉到 GND
排针 Conn_01x04: 3V3 / SWDIO / SWCLK / GND
SWDIO/SWCLK 用网络标号连到 PA13/PA14
```

### 第六步：整理与美化

原理图的"可读性"是职业素养：

| 整理项 | 操作 |
|--------|------|
| 元件横平竖直 | R 旋转到 0°/90°，网格吸附 50mil |
| 导线只走直线 | 拐角 90° 或 45°，禁斜线穿越元件 |
| 分区留白 | 模块之间空出明显间隔 |
| 文字注释 | Place → Text Annotation（放置→文本注释）给每个模块加标题框说明 |
| 页边框信息 | File → Page Settings 填标题/作者/日期/版本 |

### 第七步：全图 ERC

Inspect → ERC → Run。预期处理三类典型问题：

1. 未连接引脚：确实不用的 GPIO 加 no-connect 标记（快捷键 Q 放置叉号）
2. Power not driven：参考前述严重性设置
3. 引脚类型冲突（如 output 对 output）：检查是否真接错

**ERC 清零后保存**。这张图就是后续 PCB 实战的起点网表。

## 1.4 原理图操作速查大全

### 选择技巧

| 操作 | 方法 |
|------|------|
| 单选 | 点击对象 |
| 框选(完全包含才选) | 左键拖拽 |
| 框选(碰边即选) | 左键拖拽 + 右向左拖（绿框） |
| 加选 | Shift+点击 |
| 全选 | Ctrl+A |
| 选择连线段 vs 整条网络 | 点一下=段；再按一次U=整网络 |

### 移动与复制的细节差异

| 键 | 行为 | 适用场景 |
|----|------|---------|
| M | 移动，**断开连线** | 大范围搬移模块 |
| 拖动(Drag，按住Alt或用右键菜单) | 移动且保持连线 | 微调单个元件 |
| C | 复制 | 阵列式元件（去耦阵） |
| Ctrl+D | 原位重复粘贴 | 同上 |

### 查找与替换

Ctrl+F 搜索位号/值/网络名。大型图纸必备。

### 批量修改属性

框选全部去耦电容 → 右键 → Edit Reference Designator 或 Properties 面板批量改 Value——比如统一改成 100nF。

## 1.5 常见翻车现场（原理图版）

| 翻车 | 症状 | 预防 |
|------|------|------|
| 导线没真正接到引脚 | 表面看着连了，网表里是两个网络 | 放大 800% 检查节点吸附红点 |
| 电源符号名打错 | +3V3 打成 +3v3，两个网络互不相通 | 只用库自带符号，不自造 |
| 忘记放 no-connect | ERC 一堆警告掩盖真错误 | 不用的脚立刻打叉 |
| 位号重复 | 网表混乱 | 提交前跑一遍 Annotate |
| 复制模块忘改网络标号 | 局部电路悄悄短路 | 复制后逐个核对 label |
| 图太挤 | 自己都看不懂 | 分区+留白+注释文本 |
