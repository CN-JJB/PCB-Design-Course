# 第二章 符号库与自定义元件：没有库就自己画

> 本章目标：理解 KiCad 库体系，掌握高效找库的方法；学会从零绘制一个自定义符号（以常见的温湿度传感器 SHT30 为例），并理解引脚电气类型的意义。

---

## 2.1 KiCad 的库体系

原理图符号（Symbol）和封装（Footprint）分开管理：

```
符号 Symbol                    封装 Footprint
  ↓ 原理图里的"电路图形"          ↓ PCB上的"焊盘模板"
  Device:R                     Resistor_SMD:R_0805_2012Metric
       └── 通过 Footprint 字段关联 ──┘
```

一个符号可以配任意封装（同一个电阻符号可贴 0603 或 0805），这种解耦是行业通用做法。

### 库的三个层级

| 层级 | 存储位置 | 适用场景 |
|------|---------|---------|
| 官方全局库 | 安装目录 share/kicad/symbols | 覆盖 99% 常用器件 |
| 用户全局库 | 文档目录 KiCad/9.0/symbols | 你自制的常用件 |
| 工程专属库 | 工程文件夹内 *.kicad_sym | 只属于本项目的特殊件 |

优先级：工程库 > 用户库 > 全局库（同名符号取最高层）。

查看/编辑库列表：Preferences → Manage Symbol Libraries（偏好设置→管理符号库）。**一般不要动官方库文件本身**——升级会被覆盖。自制符号一律放进用户库或工程库。

## 2.2 高效找符号的五个方法

### 方法一：直接搜索（首选）

A → 输入关键词。搜索技巧：

```
搜 "STM32F103C8T6"   → 精确型号
搜 "STM32F103C"      → 同封装系列
搜 "LDO"             → 类别名（Regulator_Linear 库）
搜 "AMS1117"         → 具体型号
搜 "SHT"             → 温湿度传感器
```

### 方法二：按厂商系列浏览

官方库按 `厂商_系列` 组织：`MCU_ST_STM32F1`、`Driver_Motor`、`Interface_USB`。记住规律后可以像查字典一样定位。

### 方法三：从立创商城反查

立创商城元件页面 → 数据手册/规格 → 部分提供 KiCad 库下载（或用嘉立创 EDA 导出 KiCad 格式）。第三方库质量参差，导入后必须核对引脚定义与 datasheet 一致。

### 方法四：Ultra Librarian / SnapEDA

TI/ADI 官网器件页提供符号封装下载，选 KiCad 格式。适合新发布的芯片官方库还没有的情况。

### 方法五：实在没有就自己画（下一节）

> 【铁律】无论库来自哪里，使用前打开 datasheet 的 Pin Definitions 表逐脚核对一遍。用错库的损失 = 整板报废重打。

## 2.3 实战：从零画 SHT30 符号

目标器件：Sensirion SHT30-DIS-B，温湿度传感器，I2C 接口，6 引脚 DFN 封装。

Datasheet 引脚表（摘）：

| Pin | 名称 | 功能 |
|-----|------|------|
| 1 | SDA | I2C 数据 |
| 2 | ADDR | 地址选择(接地=0x44,接VDD=0x45) |
| 3 | nRESET | 复位(低有效) |
| 4 | NC | 空 |
| 5 | VSS | 地 |
| 6 | VDD | 电源 2.15~5.5V |

### 步骤一：新建符号

```
① 工程管理器打开 Symbol Editor（符号编辑器）
② File → New Library…（文件→新建库）
   → 选择保存到【工程目录】内，命名 mylib.kicad_sym
   → 弹窗问是否加入库表：选 Project（工程级）
③ 右键新库 → New Symbol（新建符号）
   Name: SHT30
   Reference designator prefix: U
   默认引脚数留空即可
```

### 步骤二：画符号轮廓

- 放置矩形：Place → Rectangle（放置→矩形，快捷键 R 旋转），画一个约 10×8 格的方框代表芯片本体
- 框的原点要在 (0,0)：Edit → Edit Symbol Properties 里确认，否则放置时鼠标抓取点会偏移

### 步骤三：放置引脚——核心步骤

快捷键 **P** 放置引脚，每个引脚设置三组属性：

| 属性项 | SDA 示例 | 说明 |
|--------|---------|------|
| Number 编号 | 1 | 必须与实物封装引脚号一致！ |
| Name 名称 | SDA | 显示在符号上 |
| Electrical type 电气类型 | Bidirectional 双向 | 决定 ERC 行为 ★ |
| Orientation 方向 | Right(朝右) | 引脚连接点朝外 |

六根引脚逐一放置：

| # | 名称 | 电气类型 | 位置 |
|---|------|---------|------|
| 1 | SDA | Bidirectional | 左侧 |
| 2 | ADDR | Input | 左侧 |
| 3 | nRESET | Input | 左侧 |
| 4 | NC | Unspecified(不连接) | 顶部 |
| 5 | VSS | Power input | 底部 |
| 6 | VDD | Power input | 顶部 |

> 【电气类型为什么重要】ERC 靠它判断连接合法性：
> - Output 接 Output → 报错（两个驱动打架）
> - Power input 没有驱动源 → 报警告
> - Input 悬空 → 提示
>
> 类型填错不会影响功能，但会让 ERC 变成狼来了——要么漏报真错误，要么满屏假警报。认真填类型是对未来的自己负责。

### 步骤四：修饰

- 引脚名上方加横线表示低有效：名称写成 `~{nRESET}` 或在属性里勾 Overline
- 放置文本标注电源范围 "2.15-5.5V"
- 符号属性里填默认 Footprint 字段（如 `Package_DFN_QFN:SHT31-DIS`，若无对应则第四章再处理）

### 步骤五：验证

保存后回原理图，A 搜索 `SHT30` 应能找到你库里的符号。放置并连一条测试线，跑 ERC 确认无异常报错。

## 2.4 自制符号的设计规范

| 规范 | 原因 |
|------|------|
| 引脚编号绝对不能错 | 这是符号的灵魂，错一号整板报废 |
| 功能相关的引脚放同侧 | 可读性：数据口一侧、电源一侧 |
| 电源引脚隐藏(Hidden)可选 | 大厂风格：VDD/GND 隐藏自动连接。KiCad 中慎用——隐藏引脚容易让 ERC 漏检，建议显式画出 |
| 低有效信号加横线 | 行业惯例一眼识别 |
| 符号大小适中 | 太大浪费图纸，太小引脚名挤不下 |
| 总线型 MCU 可拆多部分 | 多 Part 符号（如 U1A/U1B 分区显示），复杂 MCU 用图形化分组更清晰 |

## 2.6 封装库先睹为快

本阶段只需要知道：封装编辑器和符号编辑器操作几乎一样（矩形+焊盘+丝印）。焊盘的关键参数：

- Pad number 必须匹配符号的 pin number
- 焊盘尺寸来自 datasheet 的 Land Pattern 推荐
- 丝印画清楚第一脚标志

好消息：**阻容感、常见 IC 的封装官方库都有现成的且经过大量验证，直接用**。真正需要自制封装的场景（异形接口、特殊模块）到实战项目时手把手教。
