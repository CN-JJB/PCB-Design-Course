# 第四章 封装分配与原理图收尾：给每个元件找到它的"座位"

> 本章目标：为全部符号分配正确的封装，理解封装选型的工程权衡（尤其是手焊可行性），完成原理图到 PCB 交接前的最终检查。

---

## 4.1 封装分配的三种方式

### 方式一：单个编辑

选中元件按 E → 属性面板 → Footprint 字段 → 点击右侧书页图标浏览封装库。

适合零星修改，不适合批量。

### 方式二：封装分配工具（批量首选）

菜单 Tools → Assign Footprints（工具→分配封装），打开三栏视图：

```
┌─────────────┬──────────────────┬─────────────────┐
│ 左栏         │ 中栏              │ 右栏             │
│ 符号列表     │ 该符号的候选封装   │ 当前已分配结果    │
│ R1 C1 U1... │ 按库分组浏览       │ 双击中栏即应用    │
└─────────────┴──────────────────┴─────────────────┘
```

高效工作流：

```
① 顶部过滤框输入 R_0603 → 下方所有电阻统一显示
② 全选同值/同类元件 → 中栏双击 Resistor_SMD:R_0603_1608Metric
③ 一键完成整类分配，重复处理电容/电感/二极管
④ IC 类逐个确认
⑤ Apply → Save
```

### 方式三：符号属性里预设默认封装

自制符号时直接在 Symbol Properties 填好默认 Footprint——放置时自动带上。团队协作的标准做法。

## 4.2 封装选型的工程决策

同一个电气参数有多个物理封装可选，怎么定？四个维度的权衡：

### 维度一：焊接工艺匹配

| 你的焊接能力 | 推荐封装 |
|-------------|---------|
| 纯手工烙铁新手 | 0805 / SOIC / SOT-23 / TO-252 |
| 手工熟练 | 0603 / TSSOP / QFP(0.5mm) / SOT-223 |
| 有热风台 | QFN / DFN / 0402 |
| 回流焊+钢网 | BGA / 0402 及以下 / WLCSP |

> 【打样策略】嘉立创贴片服务支持的基础库封装优先；自购手焊则整体选大一号。**第一块板的目标是成功点亮，不是秀极限工艺。**

### 维度二：电流与散热

| 需求 | 封装选择逻辑 |
|------|-------------|
| >1A 的 LDO/稳压管 | SOT-223、TO-252(DPAK)——有大接地焊盘散热 |
| 大电流 MOS | TO-252/TO-263 或带散热脚的 PowerPAK |
| 信号级小器件 | SOT-23 足矣 |

### 维度三：板面积与成本

0402 比 0805 省 75% 面积，但贴片费更贵、手焊更难。学习项目用 0805 完全够。

### 维度四：供货稳定性

立创商城查现货：优先基础库（免费贴）和扩展库常备料。冷门封装（如特殊晶振尺寸）下单前必须确认货源。

## 4.4 分配后的验证流程

### 验证一：3D 目检

PCB 编辑器按 3 查看。重点核对：

- IC 的 pin1 标志位置与丝印一致
- 极性件（LED/电解/钽）方向
- 连接器引脚顺序（从焊接面看还是从插接面看？——封装图视角是顶视俯视，连接器要特别注意镜像问题）

### 验证二：尺寸抽测

对关键元件用测量工具量焊盘中心距，与 datasheet 对比。典型陷阱：

- 排针 2.54mm 间距画成 2.0mm → 插不进
- USB 口固定腿孔位错 → 外壳悬空，插拔应力全压在信号脚上
- 模组类（ESP32 等）金手指间距

### 验证三：ERC 的 Footprint 检查项

跑一遍 ERC 确认无 missing footprint 报警。

## 4.5 自制封装入门（了解即可）

当官方库没有对应封装时（常见于国产新芯片、异形模块），需要自己画：

```
① Footprint Editor → File → New Footprint → 存入 mylib.pretty
② 设置焊盘：
   Pad Properties 里逐个定义形状/尺寸/编号/类型(SMD/THT)
   datasheet 找 Land Pattern 页抄推荐值
③ 摆放焊盘到精确坐标（属性里直接输坐标最准）
④ 丝印层画轮廓+pin1标记（线宽≥0.15mm）
⑤ Courtyard 层画外扩轮廓（自动DRC防重叠用）
⑥ 保存后回 PCB 编辑器即可调用
```

精度技巧：从厂商官网下载该器件的 DXF/STEP 图导入对齐；或用游标卡尺实测实物。

## 4.6 从原理图到 PCB 的交接仪式

万事俱备，执行同步：

```
① 打开 PCB Editor（此时是空板）
② Tools → Update PCB from Schematic（F8）
   → 弹窗列出所有待导入的符号和网络 → Apply
③ 元件堆叠出现在原点附近 → 关闭弹窗
④ 拖开元件开始布局（下一部分的主题！）
```

同步的日常用法：之后任何原理图改动，重复 F8 即增量更新——新增的网络加入，删除的网络移除，改动的封装提示替换。

### 同步失败的常见原因

| 报错 | 原因与解法 |
|------|-----------|
| Footprint not found | 库名写错或库没加载→检查 Footprint 字段完整路径 |
| Duplicate footprint | 两个符号指向同一封装位号→重跑 Annotate |
| 引脚号不匹配 | 自制符号与官方封装 pad 编号不一致→改符号或改封装 |
