# 02｜电流回路、参考平面与回流路径

> 🎯 **本章目标**：以后看到任何一根信号线，都能同时画出“去程”和“回程”的闭合路径；理解为什么高速回流通常集中在信号附近的参考平面，而不是“随便从地平面某处回去”。

![信号与回流路径](../assets/svg/part0-current-loop.svg)

---

## 1. 先把“地”从神坛上拿下来

初学电路时，我们常把 GND 画成：

```text
   ─┴─
```

看起来像一个能把所有电流吸走的“黑洞”。

但 GND 本质上只是我们选定的参考网络。真实电路里：

> **电荷不能凭空消失，电流必须形成闭合回路。**

例如 MCU 驱动一个外设输入：

```text
MCU output ───────────> receiver
     ↑                    │
     └──── return ────────┘
```

当接收器、驱动器和电源系统都展开以后，这个回路可能穿过地平面、电源网络、去耦电容、封装引脚等很多结构。

所以“GND 是 0 V”只是电路计算中的参考定义，并不意味着整块地平面任何位置在任何频率下都毫无电压差、毫无阻抗。

---

## 2. 电流为什么会选择不同路径？

一句准确但重要的话：

> **电流按照整个网络的阻抗分布在所有可用路径上，而不是像人一样先选出唯一一条路线。**

在不同频率/时间尺度上，主导阻抗的因素不同。

### 2.1 低频 / 直流直觉

当变化很慢时，电阻往往更重要。电流会更多分布到电阻较小的路径。

如果是一整块均匀铜平面，回流可能在较宽区域分散。

### 2.2 快速变化时

随着频率成分上升，互连电感和电容效应越来越重要。

此时减少环路磁场储能、降低环路电感的路径会更有优势。

对于一根靠近连续参考平面的高速走线，最小化环路面积的方式通常就是：

> **回流主要集中在信号走线投影附近的参考平面区域。**

注意“主要集中”不等于“只有一条蓝色细线”。真实表面电流密度是连续分布。

---

## 3. 为什么参考平面必须“连续”？

想象 L1 上有一根高速信号，L2 是完整 GND。

```text
L1   ───────── signal ─────────>
       ↓↓↓ 电场/磁场耦合 ↓↓↓
L2   ============================  GND
       <──── return current ────
```

当 L2 连续时，回流可以跟随信号。

如果 L2 被挖出一道缝：

```text
L1   ───────── signal ─────────>
L2   ========       ============
              gap
```

走线本身仍然是连续铜线，但“信号 + 参考”的传输结构发生了突变。

回流必须：

- 绕过缝隙；或
- 通过其他电容性路径跨越；或
- 转移到另一个参考导体。

结果可能包括：

- 环路面积增加；
- 局部电感增加；
- 阻抗发生突变；
- 更多能量转成共模；
- 辐射和串扰风险上升。

这就是“不要让高速信号跨参考平面开槽”的物理原因。

---

### 3.1 一个很容易漏掉的反例：所有 GND 都连通，不代表回流彼此独立

在 [06｜实测案例：接地、过孔寄生与耦合](06_实测案例_接地过孔与耦合.md) 中，同一张滤波器原理图只改变 PCB 接地结构，频响就出现明显差异。

最差版本把多个对地支路先接到同一段细长地线，再进入 GND。逻辑网络完全正确，但高频电流必须共享那段铜的寄生阻抗：

~~~text
branch A ─┐
branch B ─┼── shared GND neck ── plane
branch C ─┘
~~~

于是 A 支路的瞬态电流会在共享路径上产生压降/磁场，B、C 支路也会“看到”它。

更好的几何是让承担快速电流的关键 GND 支路**尽早、就近、低电感地进入连续参考平面**，避免先汇总成长而细的公共回流颈。

这不是要求所有普通 GND pad 都无条件“一焊盘一过孔”，而是要求你识别：

> **哪些支路的电流频谱足够高、回路足够关键，值得单独控制其接地寄生。**

---

## 4. 参考平面一定是 GND 吗？

不一定。

一根走线可以参考：

- GND plane；
- Power plane；
- 另一个足够连续、在目标频段低阻抗耦合到系统参考的导体结构。

但工程上 **GND 是最容易处理、最稳定、最少分割的参考平面**，所以课程会优先安排关键高速信号邻近完整 GND。

如果一根线从“参考 GND 的层”换到“参考 3V3 的层”，回流必须找到 GND 与 3V3 之间的高频连接路径，而这通常依赖去耦电容和电源网络的寄生参数。

这就是为什么四层 `Signal / GND / Power / Signal` 虽然常见，却不能简单理解成“上下两层信号完全等价”。

---

## 5. 换层时，信号过孔不是全部故事

假设信号从 L1 换到 L4：

```text
L1 signal ───●
             │ signal via
             │
L4           ●──── signal
```

你需要继续问：

> L1 之前参考谁？L4 之后参考谁？回流怎样从旧参考结构过渡到新参考结构？

### 情况 A：前后都参考同一个 GND 网络

通常在信号换层区域附近提供 GND stitching via，可以缩短参考平面之间的高频连接路径。

但课程不会给你一个“所有情况必须距离 X mm”的死数字，因为最佳间距与：

- 介质厚度；
- 边沿速度；
- 过孔结构；
- 目标频率；
- 空间约束

都有关系。

原则是：

> **让参考转换路径与信号转换路径在几何上靠近，尽量减小换层处的回路面积和寄生电感。**

### 情况 B：参考从 GND 变成 Power

此时单纯加 GND via 不能自动解决全部问题，因为新参考是 Power。你需要分析 GND 与 Power 之间的高频耦合路径。

这会在 Part 2（SI）和 Part 3（PI）中继续展开。

## 6. ❌ 故障板实验：一条“看起来没问题”的 SPI 时钟

假设：

```text
Top: STM32 ---- SCK ---------------- Flash
L2 : GND GND GND [开槽] GND GND GND
```

### CAD 视角

- SCK 网络连接正确；
- 线宽合法；
- 间距合法；
- DRC 通过。

### 回路视角

SCK 的高频分量希望在 L2 投影附近闭合，但平面中间有开槽。

于是回流绕路。

### 你应该问的不是

> “SPI 才几十 MHz，会不会没事？”

而是：

1. SCK 的实际 rise/fall time 是多少？
2. 这段走线多长？
3. 平面开槽尺寸多大？
4. 驱动强度是多少？
5. 这个回路增加了多少几何面积？
6. 系统 EMC 裕量有多大？

这套提问方式比背“SPI 超过 XX MHz 才算高速”更可靠。

## 7. 🛠️ KiCad 实操：回流投影审查

在 PCB Editor 中做一个简单的人工作业：

1. 选一条 Clock / USB / SDIO / SPI SCK；
2. 高亮该网络；
3. 查看相邻参考平面；
4. 沿着整个走线投影检查平面是否连续；
5. 标出：
   - 开槽；
   - plane split；
   - 大面积 antipad；
   - 密集过孔造成的“铜颈”；
   - 换层点；
6. 对每个换层点写下“换层前参考 / 换层后参考”。

这一步目前主要靠工程师思考，不要指望 DRC 自动替代。

## 8. Design Review 卡片：Return Path

每次 Review 关键网络时，问：

- [ ] signal layer 是哪一层？
- [ ] adjacent reference plane 是谁？
- [ ] 参考平面是否连续？
- [ ] 是否跨 plane split / void / slot？
- [ ] 是否换层？
- [ ] 换层前后 reference 是否变化？
- [ ] 参考结构之间是否有低电感的转换路径？
- [ ] 连接器处回流是否能继续进入线缆/外设？
- [ ] 关键去耦/旁路/对地支路是否先共享了长而细的 GND neck？
- [ ] 关键 GND via 是否在几何上靠近它真正服务的回流支路？
