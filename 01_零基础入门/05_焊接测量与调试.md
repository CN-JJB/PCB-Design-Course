# 第五章 焊接、测量与调试：让板子真正活起来

> 本章目标：掌握手工焊接（直插+贴片）、万用表测量、安全上电流程和基础排障方法。会画板不会焊，等于厨师不会开火。

---

## 5.1 焊接的本质

焊接不是"粘"，而是**冶金**：焊锡（锡铅合金或无铅合金）熔化后与铜表面形成金属间化合物层（IMC），实现电气+机械双重连接。

```
好焊点的剖面：
   元件引脚
      │
  ════╪════ ← 焊锡浸润爬升，呈内凹圆滑的"裙边"
 ┌────┴───┐
 │ IMC层  │  ← 锡铜化合物(约1~3μm)，真正的连接
 ├────────┤
 │ PCB焊盘 │
```

判断好焊点的外观标准：

| 特征 | 好焊点 | 坏焊点 |
|------|--------|--------|
| 表面 | 光亮镜面 | 灰暗粗糙 |
| 形状 | 内凹锥面(裙边) | 圆球堆在脚上 |
| 锡量 | 恰好包住引脚轮廓 | 包不住/包成球 |
| 引脚轮廓 | 隐约可见 | 完全埋没 |

## 5.3 温度设定

| 焊料 | 推荐温度 | 说明 |
|------|---------|------|
| 有铅 63/37（熔点 183℃） | **320~350℃** | 学习首选 |
| 无铅 SAC305（熔点 217℃） | **360~380℃** | 现代量产标准 |

温度原则：**够用就好，越低越保护焊盘和烙铁嘴**。连续焊接大焊盘时可临时 +20℃。

> 【新手误区】温度越高焊得越快？错。过高温度会导致：助焊剂瞬间碳化发黑、焊盘起翘、元件过热损坏、烙铁嘴氧化寿命减半。

## 5.4 直插元件五步法

以电阻为例，标准动作分解：

```
① 准备：烙铁头挂新锡(镀锡保护)、海绵擦净
② 加热：烙铁头同时顶住 焊盘 和 引脚 的交界处
        （两个都要热！只烫一边=虚焊）
③ 送锡：约1秒后从对侧送入 2~4mm 焊锡丝，
        看到焊锡受热熔化并流动铺展
④ 撤锡：先撤走焊锡丝
⑤ 撤铁：最后撤走烙铁。保持静止 1 秒等凝固。
        （凝固前晃动板子=虚焊制造机）
全程目标时间：2~3 秒
```

常见失败模式对照：

| 现象 | 原因 | 解法 |
|------|------|------|
| 锡成球不铺开 | 焊盘不热或氧化 | 多加热 0.5s；加助焊剂 |
| 灰色渣渣浮在锡面 | 助焊剂碳化 | 降低温度、缩短时间 |
| 拉出锡尖 | 撤铁方向不对 | 向上垂直撤或沿引脚撤；补一点助焊剂重熔 |
| 焊盘掉落 | 过热过久 | 无法修复→改走飞线（后面教） |

### 插装技巧

- 弯脚成型：用镊子在距本体 2mm 处折弯，间距对准孔位插入
- LED 长脚=正极插在丝印 + 号侧
- 先焊对角两个脚定位 → 检查是否歪 → 再焊其余

## 5.5 贴片元件焊接（重点）

### 方法一：定位焊法（适合 0805/0603/SOIC）

```
① 右侧焊盘上预熔一小坨锡（左撇子反之）
② 镊子夹元件放入，烙铁熔化那坨锡的同时推正位置
③ 焊另一端：烙铁+焊锡丝同时到位，1秒完成
④ 回头补第一脚：加助焊剂，烙铁带微量锡重新拖过
⑤ 检查：放大镜下确认两端光亮饱满、无立碑
```

### 方法二：多引脚拖焊（SOIC/QFP 必杀技）

用于 SOIC-16、LQFP-48 这类密脚芯片：

```
① 芯片对准丝印轮廓放好（肉眼对齐即可）
② 四角先各焊一脚固定（歪了可重熔调整）
③ 大量涂助焊剂覆盖全部引脚
④ 取一段直径0.4~0.6mm焊锡丝放在引脚排根部
⑤ 刀头烙铁带上少量锡，顺着引脚方向缓慢"犁地"
   ——多余焊锡会被烙铁头带走粘在嘴上，
     定期在湿海绵上擦掉嘴上的锡
⑥ 拖完检查相邻引脚短路：有桥连就加助焊剂
   用干净的烙铁头轻轻带走多余锡
⑦ 最后酒精+牙刷清洗残留助焊剂，方便检查
```

关键手感：不是用力压，而是让熔融锡的表面张力自己分锡——**助焊剂充足时，锡只待该待的地方**。

### 方法三：QFN 底部散热盘

中心大焊盘必须处理，否则芯片发热严重甚至无法工作：

```
方案A（推荐新手）：中心盘打 4~9 个过孔到底层GND敷铜，
                  正面点少量锡膏，热风或烙铁从边缘加热
方案B：中心盘不上锡（防止吸走芯片），靠过孔传热到底面焊
```

### 立碑 Tombstone——贴片经典缺陷机理

回流/手焊中元件一端的锡先熔化，表面张力把元件竖起来像墓碑。

成因：两端焊盘受热不均 / 一端焊锡量差异 / 助焊剂不足。
预防（设计侧）：焊盘对称布局、热容均衡；（工艺侧）：两端同时加热、足量助焊剂。

## 5.6 拆件技术

| 对象 | 方法 |
|------|------|
| 两脚贴片(阻容) | 镊子夹住元件，烙铁左右脚来回快速加热，感觉松动即提起 |
| SOIC/QFP 多脚 | ①大量助焊剂+烙铁逐脚堆锡"游泳"拖动取下；②热风枪300℃环形吹全脚 |
| 直插元件 | 吸锡器配合烙铁逐孔清锡；顽固者剪断引脚逐根清理 |
| 清理焊盘残锡 | 吸锡带+助焊剂熨平 |

拆下的焊盘如果被带掉（起翘断裂）：刮开断点附近的走线绝缘层露出铜，用细漆包线搭桥飞线，再用 UV 胶或 502 点滴加固。

## 5.7 防静电 ESD 基础

人体静电可达数千至上万伏，CMOS 器件（所有现代芯片）栅氧层可能被瞬间击穿。

日常防护三件事：

1. 焊接前摸一下接地金属（暖气管/电源插座地极）放掉身体电荷
2. 敏感器件（MCU/RF芯片）尽量少用手直接摸引脚
3. 板子不用时放防静电袋里，不要用普通塑料袋（摩擦生电）

专业级：防静电台垫+手腕带串联 1MΩ 接地。学习阶段做到前两条即可。

## 5.8 万用表：硬件工程师的听诊器

### 四大常用档位

| 档位 | 用途 | 操作要点 |
|------|------|---------|
| 通断档(蜂鸣) | 查短路/断路 | 红 COM 黑 COM？不对——红插VΩ黑插COM。响≈<30Ω |
| DC电压档 | 测各点电压 | 并联接入，量程选大于预期值 |
| 电阻档 | 测阻值 | 断电测！在线测会被其他支路干扰 |
| DC电流档 | 测整机电流 | **串联**进回路，新手慎用易短路 |

### 实战测量套路

拿到一块通电的板子，按顺序测：

```
① 电源输入点有没有电压？（USB口 VBUS 应为 5V±0.25）
② LDO 输出点电压对不对？（3.3V ±5%）
③ MCU 电源脚上量到 3.3V 吗？（排除 LDO 到芯片之间的断路）
④ 晶振起振了吗？（示波器看波形；万用表只能粗略对比两脚直流偏置）
⑤ 关键信号有无跳变？（复位脚应在上电后为高）
```

### 万用表的坑

- 通断档响≠一定短路：10Ω 以下的正常低阻路径（如电感、磁珠）也会响
- 电流档表笔插错位（电流孔 vs 电压孔）= 直接短路电源，保险丝烧断
- 测晶振输出用普通探头会把振荡拉停（负载效应）——需用示波器低容探针

## 5.9 上电仪式：安全流程六步

新板第一次上电是最危险的时刻，按此流程可保住大部分元件：

```
第1步 目检
   放大镜全板检查：连锡？元件方向(IC缺口/LED极性)？
   电解电容极性！MOS 方向！

第2步 不插芯片测电源阻抗
   万用表通断档：3V3轨 对 GND —— 不应蜂鸣长响
   （数字几十~几百Ω正常，接近0Ω=有短路，禁止上电）
   5V 轨同理。

第3步 限流上电
   可调电源设 3.3V/限流100mA 试供；
   无可调电源则插USB后立刻用手背触碰主要IC：
   烫手立即断电！

第4步 分级验证电压
   5V → 3.3V → 各芯片供电脚，逐一核对 datasheet 标称值

第5步 观察启动迹象
   电源灯亮否？晶振起振否？复位释放否？
   有程序的话状态灯闪烁/串口打印？

第6步 记录基线
   测下整机静态电流记在本子上，日后故障排查的参照系
```

> 【血泪经验】跳过第 2 步直接上电，短路电流烧毁 LDO 甚至烧穿铜箔的事故，每个硬件工程师都经历过至少一次。请让它是别人的一次而不是你的。

## 5.10 排障方法论：三分天下

板子不工作时的系统化排查：

### 思路一：电源优先原则

80% 的"芯片坏了"其实是电源问题。任何异常先测供电，再怀疑别的。

### 思路二：分割定位法

```
现象：串口无输出
分割：电源OK？→ 晶振OK？→ 复位OK？→ BOOT配置OK？
      → 程序真的烧进去了吗(SWD能连上吗)？
      → TX线物理连通吗(通断档量)？
每次锁定一个环节验证，二分逼近故障点。
```

### 思路三：对比法

有条件时拿一块已知良好的板子逐点对比电压波形，差异点即嫌疑点。

### 常见故障速查表

| 故障现象 | 高概率原因（按频率排序） |
|---------|------------------------|
| 上电无电流 | 未上电/开关未闭合/LDO输入虚焊 |
| 电流极大且LDO发烫 | 输出短路：连锡/电容反接/芯片焊反 |
| MCU 不运行 | BOOT 配错、晶振不起振、复位悬空 |
| USB 无法识别 | D+/D- 接反、CH340 晶振(12MHz)未起振、驱动未装 |
| 时好时坏 | 虚焊（按压测试法定位）、电源不稳 |
| 局部功能失效 | 该模块去耦电容漏焊、信号线断路 |

按压测试法定位虚焊：用手指/塑料棒轻压可疑区域芯片，若故障状态改变即锁定该处，补焊重拖一遍。
