# 第三章 看懂电路图：从"天书"到"地图"

> 本章目标：掌握原理图的语言规则，能独立读懂一块 STM32 最小系统板的完整原理图。原理图是硬件工程师的"作文"，看不懂图就无法设计。

---

## 3.1 原理图是什么

**定义**：描述电路中元件之间电气连接关系的图。注意两个要点：

1. 它只表达**逻辑连接**（谁和谁相连），不表达物理位置、距离、大小
2. 同一个网络在原理图里是一条线，在 PCB 里可能是一根绕来绕去的走线

```
原理图（抽象）              PCB（物理）
                              
 VCC ──[R1]──┬── LED         实际的铜箔可能这样走：
             │                ┌──[R1]──┐
            GND               VCC      │
                              └────LED─┤
                                      GND
两幅图表达的是同一个电路。
```

### 三种图纸层次（由粗到细）

| 层次 | 名称 | 内容 |
|------|------|------|
| 框图 Block Diagram | 系统级 | 大模块+箭头：MCU↔USB芯片↔USB口 |
| 原理图 Schematic | 电路级 | 元件+引脚+连线 |
| 装配图 Assembly Drawing | 物理级 | 板上每个元件的位置图 |

本课程主要训练中间层，但画复杂系统前先画框图是好习惯。

## 3.2 符号语言规则

### 常见符号对照表

```
电阻           电容(无极性)      电解电容          二极管
──▭──          ──││──          ──│(──            ──▶|──
R?             C?              C? +极在弧面       D?

电感           LED             NMOS管            NPN三极管
──ᴖᴖᴖ──        ──▶|──→光       G├D               C
L?                             └S (箭头朝内)     B├──E
                                                 (箭头朝外)

接地 GND       电源 VCC        网络/总线          测试点
 ⏚ (三条横线)   ⊥或↑标注VCC     斜杠标号 /8位宽    ○TP?
```

### 电源符号体系——必须搞清的一组概念

| 符号 | 全称 | 含义 |
|------|------|------|
| VCC | Voltage Common Collector | 供电电压（习惯上指双极器件/系统主电源） |
| VDD | Voltage Drain | 正电源（MOS 器件的漏极供电），与 VCC 日常混用 |
| VSS / GND | Voltage Source / Ground | 地，0V 参考点 |
| VBAT | Battery | 电池/备份电源 |
| +3V3 / +5V / +1V8 | 明确电压值的网络名 | **现代规范写法，推荐** |

历史遗留：VCC/VDD 本有器件类型区分，如今工程实践中基本混用。真正重要的规范是：

> **同一个网络名 = 电气连通**。原理图里所有叫 `+3V3` 的引脚即使没有画线也全部连通；所有 `GND` 自动汇接。

这个特性让原理图可以画得干净——不用为每根电源线拉长线，就近放个符号即可。

### 网络标号 Net Label vs 导线 Wire

```
不用网络标号（乱）：            用网络标号（清爽）：
                               
U1_TX ├───────┬─── U2_RX      U1_TX ├──TX── U2_RX 处放标签 "UART_TX"
              │                
              └─── 调试座      两处都放同名标签，即视为连通
```

规则：短距离直接画线；跨远距离/跨页一律用网络标号。命名要语义化：`USART1_TX`、`SDA`、`EN_5V`，禁止 `net123` 这种无意义名字。

### 总线 Bus

一组同性质信号（如 D0~D7 数据线）合并成一条粗线表示：

```
        D[0..7] 总线
  ─────────────────────
    │   │   │  ... │
    D0  D1  D2     D7
  每个分支用总线入口(bus entry)+网络标号标注具体信号名
```

注意：总线上仍需每根线有独立网络标号，总线本身只是视觉归纳，KiCad 中真正决定连接的是标号。

## 3.3 读图方法论：四步法

拿到一张陌生原理图，按此顺序读：

```
第一步 找电源 → 从 LDO/DCDC 入手，弄清有几路电压、各供谁
第二步 找大脑 → 主控 MCU 在哪，它的电源/晶振/复位是否齐全
第三步 顺藤摸瓜 → 按接口(USB/串口/网口)沿信号流向读外围电路
第四步 查漏补缺 → 剩下没看懂的小元件逐个分析其作用
```

## 3.4 实例精读：STM32F103 最小系统的六大模块

### 模块一：供电电路

```
USB 5V ──┬── AMS1117-3.3(LDO)
         │      │IN    │OUT
      [10μF]  [10μF]  [10μF]     输出 +3V3 给全板
         │      │      │
        GND    GND    GND
         
AMS1117 各脚：VIN=输入 GND=地 VOUT=输出
输出电容作用：稳定输出+改善瞬态响应
```

读法：一路 5V 进 LDO 出 3.3V。注意 AMS1117 压差约 1.1V，所以输入必须 >4.45V——这就是为什么它吃 USB 的 5V 而不能吃锂电池的 3.7V。

### 模块二：去耦电容阵

```
STM32F103C8T6 (LQFP48) 的电源引脚及标配去耦：

Pin24 VDD_1 ──┬── 0.1μF ── GND
Pin36 VDD_2 ──┬── 0.1μF ── GND  
Pin48 VDD_3 ──┬── 0.1μF ── GND
Pin9  VDDA  ──┬── 0.1μF + 1μF ── GND    (模拟电源，多加滤波)
              另加一颗 4.7μF~10μF 总储能
```

铁律：**每一个 VDD 引脚配一颗 0.1μF**，这是 datasheet 明文要求，不是可选项。（为什么？第四章 PDN 章节揭晓。）

### 模块三：复位电路

```
+3V3 ──┬──[10kΩ]──┬── NRST(pin7)
       │          │
     [0.1μF]     RESET按键
       │          │
      GND        GND

工作原理：上电瞬间电容充电，NRST 保持低电平约 τ=RC=10k×0.1μ=1ms，
足够 MCU 完成可靠复位后拉高进入运行。按键按下强制复位。
```

### 模块四：时钟电路

```
OSC_IN(pin5)  ──┬─[8MHz晶振]─┬── OSC_OUT(pin6)
               [22pF]       [22pF]
                │             │
               GND           GND
```

8MHz 经内部 PLL 倍频到 72MHz 主频。负载电容 22pF 与晶振 CL 参数匹配（上一章讲过算法）。

### 模块五：BOOT 启动选择

```
BOOT0(pin44) ──[10kΩ下拉到GND]，另留排针可跳到3.3V

BOOT0=0 → 从 Flash 启动（正常运行）
BOOT0=1 且 BOOT1=0 → 从系统存储器启动（串口ISP下载模式）
```

新手翻车重灾区：BOOT0 悬空会导致启动随机失败。必须有确定的下拉。

### 模块六：SWD 调试接口

```
PA13 SWDIO(pin34) ── 排针pin2
PA14 SWCLK(pin37) ── 排针pin4
+3V3 ── pin1,  GND ── pin3

四根线即可完成程序下载和在线调试——ST-Link 就接这四个脚。
```

### 汇总检查表

读完这张图，你应该能回答：

- 有几路电源？（2 路：USB 5V 和 LDO 后的 3.3V）
- 每个 VDD 都有 0.1μF 吗？（有，共 3 颗 + VDA 特殊处理）
- 复位的 RC 时间常数？（10k×0.1μF=1ms）
- 晶振频率和负载电容？（8MHz，22pF×2）
- BOOT0 有确定电平吗？（10k 下拉，OK）
- 怎么烧程序？（SWD 四线）

任何一块 MCU 板子都是这六个模块的组合变形。**看懂了这张图 = 看懂了 80% 的嵌入式板卡。**

## 3.5 更多常见模块速查（后续项目都会用到）

### USB 差分对接口

```
USB_D+ ──┬── CH340G 的 UD+
USB_D- ──┼── CH340G 的 UD-
         └─ 差分对，等长并行走线，90Ω 差分阻抗(高速时)

VBUS 5V ──[0.5Ω/磁珠]── 分路给 LDO
GND 直通，外壳屏蔽层单点接 GND 或经 RC 接
```

### UART 串口直连排针

```
MCU TX ── RX(外部)     交叉相接！我的发是你的收
MCU RX ←─ TX(外部)
共地必须连，否则电平无参考
```

### LED 状态灯 ×3

```
+3V3 ──[1kΩ]──▶|── GPIO灌电流点亮(低有效)   或
GPIO推电流 ──[1kΩ]──▶|── GND(高有效)
电源指示灯常亮接死电源轨；心跳灯接 GPIO 由软件闪烁。
```

### 按键输入

```
+3V3 ──[10kΩ上拉]──┬── KEY ── GND
                   └── GPIO
未按时读到高电平，按下读到低。另一端 GPIO 配置成输入即可。
```

### I2C 总线（传感器必用）

```
+3V3 ──[4.7kΩ]──┬── SDA ── 传感器
+3V3 ──[4.7kΩ]──┼── SCL
                └── (开漏输出必须外加上拉！整条总线只需一对)
```

### SPI Flash 存储器

```
MCU SPI: SCK/MOSI/MISO + CS 四线
W25Q64 等 8 脚 SOIC，VCC 加 0.1μF 去耦
CS 不用时上拉，防止误选中
```

## 3.6 读图的坏习惯清单

| 坏习惯 | 后果 | 正确做法 |
|--------|------|---------|
| 只看主控不看电源细节 | 打板后供电异常 | 先把电源树完整画出来 |
| 忽略网络名的方向含义 | TX/RX 接反调试半天 | 标注语义化名称并交叉检查 |
| 把 VCC/VDD/GND 当装饰符号 | 连接关系理解错 | 记住同名即连通 |
| 跳过没见过的小元件 | 关键保护电路缺失 | 每颗元件都要说出用途 |
| 不查 datasheet 猜引脚 | 引脚功能张冠李戴 | 对照 Pin Definitions 表 |
