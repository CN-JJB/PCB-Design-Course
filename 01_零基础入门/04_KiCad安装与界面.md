# 第四章 KiCad 安装与界面：把工具磨快

> 本章目标：完成 KiCad 的安装和初始配置，认识全部界面区域，背下核心快捷键。工具不熟，后面每一步都会磕磕绊绊。

## 4.1 为什么选 KiCad

| 对比项 | KiCad | Altium Designer | Cadence Allegro |
|--------|-------|-----------------|-----------------|
| 价格 | **完全免费开源** | 数万元/年 | 十万级/年 |
| 功能 | 覆盖本课程全部需求 | 强大 | 工业级最强 |
| 四层/六层板 | 完全胜任 | 胜任 | 胜任 |
| 学习资源 | 官方文档+社区活跃 | 多（国内培训多） | 企业培训 |
| 文件格式 | 开放文本格式 | 私有二进制 | 私有 |

对个人学习和小团队，KiCad 是零成本且能力完全够用的选择；学会后迁移到商业软件只需适应界面，概念完全相通。

**版本选择**：安装当前稳定版（写作时为 KiCad 9.x）。官网 kicad.org → Download → Windows。

> 注意区分官网 kicad.org 与第三方下载站——务必官网，避免捆绑垃圾。

## 4.2 安装步骤详解

1. 下载 `kicad-9.x.x-x86_64.exe`（约 1~2GB，含全量元件库）
2. 双击运行，UAC 弹窗选"是"
3. 安装向导：
   - License 页：直接 Next
   - 组件选择页：保持默认勾选（含 kicad-full 全部库）
   - 安装路径：建议默认 `C:\Program Files\KiCad\9.0`；路径避免中文和空格
   - 开始菜单文件夹：默认
4. 等待安装完成（几分钟）
5. 首次启动弹出的"配置全局符号库表"对话框：**选推荐/默认选项一路确认**——它会自动索引全部官方库

> 【常见问题】
> - 杀毒软件报毒/拦截：KiCad 是正规开源软件，添加信任目录即可
> - 首次打开原理图提示找不到符号库：重新运行"偏好设置→管理符号库→恢复默认全局库"
> - 中文界面：偏好设置(Preferences)→ 常规选项(General Options)→ 语言(Language)→ 简体中文

## 4.3 工程体系：一切从 Project 开始

KiCad 是工程制管理模式：

```
我的第一个项目/
├── project.kicad_pro      工程主文件（双击它启动整个工程）
├── project.kicad_sch      原理图
├── project.kicad_pcb      PCB 板文件
├── project.kicad_prl      本地设置缓存（自动生成）
└── fp-lib-table 等        库配置（自动生成）

规则：一个产品一个文件夹一个工程。
     整个文件夹可以随意复制移动改名（相对路径引用），
     但不要单独改某个文件的文件名！
```

启动 KiCad 后看到**工程管理器**（Project Manager）：

```
┌────────────────────────────────────────────┐
│  KiCad 项目管理器                            │
│                                            │
│   ┌─────────┐  ┌─────────┐                 │
```

## 4.7 必做的五项初始设置

打开任意 PCB 编辑器 → 偏好设置 Preferences：

### 设置一：自动保存

Preferences → General → Auto Save：间隔设 5 分钟。软件崩溃是常态，5 分钟损失可接受。（另外 Ctrl+S 手动保存的习惯仍要养成。）

### 设置二：光标样式

Preferences → General → Cursor：选 Full Window Crosshair（全屏十字线）。对齐走线和判断位置时极其有用。

### 设置三：网格设置

PCB 编辑器右下角网格选择框：

- 布局阶段：0.5 mm 或 1 mm
- 布线阶段：0.25 mm / 0.127 mm(5mil) / 0.05 mm
- 放置丝印文字：0.127 mm

原则：**粗网格定位、细网格微调**，永远别在 0.01mm 网格里凭感觉摆件。

### 设置四：过孔/走线的默认预览

Preferences → General Editing：勾选 "Show footprints while routing"（走线时高亮对应焊盘），方便确认起点。

### 设置五：主题

Preferences → Preferences → Common → Color Theme：深色主题护眼，按喜好。

## 4.8 计算器工具初体验

工程管理器里打开 Calculator Tools，有三个页签值得现在就玩一遍：

### 页签一：Electrical（线宽载流）

输入：电流 1A、铜厚 1oz、温升限值 10℃、外层 → 输出最小线宽约 **0.38~0.6mm**（标准不同结果略异）。这验证了第一章那张速查表。

### 页签二：Transmission Line（传输线阻抗）

选 Microstrip 模型，输入 εr=4.4、介质厚度 h=0.2103mm（嘉立创四层板的典型层压参数）、目标 Z0=50Ω → 反算线宽约 **0.35~0.42mm**。这是第四章阻抗理论的第一口直观感受：50Ω 不是玄学，是几何+材料的计算结果。

### 页签三：RF Attenuators / Via（过孔参数）

输入过孔直径/长度 → 得到寄生电感约 1nH 量级。记住这个数量级，第四章讲地弹时会用到。

## 4.9 新建第一个工程并跑通骨架

不求理解细节（后续章节展开），只求流程通：

```
① File → New Project → 命名 hello_pcb，存到你规划好的课程文件夹
② 打开原理图编辑器 → A 放一个 R 元件 → P 放 VCC 和 GND
   → W 把三者连起来 → Ctrl+S 保存
③ 回到工程管理器 → 打开 PCB 编辑器
   → Tools → Update PCB from Schematic（从原理图更新PCB）→ Apply
④ 你会看到 R1 出现在 PCB 画布里 → M 把它拖到板框内
⑤ 按 3 看 3D 视图 → Esc 返回
⑥ File → Export → PDF，导出一份留档
```

跑完这个骨架，你就完成了「原理图→网表同步→PCB」的最短闭环。剩下的所有内容都是把这个闭环做厚做深。
