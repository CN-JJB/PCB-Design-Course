## 2.1 电阻 Resistor

### 物理本质

阻碍电流流动的元件。欧姆定律是整个电子学的第一公式：

```
U = I × R        电压(V) = 电流(A) × 电阻(Ω)
```

类比：电阻像水管里的窄口，水流（电流）通过窄口时压力（电压）会下降。

### 在电路里的五大用途

| 用途 | 说明 | 典型值 |
|------|------|--------|
| 限流 | 保护 LED：R=(5V-2V)/20mA=150Ω | 100Ω~1kΩ |
| 分压 | 两个电阻把电压按比例分出一份给 ADC 采样 | 10k+10k |
| 上拉/下拉 | 给悬空的信号一个确定的默认电平 | 4.7k~100kΩ |
| 匹配 | 吸收高速信号的反射（串阻） | 22~33Ω |
| 放电/泄放 | 给大电容放电、假负载 | 100k~1MΩ |

### 读值：贴片电阻三位/四位代码

```
三位码（±5%）：两位有效数字 + 幂次
  103 = 10 × 10³ = 10 kΩ
  472 = 47 × 10² = 4.7 kΩ
  220 = 22 × 10⁰ = 22 Ω    ← 注意！220 不是 220Ω 而是 22Ω
  0Ω   = 跳线，纯导线（常用于单点汇接或调试预留）

四位码（±1% 精密）：三位有效数字 + 幂次
  1002 = 100 × 10² = 10 kΩ
  4701 = 470 × 10 = 4.7 kΩ

R 表示小数点：
  4R7 = 4.7 Ω
  R047 = 0.47 Ω （采样电阻常见）
```

> 【新手必踩的坑】`220` 是 22Ω 不是 220Ω。同理 `100` 是 10Ω。看到三位码先想"最后一位是几个零"。

### 常用阻值速查

工程上不随便取值，用 E24/E96 标准系列：1.0, 1.1, 1.2, 1.3, 1.5, 1.6, 1.8, 2.0, 2.2, 2.4, 2.7, 3.0, 3.3, 3.6, 3.9, 4.3, 4.7, 5.1, 5.6, 6.2, 6.8, 7.5, 8.2, 9.1（×任意 10 的幂）。你算出需要 5kΩ 时应选 4.7k 或 5.1k。

### 封装与功率

| 封装 | 尺寸(mm) 英制×公制 | 额定功率 | 备注 |
|------|-------------------|---------|------|
| 0402 | 0.040×0.020 in ≈ 1.0×0.5 mm | 1/16 W | 机贴为主，手焊困难 |
| 0603 | 1.6×0.8 mm | 1/10 W | 平衡之选 |
| 0805 | 2.0×1.25 mm | 1/8 W | 手焊友好 ★推荐初学 |
| 1206 | 3.2×1.6 mm | 1/4 W | 大电流场景 |

## 2.2 电容 Capacitor

### 物理本质

两块金属板夹一层绝缘介质，能储存电荷。单位法拉(F)太大，常用：

```
1 F = 1000 mF = 10⁶ μF = 10⁹ nF = 10¹² pF

常用换算：
1 μF  = 1000 nF
1 nF  = 1000 pF
0.1 μF = 100 nF = 100000 pF   ← 最著名的去耦电容
```

类比：电容像楼顶的水箱——平时蓄水（充电），用水高峰（芯片瞬间要电流）时放水顶上，市政管网（电源）来不及供水也不怕。

### 在电路里的四大用途

1. **去耦/旁路**：芯片电源脚旁边那颗 0.1μF——吸收芯片开关瞬间的电流需求 + 把电源噪声短路到地。PCB 设计的核心话题之一。
2. **储能**：大电解电容（470μF+），稳住整板电压。
3. **耦合**：串在音频/交流信号路径中"隔直流、通交流"（音频功放输入端常见）。
4. **定时/滤波**：与电阻组成 RC 电路决定时间常数 τ=RC（复位电路 10k+0.1μF≈1ms 复位延时就是这么来的）。

### 读值：贴片电容代码

和电阻同规则：`104`=10×10⁴ pF=100nF；`106`=10μF；`220`=22pF（不是 220pF！）。

电解电容直接印数字：`470μF 16V`。

### 材质（介质）选择——重要！

陶瓷电容本体上没印材质，但材质决定了它的一切性格：

| 材质 | 温度特性 | 容量范围 | 用途 |
|------|---------|---------|------|
| C0G / NP0 | 极稳（±30ppm/℃），无压电效应 | pF~nF 级 | 晶振负载电容、射频匹配、精密滤波 ★ |
| X5R | 较稳 | 1nF~100μF | 一般去耦 ★主力 |
| X7R | 较稳（-55~125℃） | 1nF~47μF | 去耦、滤波 ★主力 |
| Y5V / Z5U | 极差（容量随电压温度暴跌 50%+） | — | 【避免使用】便宜但坑 |

> 【关键冷知识】高介电常数陶瓷电容（X5R/X7R/Y5V）有**直流偏压特性**：标称 10μF 的电容在 3.3V 偏压下实际可能只剩 4~5μF！所以电源滤波"标称值打五折"选型是常规操作。Murata/TDK 官网可查 DC bias 曲线。

### 类型总览

| 类型 | 容量范围 | 特点 | 用途 |
|------|---------|------|------|
| MLCC 多层陶瓷 | pF~100μF | 无极性、ESR 低、体积小 | 去耦主力 |
| 铝电解 | 1μF~10000μF | 有极性！ESR 高、寿命受温度影响大 | 电源储能 |
| 固态聚合物 | 10μF~1000μF | ESR 低、寿命长、贵 | 替代铝电解的优选 |
| 钽电容 | 1μF~1000μF | 容量密度大；**过压/反接会起火** | 慎用，需降额 50% |
| 薄膜 | nF~μF | 精度高、无极性、大体积 | 音频、功率因数校正 |

> 【极性警告】铝电解、钽电容**有极性**，反接轻则失效重则爆浆。钽电容反接起火是实验室经典事故。原理图和 PCB 都必须标注极性丝印。

## 2.3 电感 Inductor & 磁珠 Ferrite Bead

### 物理本质

线圈绕在磁芯上，储存磁场能量，阻碍电流变化（"电流惯性"）。

```
感抗 XL = 2πfL      频率越高阻碍越大 —— 与电容正好相反
```

### 功率电感 vs 磁珠——新手最容易混的一对

| | 功率电感 Power Inductor | 磁珠 Ferrite Bead |
|--|--|--|
| 本质 | 储能元件，L 以 μH 计 | 耗能元件，阻抗以 Ω@100MHz 计 |
| 外观 | 明显的线圈或屏蔽罩 | 小块深色方块，无绕线痕迹 |
| 用途 | DCDC 开关电源的能量传递 | 电源/信号上的高频噪声滤除 |
| 参数 | 电感量、饱和电流(Isat)、温升电流 | 100MHz 时阻抗(如 600Ω)、额定电流 |
| 类比 | 水车的飞轮 | 一块吸音海绵 |

选型要点：
- 功率电感的**饱和电流必须大于峰值工作电流的 1.3 倍以上**，否则电感量崩塌、DCDC 失控
- 磁珠串在供电里要注意 DC 偏置也会让阻抗大幅下降，大电流轨慎用
- 磁珠型号示例：600Ω@100MHz、1A，如 BLM18AG601SN1（村田）

## 2.4 二极管 Diode

单向导电阀门：电流只能从阳极(A)流向阴极(K)。

```
     A ──▶|── K          导通条件：正向压降 VF
                          硅二极管 VF≈0.7V
                          肖特基 VF≈0.3V（快、低压降）
```

### 家族成员

| 类型 | 符号特征 | VF/特点 | 典型用途 |
|------|---------|---------|---------|
| 整流二极管 (1N4007) | 普通三角 | 0.7V，慢 | 电源整流 |
| 肖特基 (SS34) | 三角带弯钩 | 0.3~0.45V，超快 | DCDC 续流、防反接 |
| LED | 发光箭头 | 红2.0V 绿2.2V 蓝3.0V | 指示灯 |
| 稳压管 Zener | 弯钩阴极 | 反向击穿恒压 | 简易基准电压 |
| TVS | 双向/单向 | ns 级响应钳位浪涌 | 接口防静电 ★重点见EMC章 |

### LED 使用速算

点亮一颗红色 LED（VF=2V，目标电流 10mA）接 5V 电源：

```
R = (5V - 2V) / 10mA = 300Ω → 取标准值 330Ω
```

LED 极性识别：实物**长脚为正**；贴片 LED 绿色 T 字标记的**横边是阴极**；原理图三角指向即电流方向。

## 2.5 三极管 BJT 与场效应管 MOSFET

两者都是"用电信号控制大电流的开关/放大器"。

| | 三极管 NPN (如 S8050) | NMOS 管 (如 AO3400) |
|--|--|--|
| 三个脚 | 基极B 集电极C 发射极E | 栅极G 漏极D 源极S |
| 控制方式 | 电流控制（基极注入电流） | **电压控制**（栅极电压决定通断） |
| 导通压降 | VCE≈0.2V（饱和时） | RDS(on)×ID，可低至几mΩ |
| 驱动功耗 | 要持续灌电流 | 几乎不耗驱动电流 |
| 新手建议 | 学概念用 | 实际项目优先用 MOS |

最常用的场景——MCU 引脚控制大电流负载（蜂鸣器/继电器/LED 灯条）：

```
         VCC(12V)
           │
        [负载]
           │D
 MCU ──1k──┤G  NMOS (AO3400)
 IO pin    │S
          GND
低电平关断，高电平(≥3V)导通。栅极串 100Ω 抑制振荡，
G-S 之间并 100k 下拉电阻保证上电默认关断。
```

PCB 注意：MOS 的 G 极走线尽量短，防止天线效应感应干扰误开通。

### 读 Datasheet 的能力比背型号重要一百倍

拿到任何 IC，datasheet 必读四部分：

1. **Features 页**：电压范围/电流能力/速率——判断能不能用
2. **Pin Definitions 表**：每个引脚的名字、方向、默认状态——画原理图的依据
3. **Typical Application 电路图**：厂商给的参考设计——照抄不会错，外围元件参数直接用
4. **Layout Guidelines 段落**：PCB 布局要求——布板时的圣旨

> 【职业习惯】画任何新芯片前，先把它的 datasheet 应用电路截图放在手边，逐个引脚对着画。90% 的"芯片不工作"事故源于漏了某个引脚的外围要求（如 CH340G 的 V3 脚必须接 0.1μF 到地）。

## 2.7 晶振 Crystal：心跳发生器

石英晶体的压电效应产生极其稳定的频率。MCU 没有"心跳"就无法执行指令。

```
典型无源晶振电路（以 8MHz 为例）：

        ┌───────┬───────┐
OSC_IN ─┤       │       ├─ OSC_OUT
        │      [8MHz]    │
       [C1]            [C2]      C1=C2=负载电容 CL 决定
        │                │       (如 CL=20pF → 选 22pF 左右)
       GND              GND
```

关键概念——**负载电容 CL**：晶振规格书标注 CL=20pF，意思是"外部电路从振荡器两端看进去的总电容应为 20pF"。外接电容 C1≈C2≈CL×2−Cs（Cs 为杂散电容约 3~5pF）→ 取 33pF 或按手册推荐。

| 类型 | 说明 |
|------|------|
| 无源晶振 Crystal | 需要芯片内部振荡电路配合，2 脚，本课主流 |
| 有源晶振 Oscillator | 内置完整振荡器，4 脚，供电输出时钟，成本高但稳定，用于对精度要求高或多芯片共享时钟 |

PCB 布局铁律（现在记住结论，第四章讲为什么）：晶振紧靠 MCU、下方 GND 完整不走线、外壳接地焊盘要接地、远离板边和干扰源。

## 2.9 封装体系全景图

封装 = 元件的"座位形状"。命名规律：

```
0402 / 0603 / 0805 / 1206     英制长宽(inch×100)，数字越小越小
                              (注意欧洲习惯用公制 1005=1.0×0.5mm)

SOT-23                        3~6 脚小晶体管/MOS
SOIC-8 / SOIC-16              鸥翼脚小 IC，间距 1.27mm，手焊友好
TSSOP / MSOP                  更密的 0.65/0.5mm 间距 SSOP
QFP / LQFP-48                 四边鸥翼脚 MCU，间距 0.5mm，可手工焊 ★
QFN-32                        底面+四周焊盘，中心有大散热地焊盘，
                              手焊较难(热风台)，底部地必须打散热过孔阵
BGA                           焊球阵列在底面，必须回流焊+精确对位，
                              打样阶段尽量避开
```

第一脚定位标志（PCB 丝印必画）：

```
SOIC/QFP: 左上角圆点 ● 或缺角        QFN: 斜切角 ◣
BGA: 圆点+左下角 A1                  二三极管: 丝印斜边对应 pin1
LED/电解: 缺口/T字横边=负极          连接器: pin1 方框加粗
```

## 2.10 元件采购常识（中国渠道）

1. **立创商城 szlcsc.com**：品类最全、原装保障、数据手册齐全，价格稍高——首选
