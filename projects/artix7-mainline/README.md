# Artix-7 FPGA Board-Level Mainline

主角：**XC7A35T-1CSG325C**

目标：训练 FPGA 板级设计，不训练 HDL。

项目 V1 聚焦：

- Bank / VCCO / IOSTANDARD
- 0.8 mm BGA escape
- Configuration / JTAG / SPI
- x16 DDR3 + MIG
- GTP teaching lane
- PDN / sequencing
- Vivado XDC ↔ KiCad co-design
- staged bring-up

正式工程文件只有在能用 Vivado/KiCad 实际验证时才进入仓库。
