# 09｜损耗、S 参数与高速通道：从“阻抗对不对”走向“通道能不能传”

> 前面讨论反射、回流、串扰和差分几何，主要建立时域直觉。本章把视角扩展到**频域与完整通道**。目标不是把你变成微波工程师，而是让你进入 FPGA GTP / SerDes 前，不再把“100 Ω”误认为高速通道的全部。

## 9.1 为什么只看阻抗不够

一条高速链路至少同时面对：

- source / package；
- PCB trace；
- via；
- AC coupling capacitor；
- connector；
- cable / backplane；
- receiver / package。

即使局部阻抗接近目标，通道仍可能因为损耗、谐振、连接器或 via stub 失败。

### 9.1.1 从“方波”转成频域：为什么高频损耗会直接改波形

<p align="center"><img src="../assets/svg/si-harmonics-channel-loss.svg" width="980" alt="Square-wave harmonics and frequency-dependent loss"></p>

数字波形不是只有“基频”这一项。理想方波可以由基波和一系列奇次谐波叠加得到；保留的高频成分越多，边沿越陡。

因此 channel 是否“保真”，不能只看某一个频点，而要看：

- 不同频率成分的 amplitude response；
- 不同频率成分的 phase / delay；
- 这些差异最后怎样映射回 time-domain waveform。

如果所有频率成分都只受到完全相同的 attenuation，并经历完全相同的 delay，波形形状可以基本保持，只是整体变小、整体变晚。

真正造成 distortion 的，是 frequency-dependent response，例如：

~~~text
low-frequency components   → loss 小
high-frequency components  → loss 大
                           ↓
edge 变慢 / pulse 展宽 / ISI
~~~

所以“channel loss”不是只看 dB 数字，而是在问：

> **这个通道还能不能把接收端需要的频谱成分按足够一致的幅度和时序送过去？**


## 9.2 频域里最先认识四个量

### S11 / Return Loss

S11 描述端口 1 输入的能量有多少返回端口 1。工程上通常用 return loss 或反射相关指标描述端口匹配质量。

不要把“某一点 100 Ω”直接等价成“整个频段 S11 都好”。

### S21 / Insertion Loss

S21 描述从输入到输出的传输。随着频率升高，PCB 通道会受到导体损耗、介质损耗、表面粗糙度、via / connector 等影响。

### Differential / Common-Mode Terms

差分通道还要关心：

- differential insertion loss；
- differential return loss；
- differential ↔ common-mode conversion。

几何不对称、过孔不对称、连接器 pin field 和 reference discontinuity 都可能提高 mode conversion。

## 9.3 三类主要损耗

### Conductor Loss

随频率升高，导体中的电流分布不再均匀。skin effect 会让电流更集中在导体表面附近，skin depth 下降，有效导电截面积减小，因此 **AC resistance 随频率上升**，导体损耗增加。

视频把 skin effect 与高频 attenuation 联系起来是正确方向；教材这里进一步把物理模型写严谨：

> **不要把 conductor loss 简化成“skin effect 让自感越来越大”。高频下最直接的损耗项是有效 AC resistance 增大；导体内部磁场被挤出后，internal inductance 并不会简单随频率上升。**

工程上还要继续考虑：

- copper roughness；
- trace width / copper thickness；
- current crowding；
- return-conductor loss；
- plating / fabrication geometry。

加宽 trace 往往可以降低 conductor loss，但同时也会改变 Z0，所以不能只以“更宽损耗更小”作为单目标优化。

### Dielectric Loss

介质并非理想无损材料。高速通道设计需要关注材料的 Dk / Df 及其频率、工艺依赖。

### Discontinuity Loss

via、pad、antipad、connector、AC coupling footprint、neck-down 都可能形成局部不连续。

## 9.4 Via Stub 为什么会从“几何问题”变成“频率问题”

贯通孔在多层板中可能留下未使用的 barrel。残桩足够长时会形成明显的谐振与 notch。

因此高速 SerDes 里会出现：

- via stub budget；
- backdrill；
- blind / buried via；
- optimized antipad。

这些并不是“高级板才炫技”，而是由通道频率与损耗预算驱动。

## 9.5 Touchstone 文件

工程里常见：

```text
.s1p
.s2p
.s4p
...
```

它们通常用于保存网络的 S 参数。

课程要求会做三件事：

1. 知道文件对应多少端口；
2. 知道 frequency sweep / reference impedance；
3. 不把厂家模型脱离其 fixture / port definition 直接拼接。

## 9.6.1 Vendor Loss Budget：为什么一条通道要“分钱”给 Package、PCB、Via 和 Connector

到了 SerDes / PCIe 这一级，`100 Ω differential` 只是最基础的几何目标。

Intel P-Tile 的设计指南提供了一个很好的教学示例：vendor 会把通道允许的总损耗拆成不同部分，而不是只给一个线宽。

~~~text
Total channel budget
= package + silicon
+ PCB trace
+ vias
+ connector / edge finger
+ other transitions
~~~

### 为什么这比“100 Ω”更真实？

假设：

- trace 本身阻抗很漂亮；
- 但 through-via 留了很长 stub；
- connector launch 有严重 discontinuity；
- FR-4 走线过长，插损已经吃掉大半 margin。

这条通道仍然可能失败。

### 教学案例：P-Tile

资料中的 P-Tile 指南给出了 8 GHz 下的明确 package / PCB loss allocation。这里**不把具体 dB 数字复制成通用规则**，因为它们属于特定 Intel 器件、封装和 PCIe 场景。

课程真正吸收的是这个方法：

~~~text
先取得 vendor channel budget
→ 扣掉 package / connector 固定损耗
→ 剩余预算分给 PCB trace + via transition
→ 再决定材料、长度、层数、backdrill / HDI
~~~

### 什么时候 4L / 6L 选择会被 Loss Budget 反推？

如果剩余 PCB budget 很紧，而你的四层方案同时需要：

- 很长 microstrip；
- 多次 through-via；
- 没有 backdrill；
- 较厚 FR-4；

那么“升级到 6L / 8L”就不是为了看起来专业，而是为了获得：

- 更好的 routing layer assignment；
- 更短的 via stub；
- 更低损耗的内/外层组合；
- 更大的 channel margin。

## 9.7 不要过早背 dB 数字

通道允许多少 insertion loss、return loss、jitter，取决于具体接口、数据率、equalization 与 compliance requirement。

本课程不提供“所有 SerDes 通用的 dB 门槛”。

## 9.8 实验建议

用同一条理想差分通道依次加入：

1. 一段阻抗不连续；
2. 一个长 via stub；
3. 一个 connector model；
4. 更高 trace loss。

观察时域波形与 S21 / S11 如何同时变化。
