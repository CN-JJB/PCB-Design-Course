# 09｜损耗、S 参数与高速通道：从“阻抗对不对”走向“通道能不能传”

> 前面讨论反射、回流、串扰和差分几何，主要建立时域直觉。本章把视角扩展到**频域与完整通道**。目标不是把你变成微波工程师，而是让你进入 FPGA GTP / SerDes 前，不再把“100 Ω”误认为高速通道的全部。

## 9.1 为什么只看阻抗不够

一条高速链路至少同时面对：

- source / package；
- PCB trace；
- via；
- AC coupling capacitor；
- connector；
- cable / backplane；
- receiver / package。

即使局部阻抗接近目标，通道仍可能因为损耗、谐振、连接器或 via stub 失败。

## 9.2 频域里最先认识四个量

### S11 / Return Loss

S11 描述端口 1 输入的能量有多少返回端口 1。工程上通常用 return loss 或反射相关指标描述端口匹配质量。

不要把“某一点 100 Ω”直接等价成“整个频段 S11 都好”。

### S21 / Insertion Loss

S21 描述从输入到输出的传输。随着频率升高，PCB 通道会受到导体损耗、介质损耗、表面粗糙度、via / connector 等影响。

### Differential / Common-Mode Terms

差分通道还要关心：

- differential insertion loss；
- differential return loss；
- differential ↔ common-mode conversion。

几何不对称、过孔不对称、连接器 pin field 和 reference discontinuity 都可能提高 mode conversion。

## 9.3 三类主要损耗

### Conductor Loss

随频率升高，电流分布发生变化；skin effect 与铜表面粗糙度都会影响有效损耗。

### Dielectric Loss

介质并非理想无损材料。高速通道设计需要关注材料的 Dk / Df 及其频率、工艺依赖。

### Discontinuity Loss

via、pad、antipad、connector、AC coupling footprint、neck-down 都可能形成局部不连续。

## 9.4 Via Stub 为什么会从“几何问题”变成“频率问题”

贯通孔在多层板中可能留下未使用的 barrel。残桩足够长时会形成明显的谐振与 notch。

因此高速 SerDes 里会出现：

- via stub budget；
- backdrill；
- blind / buried via；
- optimized antipad。

这些并不是“高级板才炫技”，而是由通道频率与损耗预算驱动。

## 9.5 Touchstone 文件

工程里常见：

```text
.s1p
.s2p
.s4p
...
```

它们通常用于保存网络的 S 参数。

课程要求会做三件事：

1. 知道文件对应多少端口；
2. 知道 frequency sweep / reference impedance；
3. 不把厂家模型脱离其 fixture / port definition 直接拼接。

## 9.7 不要过早背 dB 数字

通道允许多少 insertion loss、return loss、jitter，取决于具体接口、数据率、equalization 与 compliance requirement。

本课程不提供“所有 SerDes 通用的 dB 门槛”。

## 9.8 实验建议

用同一条理想差分通道依次加入：

1. 一段阻抗不连续；
2. 一个长 via stub；
3. 一个 connector model；
4. 更高 trace loss。

观察时域波形与 S21 / S11 如何同时变化。
