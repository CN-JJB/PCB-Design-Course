# 项目一：USB 转 UART 小板（四层入门）

> 你的第一块四层板。电路极简（一颗芯片），全部精力用于**掌握多层板工作流**：叠层设置、USB 差分对、缝合孔、阻抗控制下单。出错成本最低，练手价值最大。

---

| 项 | 规格 |

| 功能 | USB 转串口(TTL 电平)，给其他板子当下载器/调试器 |
| 接口 | USB Type-C(母) ×1、2.54mm 排针 ×6 |
| 板尺寸 | 25×18mm |
| 层数 | 4 层（TOP-GND-PWR-BOTTOM） |
| 供电 | USB 5V 输入，3.3V TTL 输出 |

## 2. 器件选型：CH340C 还是 CH340G？

| 对比 | CH340C | CH340G |
|------|--------|--------|
| 晶振 | **内置，无需外接** | 需 12MHz 晶振 |
| V3 引脚 | 内部稳压输出仍需电容 | 同左 |
| 价格 | 略贵 ¥0.5 | 便宜 |
| 结论 | ★本项目选 C | 少两元件少一个坑 |

> 选型哲学：能内置的外围就别外挂。少一个晶振 = 少一处不起振风险 + 少一块布局面积。

## 3. 原理图逐引脚讲解

CH340C SOP-16 全引脚定义与外围要求：

```
         ┌───────────┐
   GND ──┤1      16├── VCC ←─ 5V输入 + 0.1μF去耦
   TXD?──┤2? 实际以datasheet为准
```

按官方 datasheet 的 Pin Definitions 逐一列出（本项目实际连接）：

| Pin | 名称 | 方向 | 连接到 | 外围要求 | 为什么 |
|-----|------|------|--------|---------|--------|
| 16 | VCC | 电源 | +5V | 0.1μF 就近到地 | 主电源去耦铁律 |
| 15? (V3) | V3 | — | 0.1μF 到 GND | **必须！** | 内部 3.3V 稳压器输出端，漏接则芯片不工作——新手第一大坑 |
| 1? (GND) | GND | 地 | GND | — | — |
| UD+ / UD- | USB 数据 | 双向 | USB_DP / USB_DN | 直连 USB 座，差分对布线 | 12Mbps 全速 |
| TXD | 串口发 | 出 | 排针 TX | 可串 470Ω 保护 | 输出脚 |
| RXD | 串口收 | 入 | 排针 RX | 可串 470Ω | 5V 容忍输入 |
| DTR/RTS | 流控 | 出 | 排针 DTR/RTS | — | 自动下载用 |

USB Type-C 母座接线（只做设备模式最简配置）：

```
CC1 ──[5.1kΩ]── GND     ← 必须有！没有它很多C-C线不供电
CC2 ──[5.1kΩ]── GND     (5.1k=默认USB电流档 Rp 上拉在源端，
                         设备端是 Rd 下拉，阻值5.1k)
VBUS ── +5V 网络(加0.1μF+10μF)
D+ / D- ── CH340 的 UD+/UD-
外壳屏蔽焊盘 → GND 大面积连接
```

> 【为什么 CC 要下拉】Type-C 规范：源端靠检测 CC 上的 Rd 判断"有设备插入"才打开 VBUS。漏掉这两个电阻 = 插 A-to-C 线能用、插 C-to-C 线没电。经典翻车点。

## 5. 叠层与阻抗目标

叠层：嘉立创 JLC04161H（TOP-GND-PWR-BOT，参数见理论篇）。

| 网络 | 类型 | 目标阻抗 | 计算结果(w/gap) | 所在层 |
|------|------|---------|----------------|--------|
| USB_DP/DN | 差分 | 90Ω ±10% | 约 0.30mm/gap 0.20mm（以计算器实测为准） | L1 微带 |
| 其余信号 | 单端 | 不控 | Default 0.25mm | L1/L4 |
| +5V/+3V3 | 电源 | — | 平面(L3)+短粗线 | L3 |

> 本项目 USB 是全速 12Mbps，90Ω 属于"养成习惯"性质；但下单时照样勾选阻抗控制并填表——第一次走完整个流程比数值本身重要。

## 6. 布局分区图

```
┌───────────────────────┐
│ [J1 USB-C]            │ 25mm
│    ↓ 短直差分           │
│      [U1 CH340C]       │
│  [C_vcc][C_v3]        │
│              [J2排针]   │
│ v1.0 20260826         │
└───────────────────────┘
        18mm
```

布局要点：

- USB 座贴上边缘，CH340 正对其后，**差分线长度 <8mm**
- 两颗关键电容（VCC/V3）紧贴对应引脚 ≤1.5mm
- 排针贴右边缘，TX/RX/DTR/RTS/VCC/GND 顺序与杜邦线习惯一致
- 板名丝印放左下角空白区

## 9. 焊接与调试步骤

```
焊接顺序：
① 先贴片后直插：U1(拖焊) → 阻容 → USB座(先中间信号脚
  定位再焊两侧大接地腿补足锡量) → 排针
② 目检放大镜重点：SOP16 相邻脚短路、V3 电容实际落点
③ 安全上电仪式(零基础章流程)：测+5V对地阻抗→插USB
④ 验证：万用表量 V3 引脚应有 ~3.3V(内部稳压输出正常标志)
⑤ 电脑识别：装驱动(ch341ser) → 设备管理器出现 COM 口
⑥ 回环测试：排针上把 TX 和 RX 短接，
   串口助手发什么回什么 = 全链路通
⑦ 对接真实目标板烧录测试
```

## 10. 常见翻车点

| 现象 | 根因 | 防范 |
|------|------|------|
| 插 C-C 线没电 | CC 无 5.1k 下拉 | 规格书阶段就写死 |
| COM 口出现但乱码 | 波特率不匹配/晶振(若用G版)虚焊 | 选 C 版规避 |
| 时好时坏 | USB 座接地腿虚焊(应力) | 大接地腿足量锡+定位柱款 |
| 完全不识别 | V3 电容忘焊或错接 VCC | 清单第 1 条 |
| 能通信但 EMI 测试炸 | 差分换层无伴飞孔 | 本项目直接免换层 |
