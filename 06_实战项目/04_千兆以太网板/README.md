# 项目四：千兆以太网 PHY / RGMII 六层案例

> 摘下四层板训练轮的时刻。第一次上六层：内层走线、真实意义的阻抗控制（100Ω±10%）、Bob Smith 端接、以及"参考平面纪律"的全面实战。

---

## 1. 需求规格书

| 项 | 规格 |
|----|------|
| 功能 | 千兆以太网物理层接口板（RGMII 接 MAC/测试主机），含 USB 供电与调试串口 |
| 方案 | MAC 由外部提供；本案例定位为 PHY 评估/互连训练板，MDI 到 RJ45，MDC/MDIO + RGMII 引到板间接口。STM32F407 本身不提供千兆 RGMII MAC，因此不再把它描述为可直接驱动该千兆 PHY 的主控。 |
| 板尺寸 | 50×40mm |
| 层数 | **6 层** SIG-GND-SIG-PWR-GND-SIG |

> 教学取舍：完整的千兆 MAC+PHY 系统(STM32F407+KSZ9031)复杂度适合项目六之后。本项目聚焦 PHY 与 MDI 高速部分——这正是六层训练的核心。RGMII 版作为选做挑战。

## 2. 方案架构

```
[RJ45(带网变)] ──MDI×4对── [KSZ8081MLX? 千兆需88E1512级]
```

修正决策：KSZ8081 是百兆 RMII PHY。**千兆必须选支持 1000Base-T 的 PHY**：

| 型号 | 速率 | 接口 | 封装 | 结论 |
|------|------|------|------|------|
| KSZ8081RNA | 100M | RMII | QFN32 | 百兆备选(简化版) |
| **RTL8211F** | 1000M | RGMII | QFN40 | ★主流性价比之选 |
| KSZ9131 | 1000M | RGMII | QFN48 | 高端选项 |

最终规格书修正为 **RTL8211F-CG + RGMII 接口**（MAC 侧引出到排针供 F407 主控或后续核心板对接）。等长约束按理论篇速查表执行。

## 3. 核心电路逐块讲解（引脚级）

### 3.1 RTL8211F 电源体系——四种电压域！

```
VDD10/2.5? 以datasheet实际为准的三域：
+3V3(IO) ← LDO from 5V
+1V1(CORE) ← RTL8211F 内置LDO? F版内置核心稳压，
            只需外挂电容(这是它比老款省事的地方)
+1V8? 部分批次需要外部
→ 务必对照你采购批次的 datasheet Power 段落逐一确认。
每域去耦按"一引脚一容"铁律。
```

### 3.2 时钟系统——RGMII 125 MHz 与 PHY 参考时钟

```
两种方案：
A. 25MHz 无源晶振 + PHY 内部PLL倍频 → 输出CLK125给MAC
   (RGMII 模式推荐)
B. 外部 50MHz 有源晶振同时喂 PHY 和 MAC(RMII 才需要)
本板选 A：
XTAL_IN/OUT ── 25MHz ±50ppm + 22pF负载电容×2
时钟输出 CLK_125 → 串 33Ω → RGMII 排针区
```

### 3.3 MDI 四对差分——本项目的灵魂

```
PHY TXP0/TXN0 …TXP3/TXN3(4对) 
    → 网络变压器(集成在RJ45座内) 
    → RJ45

布线要求汇总表：
┌────────┬─────────────────────────────┐
│ 阻抗    │ 100Ω 差分 ±10%               │
│ 对内等长│ <0.5mm                      │
│ 对间   │ 尽量匹配 <2mm(百兆无硬性)      │
│ 过孔   │ 免打孔最佳；必须打则对称成对    │
│ 层     │ L1 直连 RJ45(同层直达!)       │
│ 参考连续│ 全程 L2 GND 完整投影          │
└────────┴─────────────────────────────┘
```

### 3.4 Bob Smith 端接网络——网变中心抽头的处理

```
网变的"空闲线对+中心抽头"侧：
TCT(4个变压器中心抽头并联)
  ├─[75Ω]─[1nF/2kV]─ ChassisGND
  └─ 其余空线对各经75Ω汇到同一节点
  
ChassisGND(机壳地) 与 PCB GND 之间：
  [1nF/2kV高压电容] ∥ [1MΩ泄放电阻] 单点连接
作用：为共模噪声提供入地通路+隔离直流电位差
布局：这堆器件放在 RJ45 正后方专属区域，
     高压电容耐压必须 ≥2kV!
```

### 3.5 LED 与配置脚

```
LED0/1/2 → 速率/活动指示(串470Ω到LED到3V3)
PHYAD[2:0] 地址 straps → 本板全接地=地址0
RXDLY/TXDLY straps → RGMII 延时选择，
  RTL8211F 支持内部延时，strap 配 RXDLY=1(TXDLY=1)?
  以 datasheet strap 表为准并在丝印注明。
```

## 5. 六层叠层与阻抗落地

```
采用 JLC 六层标准层压(以官网当期参数为准)：
L1 SIG_TOP   ─ PP 0.1mm
L2 GND       ─ PP 0.21mm  
L3 SIG_MID   ─ Core 0.3mm
L4 PWR       ─ PP 0.21mm
L5 GND       ─ PP 0.1mm
L6 SIG_BOT

阻抗计算结果(嘉立创计算器示例量级，务必自算)：
L1 微带 50Ω单端:  w≈0.35mm? (h=0.1 更薄→线更细 w≈0.20~0.25)
注意！介质变薄后同样50Ω的线宽显著变小——
这就是为什么每次换叠层都必须重算规则。
USB90差分(L1): w≈0.20 s≈0.13
MDI 100差分(L1): w≈0.18 s≈0.15 (示例值)
```

## 6. 布局分区图

```
┌────────────────────────────────────┐
│ [RJ45+网变]                        │← 左边缘
│   │ [BobSmith端接区:75Ω×5+C2kV]    │
│   └────4对MDI────┐                 │
│                  ▼                 │
│            [U1 RTL8211F]           │
│        [Y1 25M][去耦阵列]           │
│   [电源链:5V→LDO→3V3]              │
│         [RGMII排针][SWD/UART]      │
└────────────────────────────────────┘
黄金法则：MDI 路径总长压到最短——
RJ45 和 PHY 的距离决定一切，先锁这两个再摆其他。
```

## 7. 布线执行要点

```
① MDI 四对最先布：L1 一气呵成，全程目视 L2 投影完整
② 每对长度记录进 Net Inspector 表格
③ RGMII 组(12根)：组内以 CLK 为基准 Tune，
   容差按 tCO 补偿计算(理论篇速查表)
④ REF_CLK125 串33Ω+远离其他信号3W+
⑤ 电源过孔就近入 L4 平面；1V1 域(若外置)独立Zone
⑥ 缝合墙：板边+RJ45金属壳四周加密
⑦ L6 底层留给 GPIO/调试走线(参考L5 GND，质量好)
```

## 9. 焊接与调试步骤

```
① 回厂 SMT(QFN40 手焊免谈)；到手后手焊排针/RJ45
② 安全上电仪式 → 各电源域电压核对
③ 读 PHY 寄存器(BMCR/BMSR)：MDIO 应答 = 数字部分活了
④ 自协商观察：插网线看 LED 协商出 1000M Full
⑤ ping 测试 + iperf 打流 ≥900Mbps = 全链路合格
⑥ 若协商只有100M：查 MDI 差分阻抗/网变引脚映射
⑦ 若完全无应答：25MHz 起振？strap 正确？
```

## 10. 常见翻车点

| 现象 | 根因 |
|------|------|
| 只能协商 10/100M | MDI 某一对断路/阻抗离谱/网变引脚错 |
| 能通但丢包严重 | 100Ω 失配过大/对内不等长/跨分割回流 |
| PHY 无应答 | 1V1 核心电未起/strap 错/晶振未振 |
| 网口热插拔烧板 | 机壳地连接错误(高压电容位置装反侧) |
| EMI 超标于 125MHz 及谐波 | CLK125 未串阻/走线过长近边缘 |
