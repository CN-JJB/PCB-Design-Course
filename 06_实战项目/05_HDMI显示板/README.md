# 项目五：HDMI 显示输出板（六层高速）

> 等长精度的极限挑战：±0.1mm 级对内匹配、组间对齐时钟、参考平面切换管理、ESD 防护布局。完成本项目，你的 Length Matching 工具链将全面成熟。

---

## 1. 需求规格书

| 项 | 规格 |
|----|------|
| 功能 | 将并行 RGB/LVDS 源? 简化教学定位：**HDMI 连接器+ESD/电平保护通道板**——从 FPC 或排针接入已有 TMDS 信号源(如 FPGA 开发板)，完成"高速通道工程"训练 |
| 接口 | HDMI-A 母座、输入端 2×10 高密排针(FPC 可选) |
| 板尺寸 | 45×35mm |
| 层数 | 6 层 |
| 核心指标 | TMDS 3 对数据+1 对时钟全通道 100Ω±10%、组内 ±0.15mm、组间对齐时钟 ±2.5mm |

> 为什么不做完整 HDMI 发送芯片方案？TMDS 发送需要专用 TX 芯片或 FPGA，偏离 PCB 布线主题。本项目的价值在**通道工程**——这正是打样能验证的部分。

## 2. HDMI 接口解剖

```
HDMI-A 19脚中的高速部分：
TMDS Data2± / Data1± / Data0±   三对差分
TMDS Clock±                      一对时钟
DDC(SCL/SDA) + CEC               I2C类低速(EDID通信)
HPD                              热插拔检测
+5V                              源端供电输出

低速信号处理：
DDC 线上必须串 55Ω? 实际规范：源端上拉3.3V经1k? 
简化执行：SCL/SDA 各串 33Ω + TVS 阵列，
CEC 串 100Ω，HPD 经 1k 上拉到 5V 分压网络。
以 TI SII902x 类应用图为准抄结构。
```

## 3. ESD 与电平保护方案

### 方案对比

| 方案 | 组成 | 适用 |
|------|------|------|
| **集成式 TPD12S015** | 单芯片完成 5V开关+电平移位+ESD | ★推荐，省心但贵且 QFN 手焊难 |
| 分立式 | TVS阵列(TPD4E05U)+磁珠+阻容拼 | 学习版选择，器件好买 |

### 分立方案电路（每对 TMDS）

```
输入排针 ──┬──[0Ω/预留]──┬── HDMI座
           │             │
        [TVS双向×4]   [共模磁珠可选]
           │             │
          GND 直接落平面过孔×2

TVS 选型要求：
- 结电容 <0.5pF! (大电容会吃掉 3.4Gbps 眼图)
- 典型件: TPD4E05U06 / ESD224 系列
布局铁律复习：距 HDMI 座 <5mm、双地孔直落平面。
```

## 4. 六层叠层的针对性调整

本项目把 TMDS 放哪层？决策分析：

```
选项A：L1 微带(顶层直达连接器)
 + 不换层零残桩、加工直观
 − 外层阻抗受阻焊层影响(+~2Ω)、辐射稍大
选项B：L3 带状线
 + 双侧屏蔽、EMC 最优
 − 必须换层进出连接器→引入过孔不连续与回流管理负担

结论(教学)：选 A——L1 直达。理由：3.4Gbps 在普通 FR4
的损耗尚可容忍，而"零过孔"的价值大于屏蔽收益。
真实产品多走内层+背钻，那是量产课题。
```

叠层数值仍用标准 JLC 六层；重算 L1 的 100Ω 差分 (w,s)——注意 HDMI 板通常有阻焊覆盖(SMask on trace)，计算时勾选"solder mask"选项，线宽会比无阻焊略宽。

## 5. 布局分区图

```
┌──────────────────────────────────┐
│ [HDMI-A座]                        │← 左边缘
│ [TVS阵列×4 紧贴座后<5mm]           │
│   ║ 4对TMDS走廊(包地缝孔墙)         │
│ [磁珠区]                           │
│   ║                               │
│ [输入2x10高密排针]          [DDC   │
│                    处理区][5V开关] │
└──────────────────────────────────┘
黄金法则同项目四：连接器与输入端的距离=一切。
本板 45mm 长 → 4对线平均长度约30mm，可控。
```

## 6. 布线执行手册（等长全流程）

```
① 四对全部 L1 平行走廊布通，对间距 ≥4w
   (对间串扰控制)，走廊两侧包地+缝合孔墙间距8mm
② Net Inspector 记录 8 根线长度
③ 以 Clock± 为基准：
   数据三对的"平均长度"补到 = 时钟平均长度
④ 对内 Tune：每对内长短差调到 <0.15mm
   KiCad Tune 工具的目标值手动填：
   目标 = 该对两根的平均值
⑤ 蛇形纪律：Pitch≥3w、振幅≥6w、避开TVS区域
⑥ 全部完成后导出长度报告归档
⑦ DRC 开启 diff pair gap/max skew 检查项复核
```

### 参考连续性专项检查

```
L1 的四对投影下方是 L2 GND —— 本板 L2 不做任何分割 ✓
唯一风险点：HDMI 座的大面积固定腿若接机壳地?
HDMI 座外壳腿处理：
- 全部接 GND(教学板简化) 或
- 经 RC(1M∥1nF) 单点接机壳地(严格EMC版)
二选一并丝印注明版本。
```

```

[ ] 组间对齐时钟 ≤2.5mm
```

## 8. 焊接与调试步骤

```
① SMT 密脚件回厂；手焊 HDMI 座(大接地腿足锡)
② 安全上电仪式
③ 无源验证(不接任何源)：
   万用表确认各对差分线到座引脚通断正确
④ 有源验证：接 FPGA 开发板输出 720p 测试图案
   → 显示器点亮 = 通道合格
⑤ 升级 1080p60 → 若闪屏/雪花：眼图裕量不足，
   检查等长报告与 TVS 结电容实测
⑥ (进阶)借示波器+差分探头测 CLK 对波形质量
```

## 9. 常见翻车点

| 现象 | 根因 |
|------|------|
| 480p 能亮 1080p 黑屏 | 高频段塌陷：TVS 电容太大/蛇形自耦合/残桩 |
| 图像随机雪花线 | 差分阻抗失配或对内 skew 过大 |
| 偶尔整屏闪烁 | HPD 抖动/DDC 通信不稳(查上拉) |
| 显示器识别不出设备 | 5V 未输出/保险丝断/HPD 分压错 |
| EMI 测试 750MHz 炸表 | TMDS 谐波：包地墙失效或座子接地不良 |
