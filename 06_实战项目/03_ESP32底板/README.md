# 项目三：ESP32 Wi-Fi 模组底板（四层 RF 入门）

> 第一次接触射频区域。你不需要懂电磁场理论，但必须学会三条纪律：天线净空、模组供电、strapping 引脚。这三件事决定了 90% 的 ESP32 板子的成败。

---

## 1. 需求规格书

| 项 | 规格 |
|----|------|
| 功能 | ESP32-WROOM-32 底板：USB 供电+自动下载+GPIO 全引出 |
| 接口 | USB-C、UART 自动下载、双排 GPIO、3V3/GND 电源排针 |
| 板尺寸 | 40×32mm（模组居中偏一侧） |
| 层数 | 4 层 TOP-GND-PWR-BOTTOM |
| 关键约束 | 天线区净空；模组峰值电流 500mA |

## 2. 为什么用模组而不是裸芯片

| 方案 | 射频设计负担 | 认证 | 结论 |
|------|-------------|------|------|
| 裸 ESP32 芯片 | 阻抗匹配/天线设计/屏蔽罩 | 自行认证 | 学习阶段自讨苦吃 |
| **WROOM-32 模组** | 模组内部已完成，板上只需净空 | 模组带 CE/FCC/SRRC | ★本项目选择 |

模组的代价：贵几块钱、大一点。学习期这是最划算的交易。

## 3. 核心电路逐块讲解

### 3.1 供电电路——500mA 峰值是认真的

```
USB 5V ─[F 1A保险丝]─┬─ AMS1117-3.3? 
                     │   ⚠ 压差1.1V@500mA=0.55W 发热可观
                     │   更优：ME6217C33(低压差)或MP2359 DCDC
                     ▼
                  +3V3 ──┬─ 模组 VDD(3脚和4脚都要!)
                         ├─ C_Bulk 100μF固态 ←★紧贴模组
                         └─ C 10μF+0.1μF×2
                         
Wi-Fi 发射瞬间电流可达 300~500mA，
若 Bulk 电容不足 → 电压跌落 → brownout 复位循环。
现象特征：一联网就重启 = 电源不行，先查电容再看代码。
```

模组电源引脚注意：WROOM-32 的 pin1(VDD) 和 pin3? 按 datasheet 实际为 VDD 两处都要接 3V3 且**各自就近去耦**。

### 3.2 Strapping 引脚——上电瞬间的"命运开关"

ESP32 在 RESET 释放瞬间采样以下引脚决定启动模式：

| 引脚 | 上电要求 | 本板处理 |
|------|---------|---------|
| EN(CH_PD) | 必须为高，且不能太快上斜率? | 10k 上拉 + 1μF 下地(延时) + 按键 |
| IO0 | 高=Flash启动 低=下载模式 | 10k 上拉；下载电路可控拉低 |
| IO2 | 下载模式需低或悬空? 规范：don't care高阻即可 | 10k 下拉保平安 |
| IO12(MTDI) | 决定 flash 电压!高电平会烧 1.8V 配置 | 10k 下拉强制低 |
| IO15 | 控制启动日志静默 | 10k 上拉(默认输出日志) |

> 【为什么 EN 要 RC】EN 直接上拉也能工作，但 USB 缓慢充电时模组可能在电压爬坡半途反复复位。RC(10k+1μF≈10ms) 保证干净的一次性启动。这是乐鑫官方硬件设计指南的推荐值。

### 3.3 自动下载电路——DTR/RTS 的魔术

CH340(C/N/G 均可)的 DTR/RTS 通过两个 NPN 三极管交叉控制 EN 和 IO0：

```
逻辑真值(关键！两管交叉是为了允许"单独拉低")：
DTR=1 RTS=0 → EN保持高, IO0拉低 → 进入下载模式
DTR=0 RTS=1 → EN拉低(复位)
随后 DTR=1 RTS=1 → EN回高 → 从下载模式启动? 
实际时序由 esptool 自动控制：
复位进bootloader→IO0仍低→进入下载等待→烧录→软复位运行

电路(标准开源方案，照抄无数验证过的版本):
        +3V3
         │ [10k]
RTS ─b──┤Q1 NPN   c──→ EN (经此拉低EN? 注意极性)
         e
         │
        GND
(DTR 同构驱动 IO0；两路集电极各串10k到被控网络做隔离)

⚠ 三极管方向和交叉关系画错 = 只能手动按BOOT才能下载。
   直接抄乐鑫官方 DevKit 原理图这一页。
```

### 3.4 UART 连接

```
CH340 TXD ──→ 模组 RXD(IO3/U0RXD)
CH340 RXD ←── 模组 TXD(IO1/U0TXD)
共地；线上各串 470Ω 保护电阻可选。
IO9/IO10 通常不用(SPI flash 内部占用)，不引出。
```

## 5. 叠层与 RF 净空规划

叠层同前（JLC04161H）。本项目的灵魂是天线区：

```
模组摆位与净空图(顶视)：

      ┌─────────────────────────────┐
      │            ┌─────────┐      │
      │   [U1模组]  │ 天线区   │ ═══► │←板边
      │            │ 净空!    │      │
      │            └─────────┘      │
      │   模组天线段必须伸出板内禁布区  │
      │   或贴近板边朝外              │
      └─────────────────────────────┘

净空铁律：
① 模组本体含天线的延伸方向上，
   所有层(L1~L4)不得有任何铜(走线/敷铜/过孔/丝印除外文字)
② KiCad 操作：在天线投影区画 Keep-out 区域
   (Place → Add Keepout Area)勾选全部铜层
③ 天线前方至少留出 ≥10mm 无金属空间；
   若外壳有金属件需在结构上避让
④ 底层正对天线的位置同样禁铜(近场耦合)
```

## 6. 布局分区图

```
┌──────────────────────────────────┐
│ [USB-C]                          │
│   ↓                              │
│ [CH340]  ┌────────┐   [LDO+Bulk] │
│ [Q1][Q2] │ ESP32  │══天线朝外═══► │
│          │ WROOM  │             │
│ [EN键][BOOT键]                   │
│ [GPIO双排针沿下边]                 │
│ v1.0                             │
└──────────────────────────────────┘
布局原则：USB链在左，RF朝右边缘，数字 GPIO 向下引出，
        LDO 远离天线侧(发热体远离RF)。
```

## 7. 布线参数表

| 网络 | 参数 | 纪律 |
|------|------|------|
| USB 差分 | 90Ω 目标 | <10mm 直连 |
| UART(TX/RX/EN/IO0) | 0.25mm | 短直；EN 线远离天线区 |
| +3V3 到模组 | 0.5mm×2 并联 或打双孔入平面 | 路径阻抗最低优先 |
| 模组 GND 焊盘 | 每个接地焊盘独立过孔落 GND 平面 | 模组散热+回流双重需要 |
| GPIO 引出 | 0.25mm | 允许走 L4(低速无所谓参考 PWR) |

缝合孔墙任务：天线净空区四周一圈密缝(≤8mm)+板边常规。

## 8. 检查清单

```
RF
[ ] 天线净空区全层禁铜(Keep-out已设)
[ ] 天线指向板外无遮挡方向
[ ] 模组周围≥8mm间距缝合墙
电源
[ ] Bulk 100μF 距模组VDD ≤5mm
[ ] LDO 散热铜足够(AMS1117方案时)
Strapping
[ ] 五个strapping引脚的上拉/下拉逐一核对表3.2
[ ] EN 有 RC 且按键可手动复位
自动下载
[ ] Q1/Q2 极性与交叉关系对照官方图复核
[ ] IO0 可被拉低且平时为高
制造
[ ] DRC/Gerber 清零
[ ] 阻抗表(仅USB一行)填写
```

## 9. 焊接与调试步骤

```
① SMT 贴模组(热风台或回厂)；手焊其余
② 安全上电：测 3V3 轨阻抗→上电→量 3V3 精度±3%
③ 不烧程序观察：上电瞬间串口(115200)应有 ROM boot 日志乱码或正常输出
④ 安装 CP210x/CH340 驱动识别 COM 口
⑤ esptool 烧 hello_world：
   python esptool.py --port COMx write_flash 0x1000 bin
   自动下载电路应免按任何键完成
⑥ 若失败：手按住 BOOT 再点下载 → 能成则自动下载电路有问题(查Q1/Q2)
⑦ Wi-Fi 扫描测试程序 → 路由器列表出现 = RF 正常
⑧ brownout 测试：持续 ping 泛洪下载流量，观察是否重启
```

## 10. 常见翻车点

| 现象 | 根因 | 防范 |
|------|------|------|
| 一连 WiFi 就重启 | Bulk 不足/LDO 峰值不够 | 表格级核对供电 |
| 必须 manual BOOT 才能下载 | 自动下载管接反/交叉错 | 抄官方图别自创 |
| 完全没日志 | TX/RX 接反(最常见没有之一) | 回环测试先行 |
| 信号弱距离短 | 天线区有铜/靠近金属外壳 | 净空清单第1条 |
| 偶发 boot 循环 | IO12 被外部上拉(flash电压误配) | strapping 表 |
| 插着调试正常拔了就死 | EN 无 RC 依赖慢速上电 | RC 必备 |
