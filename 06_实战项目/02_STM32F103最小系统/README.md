# 项目二：STM32F103 最小系统板（四层电源实战）

> 在项目一学会"流程"之后，本项目练"电源"：第一次用整层 PWR 平面供电，布置完整的去耦电容阵列，处理晶振的净空。这块板也是你后续所有项目的"标准积木"。

---

## 1. 需求规格书

| 项 | 规格 |
|----|------|
| 功能 | STM32F103C8T6 可编程最小核心（72MHz 全速运行） |
| 接口 | USB(供电+可选拟串口?本版仅供电)、SWD 调试、双排 GPIO 2×20、复位键 |
| 板尺寸 | 36×28mm |
| 层数 | 4 层 TOP-GND-PWR-BOTTOM |
| 扩展 | 预留 SPI Flash 焊位(W25Q64 SOIC-8) |

## 2. 电源树

```
USB VBUS +5V
   │
   ├─[保护:0.5A自恢复保险丝]─[TVS:USBLC6可选]
   │
   AMS1117-3.3 LDO
   │ 输入侧 C 10μF
   │ 输出侧 C 22μF(钽/固态) + 0.1μF
   ▼
+3V3 平面(L3) ──┬─ MCU VDD/VDDA
                ├─ W25Q64 VCC
                └─ GPIO 引出排针

模拟域：+3V3 ─[磁珠600Ω]─┬─ VDDA
                        └─[1μF]+[0.1μF]到地
```

> 为什么 LDO 输出用 22μF：AMS1117 的稳定性要求输出电容 ≥10μF 且 ESR 在窗口内；陶瓷大容值注意 DC bias 折半后仍需 ≥10μF → 标称 22μF。

## 3. MCU 引脚级连接表

STM32F103C8T6 LQFP48 关键引脚（完整 GPIO 分配见你的原理图）：

| Pin | 名称 | 连接 | 外围 | 说明 |
|-----|------|------|------|------|
| 24/36/48 | VDD_1/2/3 | +3V3 | 各配 0.1μF ≤2mm | 三处独立去耦 |
| 9 | VDDA | 磁珠后模拟3.3V | 1μF+0.1μF | 模拟域隔离 |
| 23/35/47 | VSS_1/2/3 | GND | 直接落平面过孔 | — |
| 8 | VSSA | GND | 与 VDDA 电容共地 | — |
| 7 | NRST | 复位网络 | 10k上拉+0.1μF+按键 | RC≈1ms |
| 5/6 | OSC_IN/OUT | 8MHz 晶振 | 22pF×2 + 1MΩ并联电阻(可选) | CL 匹配 |
| 44 | BOOT0 | 10k 下拉 | 排针可选跳 3V3 | ISP 模式入口 |
| 20 | BOOT1(PB2) | 10k 下拉 | — | 固定从Flash |
| 34/37 | PA13/PA14 | SWDIO/SWCLK | 4P 排针 | 调试口 |
| 2 (PC13) | — | 用户 LED | 1kΩ 串联 | 心跳灯 |
| 其余 GPIO | — | 双排针引出 | 每隔 8~10 个 GPIO 配一对 VDD/GND 针 | 方便插面包板 |

## 5. 叠层与平面规划

叠层同 JLC04161H。L3 平面的分割地图：

```
┌─────────────────────────────┐
│                              │
│      +3V3 大区(占85%面积)     │
│                              │
│  ┌──────┐                   │
│  │+3V3A │← 磁珠后的模拟域     │
│  │ 小岛  │   (供VDDA)        │
│  └──────┘                   │
└──────────────────────────────┘
分割缝 0.6mm；模拟岛只覆盖 MCU 的 VDDA 角落。
```

> 【思考】只有两个电压域要不要分割？要——VDDA 隔离的价值不在耐压而在噪声。数字开关噪声经磁珠进不了模拟岛，这是零成本的干净度。

## 6. 布局分区图

```
┌────────────────────────────────┐
│ [USB座] [F1][U2 AMS1117]        │ ← 电源链贴边直线排布
│         [Cin][Cout]             │
│                                │
│        [Y1 8MHz+C C]           │ ← 晶振紧邻MCU上方
│   [SW1复位] ┌─────┐             │
│             │ U1  │ [BOOT R]    │
│   去耦阵环绕  │MCU  │             │
│             └─────┘             │
│  [W25Q64焊位]      [SWD 4P]     │
│                    [GPIO双排]   │
└─────────────────────────────────┘
```

### 布局关键动作

1. **电源链一条线**：USB→保险丝→LDO→输出电容，热路径顺直无回头
2. **晶振净空圈**：以晶振为中心 3mm 半径内（顶底两层）无任何其他元件和走线
3. **去耦阵列就位**：三颗 0.1μF 分别贴三个 VDD 引脚外侧 1~2mm，VDDA 组合贴模拟角
4. **SWD 排针在角落**：调试时插拔顺手

## 7. 布线参数表

| 网络 | 宽度 | 层路径 | 特殊纪律 |
|------|------|--------|---------|
| NRST | 0.25 | L1 直连 | 远离晶振≥5mm，全长<25mm |
| OSC_IN/OUT | 0.25 | L1 | <4mm 对称，禁止打过孔 |
| SWDIO/SWCLK | 0.25 | L1/L4 允许换层 | 换层伴飞地孔 |
| VDDA 模拟走线 | 0.3 | L1 | 只走模拟岛投影内 |
| GPIO→排针 | 0.25 | 自由 | 底层允许大量使用(参考PWR的局限已知) |
| +3V3 支路 | 0.4~0.5 | 就近打孔入 L3 平面 | 每个用电点独立落孔 |

## 8. PDN 设计书（目标阻抗法实操）

```
轨道：+3V3，负载 ~80mA(72MHz满速跑+GPIO)
瞬态假设 ΔI=50mA，允许 ΔV=±3%(99mV)
Z_target = 99mV/50mA ≈ 2Ω —— 很宽松！

配置：
- 每VDD引脚 0.1μF ×3 (MHz~几十MHz段)
- LDO出口 22μF (低频储能)
- L3/GND平面对 ≈1nF 分布电容(GHz段)
结论：轻松达标。但布局纪律(≤2mm/双孔落地)不可松懈，
     因为纪律比数值更难养成。
```

## 10. 焊接与调试步骤

```
① SMT 回厂贴 MCU+Y1(推荐)，手焊其余
② 安全上电仪式：3V3对地阻抗→上电→测各轨
③ ST-Link 连接 SWD → KeilCubeProgrammer 能识别芯片ID
④ 烧录 LED 闪烁程序 → 观察心跳
⑤ HSE 验证：RCC 寄存器读 HSERDY=1(8MHz起振成功标志)
⑥ 72MHz 全速跑 CoreMark/简单延时翻转，电流应 ~30-50mA
⑦ W25Q64 焊上 → SPI 读写 JEDEC ID 测试
```

## 11. 常见翻车点

| 现象 | 根因 | 教训 |
|------|------|------|
| ST-Link 连不上 | SWD 排针 GND 未接/PA13 被复用 | 调试口神圣不可侵犯 |
| HSE 不起振 | 负载电容错值/晶振地脚未接地 | 用四脚晶振并接地 |
| 上电偶发不启动 | BOOT0 悬空(忘焊下拉) | 配置脚必须有确定电平 |
| ADC 读数抖 | VDDA 未隔离直接接数字3.3V | 磁珠+独立滤波不是玄学 |
| USB 插着但 LDO 发烫 | 后级短路/AMS1117 无输出电容振荡 | 输出电容是稳定性的一部分 |
