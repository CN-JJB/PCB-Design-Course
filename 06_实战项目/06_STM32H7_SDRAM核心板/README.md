## 2. 电源树——本项目的第一难点

```
5V 输入
 ├─[TVS+保险丝]─┬─ USB VBUS
 │              └─ MP2315 Buck(3A)
 │                 ▼
 │              +3V3 主域 ──┬── H743 VDD/VBAT/USB_VDD?
 │                         ├── 排针外设
 │                         └─ [LDO ME6211]→+3V3A 模拟(VDDA)
 │
 ├─ MP2315 Buck#2 
 │    ▼
 │  +1V8 域? H743 无需1V8(LQFP版)，
 │  但预留 SDRAM 升级为 DDR 版的接口位? 教学裁剪：不做
 │
 └─ H743 内置 SMPS/LDO 选择脚配置：
    LQFP208 的 H743 用内置 LDO 方案：
    VDD11LDO 输出 1.1V 核心域 → VCAP1/VCAP2 各挂 2.2μF
    ★VCAP 电容是芯片内核稳压的输出端，
      必须紧贴引脚且走线短粗——漏接=不启动。
```

## 3. H743 关键引脚组讲解

```
电源类(Pin 数多，逐组处理)：
- VDD ×若干组 → 每组0.1μF+整域4.7μF×2
- VCAPP/VCAPN? LQFP 为 VCAP1(pin?) / VCAP2 → 2.2μF×2 紧贴
- VDDA/VREF+ → 模拟域：磁珠+1μF+0.1μF；VREF+ 可接分压基准
- VDDUSB → 独立0.1μF+1μF
- BOOT0 → 10k 下拉+跳线排针

时钟：
- OSC_IN/OUT: 外部晶振? H743 常用 8MHz HSE + 内部PLL到480MHz
  或直接焊 25MHz? 以你的启动代码为准选 8MHz 标准款
- PC14/15 32.768kHz LSE 预留位(RTC)

调试与系统：
- SWD 四线 + NRST 复位 RC 电路
- PDR_ON 引脚(LQFP208 特有!)必须拉高到 VDD —— 新坑！

SDRAM 接口(FMC)：
- 时钟 SDCLK(来自 FMC 输出)
- 地址 A0~A12、BA0/BA1
- 控制 RAS/CAS/WE/CS/CKE/DQM(UDQM/LDQM)
- 数据 D0~D15
共约 40 根线构成"DDR 类"约束组。
```

## 4. SDRAM 布线的约束体系

SDR SDRAM 虽比 DDR 宽松，但 143MHz 已是严肃高速：

### 分组与拓扑

```
组一 地址命令控制组(ADDR/CMD/CTRL 共约20根)：
  拓扑：从 H743 出发星型/近等长到 SDRAM
  参考基准：SDCLK
  匹配目标：全部相对 CLK ±1.5cm? 工程值 ±15mm 内
  (SDR 的建立保持裕量大，此目标轻松达标)

组二 数据组 D0~D15 + DQM×2：
  与 CLK 匹配 ±15mm 同样宽松
  但组内尽量互等长(<±5mm)减少歪斜
  
组三 SDCLK 单根(差分? SDR 是单端时钟)：
  全程最短路径优先，串阻 22Ω 靠近驱动端

关键认知：SDR SDRAM 的时序预算远好于 DDR3，
真正要严防的是：参考完整性、串扰(3W)、过孔回流。
把这三件事做对，等长只是收尾仪式。
```

### 阻抗与端接

```
单端 50Ω 目标(L3 带状线为主力层！)
驱动器 H743 FMC 无 ODT → 靠源端串阻：
  ADDR/CMD 组：22~33Ω 每根(靠近CPU侧)
  数据组：双向，两端各留 0Ω 位按实测决定
  CLK：22Ω
```

## 5. PDN 设计书（目标阻抗法完整实战）

```
轨道：+3V3 主域
负载构成：
  H743 IO 电流 ~150mA(总线满翻转)
  SDRAM  ~130mA 突发性强(整行突发读写)
  外设余量 100mA
ΔI 取 250mA，ΔV 允许 ±2%(66mV)
Z_target = 66mV/250mA = 264mΩ @ 需覆盖到 ~100MHz

配置方案：
┌────────────────┬──────────────────────┐
│ 频段            │ 器件                  │
│ DC~10kHz       │ MP2315 环路           │
│ 1k~1MHz        │ Bulk: 470μF固态×1     │
│                │ + 220μF×1 于SDRAM旁   │
│ 1M~100MHz      │ 0.1μF×12(每电源脚)    │
│                │ + 10μF×4 分布         │
│ 100MHz+        │ L4/L5 平面对 ≈2nF     │
└────────────────┴──────────────────────┘

MP2315 Buck 布局军规(开关电源专题)：
[ ] 输入环路(Cin-高侧管-低侧管)面积最小化
[] 开关节点(SW)铜皮最小必要面积(防天线)
[ ] 反馈走线远离 SW 电感
[ ] 电感底部各层净空(涡流与耦合)
[ ] 输出感测点在电容之后
```

## 6. 六层叠层与层分配决策

```
L1 SIG_TOP   ：USB差分、晶振、调试口、低速扇出
L2 GND       ：完整平面
L3 SIG_MID   ：★SDRAM 全部40根(带状线屏蔽最优)
L4 PWR       ：+3V3大区 / +3V3A岛 / USB5V条带 三分割
L5 GND       ：完整平面
L6 SIG_BOT   ：排针扇出、备用布线

为什么 SDRAM 走 L3？
① 带状线参考上下双 GND，回流最完美
② 与 L4 电源平面的噪声天然隔离(L5 在中间? 
   注意 L3 参考的是 L2/L4——L4 是 PWR!
   → 修正：本叠层下 L3 参考面为 L2 GND 与 L4 PWR，
   高频回流主要沿最近平面。为避免 PWR 平面噪声
   耦合进数据组，把 SDCLK 与敏感组安排远离
   电源域边界投影区，并保证 L4 的 +3V3 大区
   完整覆盖 SDRAM 布线区投影。
   这是六层方案一的固有课题——理论篇讲过，
   此处是它的真实落地场景。)
```

## 10. 常见翻车点

| 现象 | 根因 |
|------|------|
| 芯片完全无响应 | PDR_ON 忘拉高 / VCAP 无电容 |
| 内核跑不满 480MHz | VCORE 不稳(VCAP 远/小) |
| SDRAM 大概率读写错 | 初始化序列参数错(tRCD/tRP) 或信号串扰 |
| SDRAM 温度高+数据错 | CKE 常拉高未进自刷新? 或 DQM 极性反 |
| USB 插上电脑死机 | USB_VDD 域去耦缺失 |
| Buck 啸叫 | 输出容 ESR 失配/反馈点位置错 |
