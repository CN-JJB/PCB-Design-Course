# 实战项目总览：六块板，一条进阶路

> 六个项目 = 三块四层 + 三块六层，难度严格递增。每个项目都是一次完整的硬件交付：需求 → 原理图 → PCB → 打样 → 焊接 → 调试 → 复盘。

---

## 一、项目矩阵

| # | 项目 | 层数 | 难度 | 天数 | 核心训练点 | 新引入技能 |
|---|------|------|------|------|-----------|-----------|
| 1 | USB 转 UART 小板 | 4 | ★☆☆☆☆ | 3 | 第一次多层板工作流 | 叠层设置/差分对/缝合孔 |

## 二、为什么是这个顺序

```
项目1 教"流程"：把多层板的操作闭环走通，
      出错成本最低(电路极简单，坏了也好查)
项目2 教"电源"：第一次体会平面供电 vs 走线供电的差异
项目3 教"射频意识"：不需要懂 RF 理论，
      但必须学会敬畏天线净空和模组供电
项目4 上六层：阻抗计算从纸面落到真实下单
项目5 极限精度：±0.1mm 级等长，工具链全开
项目6 集大成：DDR 的约束密度是所有接口之最，
      能做完它，市面上 90% 的板子你都有信心接
```

## 三、通用工作流（每个项目都遵循）

```
Phase0 需求规格书     半天   写下功能/接口/尺寸/成本目标
Phase1 原理图         0.5~2天 引脚级核对 datasheet
Phase2 封装与 BOM     半天   全部有货才继续
Phase3 叠层决策       半天   用第四部分决策链
Phase4 布局           0.5~1天 分区→锚点→细节→飞线审查
Phase5 规则配置       半小时  Net Class+差分对+Custom Rules
Phase6 布线           1~3天  优先级金字塔
Phase7 平面与缝合     半天   分割/缝合墙/热孔阵
Phase8 DRC+人工巡检   半天   双清零+回流投影检查
Phase9 Gerber+下单    半天   Gerber Viewer 自检后提交
Phase10 焊接调试      1天    安全上电仪式→分级验证
Phase11 复盘归档      2小时  NOTES.md+更新个人 Checklist
```

## 六、个人 Checklist 模板（持续生长的资产）

```markdown
# 我的多层板设计 Checklist vX.Y

## 叠层
[ ] 对称性检查(材料+铜厚)
[ ] 每信号层有紧邻参考平面
[ ] 高速信号是否安排在带状线层

## 电源
[ ] 电源树文档化
[ ] 目标阻抗计算存档
[ ] 每VDD引脚去耦≤2mm 双孔落地
[ ] Bulk 电容位置合理

## 回流
[ ] 高速网络平面投影审查
[ ] 换层伴飞地孔100%
[ ] 无跨分割信号
[ ] 缝合孔墙完成(板边10mm间距)

## 差分对
[ ] 阻抗目标表已填并经计算器反解
[ ] 对内gap全程恒定(pad区除外)
[ ] 等长报告达标
[ ] 换层同步+伴飞

## 时钟/RF
[ ] 晶振下方净空
[ ] 时钟远离板边/接口
[ ] RF 净空区无任何铜和走线

## 接口与EMC
[ ] ESD器件距连接器<5mm 且双地孔
[ ] 共模抑制预留位
[ ] 未用GPIO处理策略确认

## 制造
[ ] ERC/DRC 清零存档
[ ] Gerber Viewer 六层全检
[ ] 阻抗控制勾选+表格填写
[ ] 快照归档 vX.Y
```
