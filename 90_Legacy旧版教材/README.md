# Legacy / 前置复习说明

当前仓库仍保留 `01_零基础入门` 到 `08_附录`，原因是其中包含大量有价值的基础解释、FAQ、案例、速查表和练习。

但它们**不再构成正式主课程顺序**。

## 定位

- `01_零基础入门`：零基础前置复习；
- `02_原理图设计`：原理图 / library 前置复习；
- `03_二层板实战`：进入 Part 0 前的能力 Gate；
- `04_多层板理论`：Legacy theory，优先阅读新版 Part 0 / 2 / 3 / 4 / 6；
- `05_KiCad多层板操作`：Legacy tool notes，正式课程基线已升级为 KiCad 10；
- `06_实战项目`：旧版独立案例，不等于新版持续升级的 MCU 主线；
- `07_进阶专题`：补充专题，核心内容逐步并入新 Part；
- `08_附录`：继续作为长期参考资产维护。

## 规则

旧版内容若与正式 Part 0～9 冲突：

1. 以最新 Part 为教学口径；
2. 器件与协议事实以一手资料为准；
3. 软件操作以当前 KiCad 官方文档为准；
4. 板厂参数在实际下单时重新查询；
5. 发现旧文事实错误时直接修正，不为“保留旧版原貌”牺牲准确性。
