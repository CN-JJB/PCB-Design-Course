## A. STM32 USB

### ST AN4879 — Introduction to USB hardware and PCB guidelines using STM32 MCUs

用途：

- USB peripheral hardware considerations
- PCB routing / ESD / connector guidelines
- STM32F4 等器件的 USB hardware context

当前课程查询基线：Rev 10，2025-01。

原则：

> USB 的具体 layout requirement 优先看 ST + USB-IF + protection component datasheet，而不是通用“90Ω差分口诀”。

## B. ESD Layout

### TI SLVA680A — ESD Protection Layout Guide

用途：

- `L·di/dt` 对 ESD clamping 的影响
- protection device placement topology
- 低阻抗 discharge path

教材的重要结论：

> TVS 布局质量取决于完整 ESD current path，而不是单个固定距离。

## C. PCB EMC / Differential & Common Mode

### TI SLLA561 / related EMC application material

用途：

- common-mode / differential-mode current loop 的系统思维
- PCB layout 对 emissions 的影响

### TI SLA856A — PCB Design for EMC

用途：

- continuous ground / return path
- component placement and routing as EMC controls

这些资料用于解释物理与工程思路，不代表 V2 自动适用其中所有器件级数值。

# 数字纪律

## 1. 标准限值

CISPR / FCC / IEC 等标准的：

- frequency range
- test distance
- class
- detector
- limits
- immunity level

必须按产品目标和当前标准版本核对。

教材不把某个限值表永久复制成“所有产品认证线”。

---

## 2. ESD 等级

`±8 kV contact`、`±15 kV air` 等常见数字只在具体标准/等级/产品 requirement 中有意义。

不能因为 TVS datasheet 写“IEC Level 4”就假设整机一定通过。

整机结果还取决于：

- enclosure
- connector
- discharge path
- grounding
- cable
- firmware reset behavior

---

## 3. TVS 距离

不使用统一 `<5 mm` 作为通过条件。

优先判断：

- current interception topology
- shared inductance
- discharge via/path
- connector-to-protection trace
- downstream protected trace

---

## 4. Via-fence spacing

不使用统一 `10 mm`。

可用电尺寸（例如波长比例）建立数量级，但最终还要结合：

- board/enclosure structure
- seam/aperture
- target frequency
- PCB thickness
- manufacturability

---

## 5. CMC / Ferrite

不使用“加上一定更好”。

必须结合：

- common-mode impedance
- differential insertion loss
- parasitics
- saturation / transient behavior
- channel requirement
- measurement

---

# 本 Part 的写作准则

任何整改建议尽量写成：

```text
Observed symptom
→ Current path hypothesis
→ Physics
→ Proposed PCB change
→ Side effect
→ Verification method
→ Source / requirement
```

而不是：

> “EMC 不好就多打地孔、加磁珠、套屏蔽罩。”

这也是从经验型 PCB 设计走向工程型 PCB 设计的关键分界。
