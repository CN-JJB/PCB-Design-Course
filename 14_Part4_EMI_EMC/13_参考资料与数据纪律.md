# 13｜Part 4 参考资料与数据纪律

## A. STM32 USB

### ST AN4879 — Introduction to USB hardware and PCB guidelines using STM32 MCUs

用途：

- USB peripheral hardware considerations
- PCB routing / ESD / connector guidelines
- STM32F4 等器件的 USB hardware context

当前课程查询基线：Rev 10，2025-01。

原则：

> USB 的具体 layout requirement 优先看 ST + USB-IF + protection component datasheet，而不是通用“90Ω差分口诀”。

## B. ESD Layout

### TI SLVA680A — ESD Protection Layout Guide

用途：

- `L·di/dt` 对 ESD clamping 的影响
- protection device placement topology
- 低阻抗 discharge path

教材的重要结论：

> TVS 布局质量取决于完整 ESD current path，而不是单个固定距离。

## C. PCB EMC / Differential & Common Mode

### TI SLLA561 / related EMC application material

用途：

- common-mode / differential-mode current loop 的系统思维
- PCB layout 对 emissions 的影响

### TI SLA856A — PCB Design for EMC

用途：

- continuous ground / return path
- component placement and routing as EMC controls

这些资料用于解释物理与工程思路，不代表 V2 自动适用其中所有器件级数值。

## D. Cable / Chassis / Ethernet Boundary

### TI SNLA107A — Reducing Radiated Emissions in Ethernet Applications

用途：

- connector/cable common-mode

本课程当前不做 Ethernet，但用它理解：

## I. Source Priority：EMC / RF / Mixed-Signal 到底先信谁？

Part 4 很容易出现“每篇文章都说得像规则”的问题，所以课程固定采用下面的证据顺序。

| 优先级 | 来源 | 主要决定什么 |
|---:|---|---|
| 1 | 产品安全 / EMC 标准 | 必须满足的法规定义与测试边界 |
| 2 | 芯片 / 模块厂商 App Note、Datasheet、Reference Design | 当前器件真正允许的 pin、RF、ESD、layout 条件 |
| 3 | 板厂制造能力 | keepout、stackup、阻抗、铜厚、工艺可实现性 |
| 4 | Ott / Hartley / Bogatin / Ritchey 等工程资料 | 解释为什么这些规则成立、什么时候会失效 |
| 5 | Forum / Reddit / Video | 真实失效案例、争议、debug 经验 |

### Mixed-Signal

优先组合：

- Henry Ott — *Grounding of Mixed Signal PCBs*
- TI SLYT499 / SLYT512
- ADI MT-031

它们的共同价值不是让你抄一种 ground topology，而是帮助区分：

~~~text
IC pin naming
≠ PCB ground architecture
≠ galvanic isolation
~~~

### RF

对 nRF52 一类 RF 器件，Nordic 官方 reference design / DevZone 指南优先于论坛中的“我这样画也能工作”。

尤其要区分：

- RF feed / matching region；
- antenna radiating keepout；
- board/system ground；
- enclosure / battery detuning。

### MCU EMC

ST AN1709 适合作为 STM32 系统级 EMC 的厂商入口。它不会替你修复错误 stackup，但能帮助检查：

- decoupling；
- clock / crystal；
- reset；
- I/O filtering；
- conducted / radiated susceptibility。

# 数字纪律

## 1. 标准限值

CISPR / FCC / IEC 等标准的：

- frequency range
- test distance
- class
- detector
- limits
- immunity level

必须按产品目标和当前标准版本核对。

教材不把某个限值表永久复制成“所有产品认证线”。

---

## 2. ESD 等级

`±8 kV contact`、`±15 kV air` 等常见数字只在具体标准/等级/产品 requirement 中有意义。

不能因为 TVS datasheet 写“IEC Level 4”就假设整机一定通过。

整机结果还取决于：

- enclosure
- connector
- discharge path
- grounding
- cable
- firmware reset behavior

---

## 3. TVS 距离

不使用统一 `<5 mm` 作为通过条件。

优先判断：

- current interception topology
- shared inductance
- discharge via/path
- connector-to-protection trace
- downstream protected trace

---

## 4. Via-fence spacing

不使用统一 `10 mm`。

可用电尺寸（例如波长比例）建立数量级，但最终还要结合：

- board/enclosure structure
- seam/aperture
- target frequency
- PCB thickness
- manufacturability

---

## 5. CMC / Ferrite

不使用“加上一定更好”。

必须结合：

- common-mode impedance
- differential insertion loss
- parasitics
- saturation / transient behavior
- channel requirement
- measurement

---

# 本 Part 的写作准则

任何整改建议尽量写成：

```text
Observed symptom
→ Current path hypothesis
→ Physics
→ Proposed PCB change
→ Side effect
→ Verification method
→ Source / requirement
```

而不是：

> “EMC 不好就多打地孔、加磁珠、套屏蔽罩。”

这也是从经验型 PCB 设计走向工程型 PCB 设计的关键分界。

---

## G. Immunity Standards Entry Points

正式产品按适用 product standard 与当前 edition 确认测试方案。本课程用于建立方法的基础入口：

- **IEC 61000-4-2** — Electrostatic discharge immunity；当前课程复核时已存在 2025 edition。
- **IEC 61000-4-4** — Electrical fast transient / burst immunity。
- **IEC 61000-4-5** — Surge immunity。

这些标准的 test level、coupling network、performance criterion 不能被本教材里的教学示例替代。

## H. Conducted Emissions

传导发射限值与测试端口取决于具体产品类别、供电方式和适用标准。Part 4 只固定：

```text
DM / CM model
→ source/path
→ correct measurement network
→ reproducible setup
→ applicable standard
```

不提供跨产品通用的固定 limit 表。
