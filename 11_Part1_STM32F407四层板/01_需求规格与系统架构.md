# 01｜需求规格与系统架构：在画第一根线之前先冻结问题

> 🎯 **本章任务**：写出一页可以 Review 的 V1 规格。PCB 设计从“我要做什么”开始，不从“打开 KiCad”开始。

---

## 1. V1 的教学定位

这是一个 **STM32F407 四层基础控制板**，用于训练多层板基本功。

我们故意让电路“够真实但不过载”：

- MCU 足够复杂；
- 有真实时钟、电源和调试；
- 有扩展接口；
- 但暂不加入 USB data / CAN PHY / SD 卡 / Ethernet / SDRAM。

这些会在 V2/V3 逐步加入。

---

## 2. Exact Part Number

```text
STM32F407VGT6
Package: LQFP100
```

选择理由：

- LQFP100 便于观察和手工理解 escape；
- 官方资料成熟；
- 168 MHz Cortex-M4；
- 外设资源足以支撑后续 USB/CAN/SDIO/Ethernet 主线升级；
- 相比 BGA，不会把 Part 1 变成 fanout 教程。

来源：ST STM32F407VG 产品页与 Datasheet。

## 3.1 从 V1 开始就加 Protection Requirements

产品级 requirement 不能只有“功能能不能工作”，还要写“异常时怎样失败”。

建议增加：

| ID | Requirement | 验收方式 |
|---|---|---|
| P-01 | 5V input 的反接 / 错接风险有明确策略 | schematic review + controlled bench test |
| P-02 | input short / overload 不应让 PCB copper 成为保险丝 | protection review + current-limit test |
| P-03 | hot-plug / input capacitance 的 inrush 有预算 | scope current / rail capture |
| P-04 | 用户可接触接口进入 Part 4 ESD threat inventory | connector review |
| P-05 | rail brownout 时 MCU 进入确定 reset state | slow-ramp / droop test |
| P-06 | firmware lockup 有 watchdog / recovery 策略 | forced hang test |

不是每一项都必须在 V1 装器件，但每项都必须：

> **closed / accepted / deferred with rationale**

保护架构见：[09｜产品级保护电路](09_产品级保护电路_从接口到SafeState.md)。


## 3.2 如果产品使用 Battery，Requirement 必须多冻结六类信息

不要只加一句：

~~~text
Battery powered
~~~

至少记录：

| Category | Requirement |
|---|---|
| Electrical | Vmax / Vnom / Vmin、average / pulse current、runtime |
| Chemistry | primary/rechargeable、temperature、self-discharge |
| Safety | cell/pack protection、charger、thermal sensing、safe state |
| Mechanical | holder/pouch keepout、swelling、replaceability |
| Regulatory | target market、coin-cell rules、EU replaceability、applicable safety standard |
| Logistics | exact MPN、UN 38.3 evidence、supplier/lot traceability |

完整方法见：[10｜电池供电产品](10_电池供电产品_选型安全认证与可维修性.md)。


## 4. 电源架构

V1 暂定：

```text
5V_IN
  │
  ├── input protection / connector
  │
  └── 3.3V LDO
        │
        └── 3V3_MAIN
             ├── STM32 VDD
             ├── VDDA branch
             ├── LEDs
             └── expansion (limited)
```

教学参考 LDO：`AP2112K-3.3`。

Diodes Incorporated 官方资料给出：

- guaranteed output current 600 mA（电气能力）；
- 典型应用使用 1 µF input / output ceramic；
- 推荐 X5R/X7R；
- 但实际可持续电流还受封装和 PCB 散热限制。

因此我们不会写：

> “600 mA LDO，所以这块板随便用到 600 mA。”

热耗散必须估算：

```text
P ≈ (VIN - VOUT) × IOUT
```

例如 5 V → 3.3 V 时，压差 1.7 V；负载增加后热功耗很快上升。V2 如果外设电流显著增加，会重新评估 regulator architecture，而不是机械沿用 V1。

AP2112 官方资料：
https://www.diodes.com/part/view/AP2112

## 5. 时钟策略

V1 保留：

- MCU 内部时钟可用于最初 bring-up；
- HSE crystal/oscillator footprint 用于外部高精度时钟实验；
- LSE 是否装配由 RTC 练习决定。

这里先不写死 crystal 型号与 load capacitor 数值。

原因：晶体负载设计必须依据：

- 晶体 datasheet 的 `CL`；
- MCU oscillator characteristics；
- PCB stray capacitance；
- ST 的 clock design guidance。

公式和选型会在原理图章节落实。

## 6. 调试与 Bring-up 设计

至少引出：

```text
SWDIO
SWCLK
NRST
GND
Target Vref (3V3)
```

可选：

```text
SWO
```

Header 要靠近可接触区域，不要被高器件挡住。

### 为什么必须有 Target Vref？

调试器需要知道目标板 I/O 电平环境。不同调试器实现细节不同，因此最终 pinout 以所用 ST-LINK 文档为准。

## 7. 机械需求

教学 V1 先定义一组可修改目标：

```text
Board target: ~80 mm × 60 mm
Mounting: 4 × M3 clearance holes
Components: primarily top side
Debug/UART/power connectors: board edge accessible
```

这不是“最佳尺寸”，而是为了：

- 留足空间观察布局；
- 不用极限工艺；
- 让去耦、电源、时钟区域都能清楚展示。

后续 V2 再做密度优化。

---

## 8. Manufacturing Strategy

V1 采用普通四层 FR-4 标准工艺，不使用：

- blind/buried via；
- via-in-pad；
- HDI microvia；
- buried capacitance；
- exotic laminate。

原因：Part 1 的教学目标是标准多层板结构，不让特殊制造技术掩盖基本功。

## 9. 初始 Critical Nets Table

| Net | Why critical | V1 policy |
|---|---|---|
| 3V3_MAIN | MCU 主供电 | 明确电流路径与局部去耦 |
| VDDA | 模拟供电 | 独立检查连接/去耦 |
| VCAP1/2 | 内部稳压器外部电容 | 严格按 ST 指南 |
| NRST | bring-up | 短、可测、按官方建议 |
| HSE_IN/OUT | oscillator loop | 极短、远离干扰、局部布局 |
| SWCLK | fast debug clock edge | 短、参考连续 GND |
| UART_TX/RX | bring-up | 清晰可访问 |

## 10. ❌ 故障板：需求阶段就埋下的坑

错误需求：

> “做一块 STM32F407 最小系统，所有接口都引出来，越小越好。”

问题：

- “最小”没有尺寸；
- “所有接口”没有优先级；
- 没有电源输入定义；
- 没有调试方式；
- 没有板厂能力；
- 没有装配方式；
- 没有验收标准。

这种项目在布局阶段一定会不断改需求。

工程上更好的做法是：

> **把模糊愿望改写成可以检查的 requirement。**
