# Part 1｜第一块真正的四层板：STM32F407 V1

> 🎯 **项目目标**：从需求开始，完整交付一块可制造、可调试、可 Review 的 STM32F407 四层控制板。重点不是堆接口，而是第一次建立“叠层—原理图—布局—布线—制造”闭环。

主控：**STM32F407VGT6 / LQFP100**。

ST 官方信息显示 STM32F407VG 为 168 MHz Cortex-M4，最高 1 MB Flash、192 KB SRAM，并提供 USB OTG、CAN、SDIO、Ethernet、FSMC 等丰富外围，因此适合做贯穿四层→六层课程的 MCU 家族主线。

---

## 1. 为什么 V1 不把所有接口一次塞满？

因为第一块四层板真正要学的是：

- 需求冻结；
- 电源树；
- MCU 最小硬件；
- Stackup；
- Reference Plane；
- Placement；
- Net Class；
- Return-path-aware routing；
- DRC + manual review；
- Gerber / drill / fabrication notes。

如果第一版同时加入 Ethernet、SDRAM、USB、CAN、SDIO、HDMI，你将无法判断：

> “我现在遇到的问题是四层板基本功，还是某个高速接口自己的规则？”

所以主线采用逐版升级。

---

## 2. 产品家族路线

```text
V1 — STM32F407 四层基础控制板
 │   学：四层 stackup / power / placement / reference plane / review
 │
 ├─ V2 — 四层增强版
 │   加：USB FS / CAN / SDIO / 更严格 SI/EMC
 │
 └─ V3 — STM32H7 六层版
     加：Ethernet / SDRAM / 多电源域 / 六层高速综合
```

FPGA 另走专项副线，不干扰 MCU 主线。

---

## 3. V1 功能范围

### 必须有

- STM32F407VGT6；
- 3.3 V 主电源；
- VDD / VDDA / VCAP / VBAT 正确处理；
- SWD 调试接口；
- BOOT0；
- NRST；
- HSE 时钟位置预留；
- 用户 LED；
- 用户按键；
- UART 调试口；
- GPIO expansion headers；
- 测试点；
- 安装孔。

### V1 有意不做

- USB data；
- CAN transceiver；
- SD card；
- Ethernet PHY；
- SDRAM。

这些会在知识准备好以后逐步加入。

## 4. 本项目的四层结构

课程默认研究：

```text
L1 — Signal + Components
L2 — Solid GND reference
L3 — Power distribution
L4 — Secondary Signal + Components
```

但我们不会说“所有四层板都应该这样”。

这只是一个真实、常见、适合 MCU 教学的案例。

Part 1 会用 JLCPCB 公开的 1.6 mm 四层阻抗叠层作为**真实板厂案例**，同时教你如何替换为自己的板厂。

---

## 5. 这块板的“毕业标准”

### 功能层面

- 可以稳定上电；
- SWD 可连接；
- MCU 可下载程序；
- HSE/内部时钟方案可验证；
- LED / button / UART 可完成 bring-up；
- 所有 GPIO header pinout 文档化。

### PCB 层面

- L2 GND 连续；
- 关键网络有明确 reference；
- 去耦布局能解释电流环路；
- 不为了走线随意切割 GND；
- 电源走向清楚；
- 测试点可访问；
- DRC 通过；
- Gerber Viewer 人工检查通过。

### 工程层面

你必须能回答：

1. 为什么选择这个 stackup？
2. 为什么 L2 保持 GND？
3. 每颗 MCU 去耦电容服务哪个引脚/区域？
4. 为什么 HSE 放这里？
5. 为什么 SWD header 放这里？
6. 为什么某条线走 Top 而不是 Bottom？
7. 哪些检查是 DRC 做的，哪些必须人工做？
