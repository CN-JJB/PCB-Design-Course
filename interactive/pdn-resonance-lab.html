PDN Resonance Lab：阻抗峰怎样放大 VCC 噪声

教学用二阶/多支路趋势模型。观察 local decoupling、upstream isolation、阻尼和负载重复频率怎样改变 resonance / ringing。不是 ADS、PIPro 或 VNA 测量替代品。

观察项趋势解释
Estimated low-frequency resonance由 upstream isolation 与 bulk/local C 的组合决定，真实系统会更复杂。
Peak Q tendency
Repeated excitation当负载重复频率接近 resonance / harmonic relation 时更容易持续加能。
First action
真正 rail noise 满足 ΔV(f)=ZPDN(f)·ΔI(f)。本页只给归一化趋势，不输出假的 mV 或 dB。
