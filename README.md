详细的时间规划、自检题、推荐资源见 **00_课程总览/学习路线.md**。

## 本教程的写作约定

1. **菜单双语**：所有操作写成「英文原名 + 中文译名」，任何语言版本都能对照
2. **数值有出处**：关键数字标注来源（IPC 标准/datasheet/厂商参数表）
3. **每个概念四段式**：物理原因 → 公式 → 直觉理解 → 常见错误
4. **每章末自检**：答不上来不进下一章
5. **每个项目可打样**：全部基于嘉立创标准工艺验证过的参数
